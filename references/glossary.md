# 术语表 — 交易员江河 · 交易决策体系

> 本表只收作者**用法与常识不同**、或他反复使用并明确定义过的关键概念。
> 每条给出：作者的定义（尽量用原文片段）→ 与常识用法的差异（≠/＝）→ 为什么其他能力卡需要它。
> 术语表不独立成能力，作为全部能力卡的共享词典。

## 以损定仓

- **别名**: 以损定仓法
- **作者的定义**: "你最好再做一个以损定仓的这件事儿/就是你的每一次成本的金额是可固定的/而不是浮动的"
- **与常识用法的差异**: ≠ 按固定点位止损 / 按固定手数下单 —— 不是"拿的点越多赚得越多"，也不按点数算盈亏。 = 先按逻辑找到"逻辑否认点"作为止损位，再确定单笔固定亏损金额，然后用仓位（手数）反推，使这笔单无论止损多少点都亏同一个固定金额。
- **为什么其他能力卡需要它**: 是作者整套仓位与风控的地基，直接决定开多少手；也是"大小周期盈亏一样""杠杆只是工具"的前提。下游所有"仓位/风控"能力卡都要引用它，并需与"逻辑否认点"绑定解释。
- **出处**: ep-7.17 L1266、ep-7.17 L1267、ep-7.29 L1273

## 盈亏同源

- **别名**: 应亏同源
- **作者的定义**: "你们要记住一个逻辑 / 盈亏同源能懂啥意思吧 / 应亏同源最简单"
- **与常识用法的差异**: ≠ 存在"必胜逻辑/一招制胜"，也 ≠ 亏损单里一定有新东西可学。 = 亏损单与盈利单来自同一个交易逻辑——同一个逻辑既会带来盈利也会带来亏损，因此没有必对/必错逻辑，只有概率性对错，整体赚的比亏的多即可。
- **为什么其他能力卡需要它**: 解释了作者为何不刻意复盘单笔亏损、为何强调"亏损是必要成本"；下游"心态/复盘"能力卡要用它纠正"拆解亏损单"的直觉。
- **出处**: ep-7.17 L0571、ep-8.5 L0875、ep-8.26 L0137

## 主周期/次周期

- **别名**: 成本周期, 交易周期, 逻辑周期, 进场周期, 关联周期, 参考周期
- **作者的定义**: "在我的概念里 / 没有什么大周期 / 没有什么小周期 / 就是这个是伪概念 / 就有主周期 / 有次周期就行了 / 然后一切交易逻辑全围绕主周期去做判断 / 然后次周期用来做进场没了"
- **与常识用法的差异**: ≠ "大周期定方向、小周期找入场"（按大小分）。 = 按"成本"分——主周期＝交易周期/成本周期，管方向、节奏、位置与"拿什么成本换什么利润"；次周期只用于进场（找信号）；再引入的其它周期叫"参考周期"，不参与决策。作者明确否定"大周期/小周期"，称其为伪概念，认为任何周期都在描述同一件事，不存在"大周期更对"。
- **为什么其他能力卡需要它**: 是作者全部周期论述的落点，决定"看哪个周期、在哪个周期等信号"，也是解盘第一步；下游"周期搭配/解盘"能力卡必须以此为准，避免周期打架。
- **出处**: ep-7.29 L0592、ep-7.29 L0593、ep-8.5 L0575

## 关键位（参考位/交易位）

- **别名**: 关键区域, 参考位, 交易位
- **作者的定义**: "这一段空投开始赚钱的点位 / 也是这一段多头怎么样开始亏损的点位 / 就多头在这个位置被套牢 / 空投在这个位置开始赚钱 / 这就是我们所谓的关键位"
- **与常识用法的差异**: ≠ 画一条线、价格到那就反转 —— 它只是"共识累积处/参考"，本身没太大作用，作用"就是用来突破的"，起作用的是到关键位之后的价格行为。 = 空头开始赚钱、多头开始被套牢（或反之）的点位；是**区域**而非线或精确价格点（"关键为你找不出来那么特别/精准的某一个点"）；分"交易位"（可下单）与"参考位"（只参考）。
- **为什么其他能力卡需要它**: 是"参考历史"的落脚点，也是"在哪瞄定、在哪不做"的依据；下游"关键位识别/解盘"能力卡必须带上"关键位是区域+分交易位/参考位+不保证起反应"这三点澄清。
- **出处**: ep-7.29 L1827、ep-8.5 L0976、ep-8.7 L235

## 攻防一体位

- **别名**: 攻防转换位, 攻防一体, 回踩防守位, 防守位, 上半沿, 下半沿
- **作者的定义**: "什么叫攻防体 / 就是你画不出两个关键位 / 一个一个区间内画不出两个关键位"
- **与常识用法的差异**: ≠ 独立的进攻位/防守位（一个标准区分）。 = 当画不出独立的进攻位与防守位时，把两者合并成一个区间（攻防一体位），区间上下半部分权重不同；它"并不标准"。作者又明确：攻防一体位与关键位无本质区别，只是关键位的一个统称/细分叫法，不是独立工具。"防守位"＝结构延续的防守点（预先画出来看反应，不是必须瞄准那根线，作者用"紫色区"标5分钟防守位）；区域太大时会细化出"上半沿/下半沿"作为锁定。三者同属关键位的分层坐标，故合并。
- **为什么其他能力卡需要它**: 是作者标区域做单（尤其"5分钟看攻防一体"）的常用处理方式；下游"位置判定"能力卡需防止把它当成独立概念或标准结构。
- **出处**: ep-7.29 L0869、ep-7.29 L0880、ep-8.7 L016

## 第一推动/第二推动

- **别名**: 一推, 二推, 二推不破, N字型, N字形
- **作者的定义**: "二推不破是打破事儿/再回来能懂吗/这叫二推不破/最少得给这个点打破对吧/走出个右侧"
- **与常识用法的差异**: ≠ "收个反向K线就能进"，也 ≠ 双底/双顶。 = 第一推动＝打破结构的强势推动；第二推动＝第一推动回调结束后的再次推动。一推回撤二推走出后构成 N 字形（作者逻辑的承载图形，"不是看N字型做交易，而是靠N字形得到信息"）。"二推不破"＝先打破某点（走出右侧）再回来不破该点；未打破点的形态只能叫双底/双顶。二推波只是**信号**，不是交易逻辑。
- **为什么其他能力卡需要它**: 是"抓转折"的过滤条件、也是识别结构与找位置的基础构件；下游"进场信号/结构"能力卡需区分"打破≠延续""信号≠逻辑"。
- **出处**: ep-8.3 L0421、ep-8.3 L1214、ep-8.5 L0820

## 抓转折

- **别名**: 顺势转折, 强势追涨, 高抛低吸
- **作者的定义**: "看到一个第一推动 / 强势的第一推动之后 / 然后产生一个微弱的回调 / 去判断这一段回调结束 / 去拿第二推动利润能不能懂"
- **与常识用法的差异**: ≠ "收个反向K线就能进"，也 ≠ 趋势/波段交易，也 ≠ "什么都能做"。 = 看到强势第一推动后产生微弱回调，判断该回调结束，去拿第二推动的利润；前提是回调不能过深、必须是外部结构、有第一推动。条件"非常苛刻"，只有极强势才追；利润空间小、胜率偏高，宜配敏感离场。作者自述只会这几招——"顺势转折、高抛低吸、强势追涨（强势就抓转折）"，即只做认知内的这几种。
- **为什么其他能力卡需要它**: 是作者一分钟/五分钟短线进场的主要模式，也是"追单"的少数合法例外；下游"进场手法"能力卡需标注其苛刻条件，避免被滥用。
- **出处**: ep-8.3 L0808、ep-8.5 L0702、ep-8.5 L0721

## 共振

- **别名**: 逻辑共振, 套娃, 高质量机会, 容错空间
- **作者的定义**: "什么叫高质量订单 / 是共振 / 就是你未必它周期一定要大 / 但是要共振 / 在我算看来是高质量的 / 就是你的大周期跟你的小周期 / 形成了一个共振"
- **与常识用法的差异**: ≠ 大周期＝高质量；共振是加分项、不是必需。 = 两个逻辑/两个周期方向重合重叠（如"打破形成反转"与"二推不破"重合、大区间套小区间"套娃"）。共振处是最佳位置、高质量订单；大小周期共振时即使没按大周期利润走，小周期也能拿到利润离场（"容错空间"）。低质量机会＝顶着主周期方向做。
- **为什么其他能力卡需要它**: 是作者定义订单质量与过滤机会的核心标准，也是"用小成本博大利润"的依据；下游"机会分级/仓位"能力卡以"是否共振"决定做不做、用多大仓。
- **出处**: ep-7.29 L1305、ep-7.29 L1309、ep-8.7 L866

## 参考历史、尊重当下

- **作者的定义**: "就一句话就概括了嘛 / 参考历史 / 尊重当下"
- **与常识用法的差异**: ≠ 只看历史关键位就做，也 ≠ 只看当下信号就做。 = 作者整套逻辑的一句话概括：参考历史（用历史找关键位/拐点、看共识累积）＋尊重当下（在关键位观察当下微观结构/行为），两者重合才做。不同流派（订单流/期权等）只是载体不同、底层逻辑相同。
- **为什么其他能力卡需要它**: 是作者最核心的方法论口号，几乎每场直播都出现；下游"总纲/解盘"能力卡用它统一"历史+当下"两步框架。
- **出处**: ep-7.29 L0940、ep-7.29 L1815、ep-9.30 L1342

## 动态离场

- **别名**: 动态止盈, 敏感离场, 钝化离场, 推左一
- **作者的定义**: "我止盈策略就是我是动态离场 / 我就是一个动态离场"
- **与常识用法的差异**: ≠ 静态止盈/设死盈亏比。 = 不预设静态止盈位，根据行情动能（是否还能继续运动、是否创出新高/新低）决定离场；到预期位后改为推止损，用小利润回撤博更大奔跑。分两型且不可兼得：敏感离场（等一个减弱就走，接受卖飞）／钝化离场（等结构打破或"推左一"，接受利润回撤）。"推左一"＝用左侧第一根K线跟着往上推止损的钝化手法。
- **为什么其他能力卡需要它**: 是作者止盈策略的核心，决定持仓时间长、常出现"浮盈回吐"；下游"离场/定制系统"能力卡以它为可选模块，并须绑定"必选题"（两型只能选一）。
- **出处**: ep-7.17 L0369、ep-7.29 L0379、ep-8.26 L0848

## 左侧/右侧

- **别名**: 左中左, 左中右, 右中左, 右中右
- **作者的定义**: "在A点买/你就是左侧/你现在在B点买/你就是右侧/……它是相对概念/他不是绝对概念"
- **与常识用法的差异**: ≠ "某点一定是左侧/右侧"的绝对定义。 = 相对概念，没有绝对定义——同一位置相对于更早的点是右侧、相对于更晚的点是左侧；要先定义参照点才能定出左侧/右侧。作者把进场位置细分为左中左/左中右/右中左/右中右四个模型（加"共振"共五个），"右中左打破就算右侧了"；判断一笔单先要说出它属于哪个模型，不属于任何模型就不做。
- **为什么其他能力卡需要它**: 是作者描述与筛选进场时机的入口工具，决定进场是左侧还是右侧、是否接受扫损；下游"进场模型"能力卡需先讲清"相对概念"再讲四模型。
- **出处**: ep-7.29 L0930、ep-8.5 L1392、ep-8.7 L1177

## 强弱转换

- **别名**: 强转弱, 弱空, 强空, 强弱
- **作者的定义**: "就是一个宽幅对吧 / 就是一个弱趋势的空嘛 / 能懂吗 / ... 弱空就代表着什么 / 第一我不要去追空"
- **与常识用法的差异**: ≠ "看到多头强就该做多"。 = 描述行情力度与节奏（强转弱、弱空/强空）；"多头强跟能不能做多是一回事，他俩是两个事"——强弱（看到什么）≠ 可做性（要做什么）。弱空＝弱趋势的空（宽幅），不能追空、只能高抛。原文未展开"强弱转换"的具体判据。
- **为什么其他能力卡需要它**: 防止把"看到强"直接等同于"该做该方向"；下游"节奏判断"能力卡用它区分"该不该追、怎么高空"。
- **出处**: ep-7.17 L2028、ep-7.29 L0443、ep-7.29 L1920

## 方向—节奏—位置—信号

- **别名**: 四要素, 信号vs交易逻辑
- **作者的定义**: "方向你得有吧 / 位置你得有吧 / 节奏你得有吧 / 就在这做你得有吧 / 然后最后才是信号"
- **与常识用法的差异**: ≠ "看到信号就下单"。 = 一笔订单的四要素，按此顺序，信号排最后；信号（如二推波、某根K线形态）只是局部触发点，不能单独作为下单依据；交易逻辑＝方向/节奏/位置/信号的整体。单看一个信号（尤其小周期信号）没意义。
- **为什么其他能力卡需要它**: 是作者判断"这笔单缺什么"的诊断工具，防止拿单个信号直接下单；下游"下单前检查/系统骨架"能力卡以它排序。
- **出处**: ep-8.7 L1244、ep-8.7 L1245、ep-8.7 L1248

## 外部结构/内部结构

- **别名**: 内部结构, 外部结构
- **作者的定义**: "内部结构的作用/我认为它唯一的作用就是唯一的价值/就是帮你明确外部结构/能懂吗/大NO NO"
- **与常识用法的差异**: ≠ 内部结构也是重要决策依据。 = 内部结构唯一作用是帮你明确外部结构；作者称自己"都不看内部结构这个东西"，认为内部结构大多数都不重要；在内部结构做单等于换了逻辑周期。
- **为什么其他能力卡需要它**: 纠正粉丝对"内部结构点被打破"的过度解读；下游"结构判断"能力卡需说明内外之分在真正懂逻辑后只是节奏问题。
- **出处**: ep-8.26 L1629、ep-8.26 L1631、ep-9.24 L1137

## 结构延续

- **别名**: 结构打破, U中U
- **作者的定义**: "但是这个右侧行为/它现在来说没有形成一个U中U/也就是没有形成一个结构上的一个延续啊/重点在这个点能不能破"
- **与常识用法的差异**: ≠ "打破＝延续"。 = 价格打破关键位后继续按原方向走出新结构（U中U）；结构点被打破前视为原方向延续（防守位），被打破则可能发生结构转变。"打破"只是可能转变，需再走出结构延续才算。
- **为什么其他能力卡需要它**: 是"方向是否变化"的判定依据，也是等信号的触发条件；下游"趋势判断/等待策略"能力卡需区分打破与延续。
- **出处**: ep-9.16 L2003、ep-9.24 L140、ep-9.28 L2781

## 真空区

- **别名**: 真空, 真空区域
- **作者的定义**: "那这个位置没有什么博弈区/这个位置来看的话/它是一个真空/没有什么博弈区/就是你的一个助推因子非常少"
- **与常识用法的差异**: ≠ 有历史与当下重合因子的位置。 = 左侧没有价格停留/成交的空白区域（如大阴线/急跌造成的空白），无博弈区、助推因子极少；只有单一因子，作者一般不做，也可作为抓转折的加分背景。
- **为什么其他能力卡需要它**: 用于判断某位置是否值得做；下游"位置质量评估"能力卡用它识别"因子太少不做"的情形。
- **出处**: ep-9.4 L2439、ep-9.4 L4406、ep-9.14 L1055

## 排斥反应

- **作者的定义**: "等他当下出现一个明确的向上上涨/排斥反应/我们干进去/这就要参考历史/加尊重当下干就行了"
- **与常识用法的差异**: ≠ "碰到就涨"（单看影线）。 = 价格到达筹码区/关键位后出现的明确反向反应（明确向上/向下的排斥），是结构信号；作者要求必须出现明确排斥反应才动手，并把它当作进场/离场的明确信号。
- **为什么其他能力卡需要它**: 是"等明确信号"框架里信号的具体形态，也是"尊重当下"的落地动作；下游"进场触发"能力卡用它界定"什么时候才动手"。
- **出处**: ep-9.3 L3384、ep-9.4 L0882、ep-9.4 L1383

## 假突破

- **别名**: 假跌破, 二次突破
- **作者的定义**: "如何判断它是不是假跌破对吧 这是需要现在去判断的一个点吧 ... 谨慎一点的话就不把这个当假突破 ... 你就是正常 当他现在处于一个啥也不是状态"
- **与常识用法的差异**: ≠ 真突破。 = 打破结构位但未跟随/未拉开距离（未满足实体拉出50%+第二根跟随）的突破，可反向操作，并对防守位有"消耗"作用；二次突破＝回撤回区间后再次突破，是判断震荡突破真伪的关键。作者强调证据矛盾时宁可判"啥也不是"，不轻易当假突破——真突破（跟随、拉开距离）≠ 假突破（无跟随、未过50%）≠ "啥也不是"。

- **作者的定义**: "啥叫真赢 / 就是真 / 就单笔200%分之五这种的仓位管理 / 然后一笔一笔按照技术平推也带止损 / 怎么样平推推上去的对吧 / 那啥叫假赢呢"
- **与常识用法的差异**: ≠ "赚到钱就是对的"。 = 真赢＝用单笔2%-5%仓位、按技术平推且带止损赚上来的；假赢＝靠重仓/扛单/梭哈/不带止损打上来的（一改仓位管理往往就赚不到钱）。配套区分：概率损（概率成本）＝交易逻辑完全正确但结果亏了，属必须付出的成本；系统之内的错＝违背自己规则的错（不允许），系统之外的错＝规则内仍发生的错（可接受），错过≠做错。
- **为什么其他能力卡需要它**: 判断资金能否持续、以及如何评价一笔亏损；下游"资金曲线诊断/复盘"能力卡以此区分"该改系统还是只是概率成本"。
- **出处**: ep-9.9 L2834、ep-9.16 L2062、ep-9.16 L2097

- **作者的定义**: 表象=固定图形/模型（W底、回踩确认等）的形态比对；实相=支撑该图形的更微观内容/数据/细节（如订单流佐证）。
- **与常识用法的差异**: ≠ 只看形态；= 表象重要但实相更重要，主张两者结合、更重实相。
- **为什么其他能力卡需要它**: 关联能力卡：无直接对应卡

- **与常识用法的差异**: ≠ 直接下单；= 短线策略流程中的中间态（从"被打破"到"新N字构成"之间）。
