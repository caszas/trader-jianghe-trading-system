# 体系总览 — 交易员江河 · 交易决策体系

> 来源：交易员江河的公开直播与视频内容（转写稿合计 135 万字）。
> 原作者：交易员江河 · https://space.bilibili.com/3546770449631285

## 一句话主旨

把交易当成一门**算账的生意**：先看穿 K 线背后的多空资金强弱，只在"认知以内"的极少数机会出手，
用"以损定仓"控制成本、用"动态离场"兑现利润，靠"筹码分配"把盈亏比从小做大，
最后用**规则**替代情绪、用**拆订单**替代感觉。

作者要回答的核心问题是：**为什么大多数人学了技术还是亏钱？**
他的答案是把交易当"看图猜方向"而不是"算账的生意"。

## 体系骨架（七层，层层递进）

1. **市场认知层** —— K 线是资金的语言，不是形态的图册。裸 K 的第一课是"忘掉形态"：
   一个逻辑可以有多种形态载体，同一形态在不同背景下含义不同。K 线涨跌 = 资金流动 = 多空阵营力量强弱。
2. **机会筛选层** —— 只做认知以内的少数机会，看不懂就不做（"硬座"）。
   用必要条件（历史与当下重合、多因子共振）过滤机会，宁可空仓。
3. **周期契约层** —— 周期不是方向，而是"拿什么成本去换什么利润"的契约。
   主周期 + 次周期搭配；"顺一个势的同时一定逆一个势"，没有绝对顺势，只需顺主周期。
4. **执行风控层** —— 止损按**逻辑否认点**定，不按点位；仓位由止损距离反推（以损定仓）。
   订单只有两种结局：打止损，或赚钱离场——没有"没打止损就割肉"。离场用动态判断，不设固定止盈。
5. **资金管理层** —— 起步点必须是"健康订单"（挑不出毛病的必要条件组合），不做任何"包容行为"。
   符合逻辑但无加分项 → 半仓；有共振等加分项 → 正常仓。**只做递减，不做浮盈加仓。**
6. **系统建模层** —— 拆订单：取历史订单，先"拆盈利"找必要条件，再"拆亏损"砍掉高频亏损条件。
   这是把主观经验外化为规则的唯一路径。
7. **心态与成长层** —— 用规则替代修心；同一逻辑连损两次即停手；盈亏同源、不假想稳定。
   资金观：本金取"能心疼"的量、必须留备用金、"认知不能变现就等于没有认知"。

## 核心命题

1. 市场看的是资金与多空力量对比，不是形态；形态只是逻辑的载体。
2. 只做认知以内的机会——看不懂、有犹豫、需要问别人的，一律不做；空仓不是损失。
3. 周期是"拿什么成本换什么利润"的契约，不是方向；不存在"多周期全顺"。
4. 一笔订单只有两个出口：打止损，或赚钱离场；没有第三种，也绝不留被套单。
5. 技术只决定**底线**（小亏小赚甚至不亏）；从小做大靠筹码分配，且只做递减不做递增。
6. 心态问题用规则解决而非"修心"；亏损之后要做什么，必须在交易系统里写死。
7. 把感觉量化成数据：用拆订单回测从历史订单里拆出必要条件，砍掉高频亏损条件。
8. 离场方式是**必选题**（卖飞或利润回撤），想两者兼得会陷入内耗。
9. 交易系统 = 主观构建 + 客观执行；且必须"触发才做"，不是"想做就做"。
10. 认知不能变现就等于没有认知；认知必须转化为行动。
11. 资金必须被严肃对待：本金取"能心疼"的量级、必留备用金、分批出金、做资金隔离。
12. 稳定盈利只是对过往的总结，不是对未来的承诺；没有稳定的事，只有稳定的人。

## 关键术语（作者本人的用法）

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 以损定仓 | 先找"逻辑否认点"当止损，再由止损距离反推仓位 | ≠ "设个止损"；顺序是先定止损**再**定仓位 |
| 逻辑否认点 | 使"当初做这一单的理由"不再成立的位置 | ≠ 技术止损位；由做单逻辑推出 |
| 健康订单 | 起步点挑不出任何逻辑毛病的订单 | ≠ "胜率高的单"；评价的是入场时的完备性 |
| 硬座 | 看不懂、有犹豫、需要问别人却仍然做的那一单 | 判定结果是二值的"不做" |
| 攻防一体位 | 同一结构里既是进攻位又是防守位的价格区域 | ≠ 支撑/阻力；一个区间画不出两个关键位 |
| 关键位（区域） | 一个价格区域，套牢共识与护盘共识在此决策 | ≠ 精确到点的支撑阻力线 |
| 共振 | 多个因子在同一点上同时成立 | ≠ "多个指标同向" |
| 主周期 / 次周期 | 主周期定方向、节奏、位置；次周期只做进场 | ≠ "多周期共振"；周期由人臆想、是工具 |
| 筹码分配 | 按机会质量分层给仓，且只递减不递增 | 核心禁令是不做浮盈加仓 |
| 拆订单 | 把历史同类机会全找出来，拆盈利找必要条件 | ≠ "复盘"；要求样本级的共性提取 |
| 真突破 / 假突破 | 实体拉出关键位 50% 以上且第二根跟随 = 真 | ≠ "突破即入场" |
| 动态离场 | 动能减弱、创不出新高低时离场 | ≠ "移动止盈"；判据是动能而非价格 |
| 盈亏同源 | 同一个逻辑既可能赚钱也可能亏钱 | 单笔结果不可用于评价方法 |
| 必选题 | 离场方式必须二选一：卖飞 或 利润回撤 | ≠ "优化止盈"；想两者兼得会左右脑互搏 |
| 假赢 / 真赢 | 假赢：靠临时改仓位得来的盈利 | 评价盈利的来源是否可复制 |
| 认知圈 | 你能持续做出比市场更准判断的范围 | ≠ "熟悉的领域" |
| 刻舟求剑 | 把某个历史形态直接套用到当下而不看背景变化 | 主张"参考历史 + 尊重当下" |
| 贴脸损 | 把止损放得极近以提高盈亏比 | 提高盈亏比的两条路径之一 |
| 一推动 / 二推动 | 抓转折＝针对第一推动判断回调结束、拿第二推动利润 | ≠ "波浪理论" |
| 动能线 | 连接发力点的线，用于判断动能延续性 | ≠ 趋势线 |
| 认知两极划分 | 认知只有"懂"与"不懂"两极 | 主张二值化以强制清晰 |
| 猥琐派 | 行情分开做、利润分开拿，不追求一次吃满 | 一整套保守的做单哲学 |
| 亏不没 | 交易是生意，亏损只是成本，正确执行不会把本金亏光 | 前提是带止损 + 以损定仓 + 连损限制 |

（更完整的术语表见同目录的 `glossary.md`。）

## 作者的局限（读这套体系要打的折扣）

1. **"认知以内"可自我判定这一假设未被证明。** 判据是"倒退回去还会这么做、没有犹豫"，
   但犹豫与否是主观感受，无法在事前客观判定——容易被事后合理化。
2. **方法核心不可完全外化。** 作者明确说"手工交易能赚钱取决于两个字——主观"
   "大部分因子在你这个人自身身上"。他的位置概念（攻防一体位、防守位、强弱转换）
   在公开直播内容中**没有可列出的检查项**。
3. **要求别人用数据说话，自己几乎没给过实测统计。** 全篇没有他自己的胜率、盈亏比、
   最大回撤或交易笔数（唯一提到的"回测 200 单胜率 65%"是学员的）。
   因此"这套系统有效"目前是基于个人叙事的信念，**不是已被验证的结论**。
4. **变现立场。** 作者通过自媒体 + 收学员变现，对"学不会"的归因偏向个人，
   系统性低估了这套主观判据的可传授难度——他自己也说"900 多人听，能有 5 个人做就不错了"。
5. **样本窄。** 主要做黄金与"大饼"，自称"我就那两招"。单标的、少策略的样本难以支撑普适性主张。
6. **公开演示失真。** 他自承直播做单会失真（会提前推止损、有节目效果），
   因此直播内容中的"实盘"不能当作真实交易样本直接复刻。
7. **风控不完备。** 全篇强调单笔止损与连损停手，但对平台风险、出金风险、
   极端行情滑点只给了"分批出金"一条。

## 边界说明：平台与合规

本体系内容围绕黄金（CFD）与加密合约展开，涉及"对赌盘""平台风控""分批出金"等操作。
**这类平台在中国大陆不受法律保护**，作者本人也承认"不敢说自己是做这个的"
"人家一听你做 CFD 就划入赌博范畴"。

因此：

- 直播内容中与平台规则绑定的部分（固定手数避免被标记、分批出金、双账号套利的封控风险）
  **不蒸馏为通用交易能力**，只作风险提示。
- 带单、喊单在中国境内违法（作者 2026.9.16 明确表态）。
- 本体系**不构成投资建议**。所有内容源自一位交易员在公开直播中的个人表述，
  其方法依赖个人主观判断且未经样本外验证。

| 缺口 | 影响 |

| "节奏"的判据缺失 | "方向对却被小周期打损"的排障无法闭合 |
| 攻防一体位 / 防守位 / 关键位 / 参考位无检查项 | 无法教用户识别位置，只能交付"要问什么" |
| "强弱转换"证据仅一处、判据缺失 | 只能作术语提示 |
| 仓位计算公式原文未给 | 卡片中的公式标为"实现约定" |
| 筹码分配的分层阈值原文未给 | 分层规则标为"实现约定" |
| 拆订单的样本量下限、频率阈值未给 | 无法判定拆出的条件是否稳定 |

| "动能减弱""回调过深""第一推动强度"未量化 | 动态离场与抓转折的判据依赖经验 |

## 怎么用这套体系

**如果只想记住一句话**：把交易当成算账的生意——**先算清你能亏多少，再决定做多少；
看不懂就不做；一笔单只有打止损或赚钱离场两个出口。**

**如果要动手改自己的做法**，按这个顺序：

1. **先做能立刻执行的三件事**：带止损、以损定仓、连损两次就停手。作者说这三件事做到，就爆不了仓。
2. **然后堵住最大的漏洞**：看不懂就不做（硬座闸门），起步点必须是健康订单。
3. **再建立可复现的基础**：固定主周期，只顺主周期。
4. **接着把经验变成数据**：拆订单回测——拆盈利找必要条件，拆亏损砍条件。
5. **最后才谈从小做大**：筹码分配，只做递减不做递增。

`references/capabilities/` 下对应的能力卡即可。
