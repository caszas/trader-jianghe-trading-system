## I — 方法论骨架（Interpretation）

这张卡回答一个决策：**别人带单、我跟不跟？** 作者给出的不是"挑一个好老师"的筛选法，而是三层递进的否决论证，任何一层成立都应拒绝把决策权交出去。

第一层是**法律**。作者把带单行为直接定性为违法，并据此推出：真正成熟、已有财富积累的交易员不会对风险敏感到去冒法律风险；愿意冒这个风险的人，多因缺钱或能力不足。这一层不看收益、不看人品，先看行为本身的法律属性。

第二层是**期望值**。带单若按分润收费，收益分配天然不对称：亏 100 两人同担，赚 100 带单方先抽成（原文举例抽 20），跟单方只拿 80。带单方"亏 100 赚 120"、跟单方"亏 100 赚 80"，同一笔服务的期望值被结构性压低。按时间收费同样是跟单方净流出。天下没有免费午餐。

第三层是**概率游戏**。盈利靠具备概率优势的系统长期反复执行，阶段性样本说明不了真实数据；典型情形是没跟之前曲线笔直向上，一开始跟单就撞上回撤、恐慌退出，之后带单者又起飞。根因不是故意坑人，而是胜率非 100%、人人都有亏损阶段，且跟单者无法与交易员逻辑同频、无法从第一单跟到最后一单不擅自调整。

结论是把决策权收回来：自己亏是技术问题（学艺不精），让别人帮你亏是判断力问题；回归"打铁还需自身硬"，把时间精力投在自己的系统建设上，而不是走捷径、躺着赚钱。

## A1 — 应用示例（Application Example）

### 示例 1: 水果生意老哥踩遍坑仍要带单（直播转述案例）
- **类型与来源**: 直播转述案例（reported_case，ep-2026.11.14 L1 / L13 / L25）
- **问题/输入**: 做水果生意一年赚三四百万的老哥，两年在市场亏 100 多万、又被割韭菜 100 多万；跟单、买指标、投量化、三天速成战法全部踩过。
- **方法论的使用**: 作者先识别其"已踩遍常见坑"，再听其诉求——"想走捷径、时间精力不够、不求多赚微微赚点"；对照三层论证：带单违法、收费使期望值为负、概率系统需长期执行且逻辑同频，判定这条路走不通。
- **结论**: 当场回绝带单请求，并劝其别做交易、回归生活。
- **结果**: 老哥未接受；原文未给该老哥的后续结果。

### 示例 2: 收到分润带单邀请的三层判断（合成演练）
- **类型与来源**: **合成演练**。素材只给规则、无带数值的完整成交案例；以下按原文规则复算，不冒充作者亲历，也无真实成交结果。分润"抽 20"取自 ep-2026.11.14 L87 与 ep-2026.11.10 L2513 的原话。
- **问题/输入**: 有人邀请跟单，赚了抽 20% 分润，亏损自负；跟单者自称"没时间盯盘，只想微微赚点"。
- **方法论的使用**:
 1. 法律层：带单在中国境内违法 → 命中否决项。
 2. 期望值层：亏 100 同担、赚 100 只到手 80，带单方赚 120 → 跟单方期望值被压低。
 3. 概率层：跟单者没时间盯盘，无法与交易员逻辑同频，也无法从第一单跟到最后一单不擅自调整；撞上回撤就会退出。
 4. 诉求核对："没时间精力、微微赚点"是想走捷径（ep-2026.11.14 L35）。
- **结论**: 三层均命中否决，拒绝跟单，回归自身能力建设。
- **结果**: 演练演算，无真实成交结果（未说明）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户收到带单/喊单邀请，问"要不要跟""这个能跟吗"。
2. 用户说"我没时间盯盘，想找人带我赚点"或"有没有自动赚钱的软件/量化躺赚"。
3. 用户在讨论分润、跟单收费、代打、共享账号等安排，问"这样划不划算"。
4. 用户跟了一段时间单，遇回撤就想退出，或中途擅自改单，问"是不是该跟下去"。
5. 用户问"别人亏了是技术问题，我跟别人亏算什么""带单的人自己靠谱吗，能不能托付"。
6. 用户想把自己从决策中抽离，把钱和单子交给别人打理。

### 语言信号（用户的话里出现这些就应激活）

- "跟单 / 带单 / 喊单 / 代打 / copy trade / follow trade"
- "能不能跟你 / 找人带 / 老师带单 / 跟大神做"
- "分润 / 抽成 / 交 20% / 时间收费 / 收费跟单"
- "没时间盯盘 / 躺赚 / 走捷径 / 微微赚点 / 自动印钞机"
- "曲线很漂亮，我跟了怎么就亏了 / 跟单回撤 / 中途能不能改单"
- "别人帮我亏 / 打铁还需自身硬"

### 与相邻能力的区分

- 与 `mentor-consistency-check` 的区别: 那张卡判断"某个博主/盘手值不值得学、手法是否一致、盘是真是假"；本卡不评估人的好坏，而是判定**任何带单/跟单安排本身不可行**，结论是拒绝而非打分。先有本卡的否决，才谈得上要不要评估人。
- 与 `invest-vs-speculate` 的区别: 那张卡判定"我买的是公司价值还是价格变化"；本卡判定的是**决策权归属**——单子由谁做。两者不重叠：投机也可以完全独立自主。
- 与 `setup-gate` 的区别: setup-gate 管单笔订单是否触发系统、能否进场；本卡管"要不要把整套决策交给别人"，是更早的前置立场。
- 与 `trade-system-build` 的区别: 那张卡讲怎么建自己的系统；本卡是它的否定面——拒绝外移决策权，把人推回"自己建系统"这条路。

## E — 可执行步骤（Execution）

**必需输入**: 带单/跟单邀请的具体形式（带单、喊单、代打、分润、时间收费、免费）；收费方式与比例；跟单者自身条件（能否投入时间精力、是否已有自己的系统）；跟单者与带单者逻辑是否同频、能否全程不擅自调整。信息缺失时先问："他怎么收费？你打算跟多久？你能不能全程按他同一套逻辑执行？"

**交付物与完成标准**: 一份**接受/拒绝的二值判断**，写明三层各自的判定与依据，并给出拒绝后的去向（回归自身能力建设）。完成标准：三层逐层给出结论，任一层命中否决即判"拒绝"；不输出任何带单/跟单的操作指引。

1. **法律层判定**
 - 确认该安排是否为带单/喊单。
 - 完成标准: 写明带单/喊单在中国境内违法、跟单不受法律保护，只作风险提示，不给操作指引。
 - 判停条件: 命中即判"拒绝"，转第 4 步。
2. **期望值层判定**
 - 核对收费方式：分润（原文举例抽 20）、时间收费或免费。
 - 完成标准: 按"亏全额同担、盈利被抽成"写出收益分配的不对称，判定跟单方期望值被压低。
 - 缺口标注: 原文未给分润比例的合理区间——按**实现约定**，不设"可接受比例"，任何分润/收费均判期望值为负。
3. **概率层判定**
 - 核对：能否从第一单跟到最后一单不擅自调整；能否与交易员逻辑同频；阶段性样本能否代表真实数据。
 - 完成标准: 明确写出"阶段性跟单无法验证真实数据、遇回撤易恐慌退出、不同频则拿不住"。
 - 缺口标注: 原文未给"长期"的时间标准——按**实现约定**，不折算为具体天数或单数，凡以"先跟一段看看"为诉求的均判为无法验证。
4. **给出结论并收口**
 - 完成标准: 输出"拒绝"；引用"自己亏是技术问题、让别人帮你亏是智商问题"与"打铁还需自身硬"，把去向落到自身能力建设，不提供替代的跟单方案。

**实现约定**: 本卡中"任何分润/收费均判期望值为负""凡'先跟一段看看'均判无法验证"是对原文缺口的执行口径；原文只给拒绝对策，未给比例阈值、时间阈值与无分润纯友情带单的量化结论，以上约定不改变"拒绝跟单、回归自身能力"的原意。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **用户只是想评估某个博主/盘手靠不靠谱**。那是 `mentor-consistency-check` 的活；本卡不给"挑人"的打分表。
- **用户问的是单笔能不能进、止损放哪**。交给 `setup-gate`、`stop-loss-mechanics` 等；本卡不判订单。
- **用户问的是"我这算投资还是投机"**。交给 `invest-vs-speculate`；本卡只管决策权归属。
- **当作带单/跟单的操作指引来用**。中国境内带单/喊单违法、跟单不受法律保护，本卡只作风险提示，不提供任何操作指引，也不构成投资建议。

### 作者警告的失败模式

- **分润的期望值陷阱**（ep-2026.11.14 L87、ep-2026.11.10 L2513）。陷阱：以为"赚了再分一点"很公平；机制：亏全额同担、盈利先被抽成，跟单方期望值被结构性压低；预警信号："赚了抽 20%""稳赚才收费""风险你自己担"。
- **阶段性跟单撞上回撤就退出**（ep-2026.11.14 L122）。陷阱：看到带单者曲线笔直向上才进场；机制：胜率非 100%，开始跟单恰遇回撤、恐慌结束，结束后对方又起飞；跟单者不同频、无法从头到尾不擅自调整；预警信号："他最近曲线太准了""跟了两单亏了就不跟了""中途自己改一下单"。
- **想走捷径、躺着赚钱**（ep-2026.11.14 L35）。陷阱：以"没时间精力、现实生意要处理、不求多赚"为由找人带；机制：概率优势系统需自身建立并长期执行，把决策权外移无法形成可复制能力；预警信号："没时间盯盘""微微赚点就行""为什么不做成自动印钞机"。
- **把亏损责任交出去**（ep-2026.11.14 L48）。陷阱：认为跟别人亏不算自己的问题；机制：钱从自己手里亏是技术问题，钱从别人手里亏是判断力/智商问题；预警信号："是他带我亏的""我自己的单没问题，跟单才亏"。

### 作者的盲点 / 时代局限

- **分润比例的合理区间原文未给**。原文只举"抽 20"的算例，未给任何可接受比例，不可据此反推"抽少一点就能跟"。
- **"长期"的时间标准原文未给**。未给跟多久才算长期、多少笔才算样本充分，不能自行折算成天数或笔数。
- **"逻辑同频"无判据**。原文只说"无法与交易员逻辑同频、无法从第一单跟到最后一单"，未给可观测的判定清单。
- **纯友情、不收费带单的量化结论原文未给**。原文只说无分润仍有其他风险，未给独立测算。
- **平台与合规语境**。内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护；带单/喊单在中国境内违法、跟单不受保护。此处仅作风险提示，不构成投资建议，不提供任何跟单/带单操作指引。

### 容易混淆的邻近方法论

- **交易博主手法一致性评估**（`mentor-consistency-check`）：它问"这个人值不值得学"，本卡问"要不要把决策权交出去"；前者可能得出"值得学"，后者仍对带单说"不"。
- **投资与投机判定**（`invest-vs-speculate`）：它按出发点区分买价值还是买价差，与本卡的决策权归属是不同维度。
- **交易系统构建**（`trade-system-build`）：它是本卡结论的落点——拒绝外移之后，回到自己搭系统、自己执行；不是同一层的方法。
- **找盘手合作/委托交易**：看似"委托"而非"跟单"，只要把下单决策交给他人，仍落在本卡的否决范围内。
