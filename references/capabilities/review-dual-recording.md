# 复盘双重记录（客观市场记录 + 主观决策记录）

## I — 方法论骨架（Interpretation）

复盘双重记录解决的是一个前置问题：**记账之前先记什么、怎么记，事后才有的比**。作者给出两个必须同时满足的前提。

第一，**双重记录并列**。每笔订单留下两套互不相干的记录：一套客观记录市场的真实状态，一套记录你当时的想法与决策；两者必须分开写，不能混。只有并列，事后才能拿"当时怎么想"去对"市场实际怎么走、结果如何"，定位问题出在哪一点。记录阶段只写事实，不写感悟、不写总结——复盘是记录之后的独立阶段。

第二，**先有一套可固定执行的系统**。再简陋也要有。只有按同一套规则重复输出，样本才具备一致性、才有统计价值；一致性是复盘能得出结论的前提。每笔凭灵机一动用不同方法，今天这么想明天那么想，样本就失去一致性，复盘看不出数据的真实情况，也看不出该优化、该规避什么。

两个前提是**并列关系**，不是二选一：没有系统，记录失去统计意义；没有双重记录，系统无从被检验与完善。

**分工**：本卡管记录契约——记什么、怎么记，才能事后对比定位问题；`review-scope` 管统计口径——什么算盈亏、概率损作成本、卖飞是假盈利。本卡是 `order-deconstruction-backtest` 的**上游**：先留下可比的双重记录样本，下游才能从样本拆必要条件、找共性、改一件事再回测。

## A1 — 应用示例（Application Example）

### 示例 1: 100 笔订单记录 → 事后对比锁定"左侧进场"主要问题
- **类型与来源**: 原书演示案例（数字为演示举例），ep-2026.10.22 L106、L110、L117、L121
- **问题/输入**: 作者演示记录 100 笔订单，其中 60 笔亏损。
- **方法论的使用**: 先有一致、可比的订单记录样本（本卡的双重记录是前置），再逐笔拆亏损原因、找共性，发现 60 笔亏损中 30 笔都因"左侧进场、到关键位就坐进去"。
- **结论**: 只有样本一致且客观/主观可对照，事后对比才能锁定"左侧进场"这一主要问题；它是下游"只改一件事、回历史盘面验证反馈"的输入。
- **结果**: 原稿为演示举例（100/60/30），未给真实成交结果。

### 示例 2: 一笔订单的双重记录并列 → 事后定位问题（合成演练）
- **类型与来源**: 原书未提供带字段的记录模板案例，以下为**合成演练**，仅演示"双栏并列→事后对比"的步骤，不代表作者亲历。
- **问题/输入**: 假设使用者按一套固定系统做了一笔单，并留下两栏记录。
- **方法论的使用**:
 1. 客观栏只写市场真实状态（时间、品种、关键位、进场/离场价、实际结果）；
 2. 主观栏只写当时的想法与决策（当时判断、进场理由、预期）；
 3. 记录阶段两栏都不写感悟、不写总结；复盘另列一阶段；
 4. 事后把两栏并排：若主观写"预期在关键位受阻做空"、客观显示"未到关键位就因回撤离场"，不一致处即为定位点——区分是判断问题还是执行问题。
- **结论**: 双重记录本身不直接给出"错在哪"，它提供可对比的素材；定位问题靠并列两栏的对照，结论再交给下游拆单复算。
- **结果**: 演练演算，无真实成交结果（未说明）。
- **缺口标注**: 上述客观栏/主观栏的**字段与保存格式原文未给**，均为**实现约定**、非作者原文，不得当作作者给定的模板。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户想做复盘，却不知道该记录什么、记成什么样才有用。
2. 用户记了很久的单子，事后却看不出问题在哪——记录里全是感悟和总结。
3. 用户把客观盘面和自己的主观想法混写在一起，事后无法对比"当时怎么想 vs 实际怎么走"。
4. 用户每笔凭灵机一动用不同方法下单，复盘时看不出数据的真实情况。
5. 用户还没有一套固定可执行的系统，就想直接开始复盘、做统计。
6. 用户拿到一份订单记录，想知道"这样记能不能支撑事后对比定位问题"。

### 语言信号（用户的话里出现这些就应激活）

- "复盘 / review / 事后看 / 回头看"
- "记录 / 记单子 / 交易日志 / journal / 记账"
- "客观记录 / 主观记录 / 双重记录 / 两套记录"
- "记录什么 / 怎么记 / 记录模板 / 字段怎么设"
- "复盘看不出问题 / 数据看不出来 / 记了等于没记"
- "先有系统 / 没有系统能复盘吗 / 一致性 / 每笔方法不一样"

### 与相邻能力的区分

- 与 `review-scope` 的区别: review-scope 管**统计口径**——复盘只统计实际成交结果（概率损作成本、卖飞是假盈利、什么才算数）；本卡管**记录契约**——记什么、怎么记，才能事后对比定位问题。一个是"什么算数"，一个是"记什么、怎么记"。先按本卡留下双重记录，再按 review-scope 的口径统计。
- 与 `order-deconstruction-backtest` 的区别: **上下游关系**。本卡是上游，产出客观/主观并列的一致性问题样本集；拆单是下游，从这些样本和历史订单拆必要条件、找共性、改一件事再回测。没有双重记录，拆单会把当时的主观想法和客观结果混在一起，结论失真。
- 与 `trade-system-build` 的区别: 后者构建可固定执行的交易系统，是本卡的**前置**。本卡要求"先有系统（再简陋也要有）"；系统缺失时样本无一致性，先回 trade-system-build 补系统再记录。
- 与 `emotion-three-step` 的区别: 情绪三步处理亏损之后"事实→感受→我要怎么做"的情绪动作，属动作层；本卡的主观记录是**决策当下**的思路与逻辑，属数据层，不是事后情绪日记。两者形似而用途不同。

## E — 可执行步骤（Execution）

**必需输入**:
- 每笔订单的**客观市场记录**（市场真实状态）。
- 每笔订单的**主观决策记录**（当时的想法与决策逻辑）。
- 一套**待验证、可固定执行的交易系统**（再简陋也要有）。
- 缺口标注: 客观记录的具体字段、主观记录的具体字段、保存格式，**原文未给**；若要落表，须写明所用字段为**实现约定**、非作者原文，不得脑补成作者给定的模板。

**交付物与完成标准**: 一份**双栏并列的订单样本集**——每笔同时有客观栏与主观栏、两栏分开写，且全部订单按同一套系统规则产出。完成标准：①客观与主观分栏、互不混写；②记录阶段不写感悟、不写总结，复盘列为记录之后的独立阶段；③样本由一致规则产出、具备可比性。

1. **确认前置系统**
 - 确认已有一套可固定执行的交易系统（再简陋也可）。
 - 完成标准: 能说清一套可重复的进场/离场规则。
 - 判停条件: 若没有系统 → 先回 `trade-system-build` 建系统，暂不进入样本累积。
2. **逐笔做客观市场记录**
 - 只记录市场的真实状态，单独成栏。
 - 完成标准: 该栏不含任何想法、感悟、总结。
 - 缺口标注: 客观栏字段**原文未给**（实现约定：可含时间、品种、关键位、进场价、离场价、实际结果，均为实现约定、非作者原文）。
3. **同时逐笔做主观决策记录**
 - 另起一栏，只记录当时的想法与决策逻辑。
 - 完成标准: 该栏只写"当时的思路与逻辑"，不写事后感悟。
 - 缺口标注: 主观栏字段**原文未给**（实现约定：可含当时判断、进场理由、预期，均为实现约定、非作者原文）。
4. **两栏并列、记录与复盘分离**
 - 完成标准: 客观与主观两栏并列对照；记录阶段不写感悟、不写总结（ep-2026.3.23 L0131）；复盘是记录之后的独立阶段。
5. **以一致规则重复输出**
 - 所有订单按同一套系统规则产出，使样本具备统计价值（ep-2026.10.21 L872、ep-2026.10.22 L54、L56）。
 - 判停条件: 若每笔用不同方法、灵机一动（ep-2026.10.22 L58、L59、L62）→ 样本无一致性、复盘看不出真实数据，回到步骤 1 先固定系统。
6. **事后对比定位问题**
 - 完成标准: 用并列两栏指出问题所在点（客观与主观不一致处、反复出现的偏差）；把样本集交给下游 `order-deconstruction-backtest` 拆共性，并注明"系统"的最低完备度原文未给、由使用者自定。

**实现约定**: 上述"客观栏/主观栏字段""保存格式"以及步骤中的栏位设置，原文**均未给**，均属**实现约定**，不改变"客观+主观双重记录并列、先有可固定执行的系统"这一原意。使用者须自行写明所用字段并披露。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **没有固定系统就想靠记录直接复盘时**。先有可重复执行的系统（再简陋也可）；每笔方法不一致的样本没有统计意义，复盘看不出真实数据（ep-2026.10.22 L58、L59、L62）。
- **把主观决策记录写成情绪日记或感悟总结时**。记录就是记录，不写感悟、不写总结（ep-2026.3.23 L0131）；情绪处理归 `emotion-three-step`，不在本卡的记录阶段做。
- **把它当成统计口径时**。本卡不决定"什么算盈亏"——那是 `review-scope` 的职责；本卡只管记什么、怎么记。
- **把它当成给主观想法找事后合理化的工具时**。双重记录是为了暴露"当时怎么想 vs 实际怎么走"的差距，不是为了让主观叙事自圆其说。

### 作者警告的失败模式

- **灵机一动式记录**（ep-2026.10.22 L58、L59、L62）。陷阱：这单用这个方法、那单用另一个方法，今天这么想明天那么想。机制：输出不一致 → 样本无一致性 → 复盘看不出数据真实情况、看不出该优化与规避什么。预警信号："这单用这个方法、那单用另一个方法""今天这么想明天那么想"。
- **在记录里写感悟、写总结**（ep-2026.3.23 L0131）。陷阱：把记录和复盘混成一阶段。机制：记录阶段被主观总结污染，事后失去可对比的客观素材。预警信号："记一下今天的心得""顺手写个总结"。
- **只记结果、不记当时的决策**（双重记录缺了一栏）。陷阱：客观结果有、主观想法缺。机制：事后能看见盈亏，却无法定位"当时的判断错在哪"。预警信号："结果我记了，当时怎么想的我没写"。

### 作者的盲点 / 时代局限

- **记录模板字段与保存格式原文未给**；"先有系统"的最低完备度也未定义。使用者须自定并披露，不可把实现约定的字段冒充作者原话。
- **"客观记录"的客观性无判据**。什么算客观、如何避免主观混入，原文未给，只能靠使用者自律区分。
- **"先有系统"与"复盘完善系统"相互依赖**。系统未建时样本无价值，系统建好后复盘才有用；这个循环如何从零启动，原文未说明。
- **引文"事后对比书看出问题"中的"对比书"疑为转写讹误**（应为"对比"），本卡照录原文，不擅改。
- **标的与平台语境**。内容围绕黄金 CFD 与加密合约；这类平台在中国大陆不受法律保护，行情与滑点条件下"客观记录"的可信度可能下降。内容不构成投资建议。

### 容易混淆的邻近方法论

- **传统交易日志**（只记盈亏与技术位）：本卡要求客观与主观并列，缺一栏就无法事后对比定位问题。
- **情绪日记**（`emotion-three-step`）：那是亏损后处理情绪的动作层；本卡的主观记录是决策当下的思路与逻辑，不是事后情绪。
- **`review-scope` 的记账口径**：那是"什么算数"，本卡是"记什么、怎么记"；两者先后衔接，不可互相替代。
