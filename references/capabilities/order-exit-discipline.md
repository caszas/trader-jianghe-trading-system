# 订单出口纪律（只有打止损或赚钱离场）

## R — 原文（Reading）

> 在我那个订单逻辑里 / 要么就是成本打掉 / 打掉我止损 / 要么就赚钱离场

— 交易员江河，ep-2026.7.17 L00509–L00514

---

> 手动止损你执行99次 / 犹豫一次你都输

— 交易员江河，ep-2026.9.10 L02461

---

## I — 方法论骨架（Interpretation）

一笔订单的出口是封闭集合，只有两个元素：**打掉止损**，或**赚钱离场**。没有第三个选项——不存在"没打到止损但浮亏了所以先割掉"。割肉不是"控制风险"，而是把一笔尚未被证伪的单，用情绪提前结账。

与之配套的还有一条容易被忽略的禁令：**不推保本**。一根 K 线不足以否认进场逻辑时，就不该把止损推下去把单子变成"白玩"。只有行情走出转折、走出新的发力，止损才有资格跟着移动。

"带止损"是这一切的底线。带了止损，即使抛硬币做单也很难亏完；不带止损，用什么逻辑都救不了，也就没有资格来问"能不能上去"。作者由此强烈反对手动止损：执行 99 次，犹豫一次就输，而且一次犹豫会带来下一次犹豫——意志力是消耗品。

需要澄清的是：出口的合法性看的是"进场逻辑有没有被否认"，不是账户此刻浮亏多少、浮盈多少。割不割由逻辑决定，不由盈亏决定。至于"已经偏离预期、已经浮亏被套"这种状态该怎么处置，是另一件事——本能力负责的是"哪些出口是允许的"，不负责"偏离之后怎么判"。

补充判据（止损的定性）：止损是**中性的风险控制手段**，不是贬义词；亏损是概率游戏中的必然成本，不是失败。原文："止损呢从来不是贬义词 而是中性的风险控制手段 亏损呢也从来不是交易里的失败 而是概率游戏中的必然存在成本"（ep-2026-03-16 L0086、ep-2026-04-09 L2762）。由此推出两条纪律：① 任何订单必须设止损，绝不做"不设止损 / 重仓梭哈"（ep-2026-08-01 L485，原文"从来绝对见不到我不设止损的……我也并不是那种什么不带止损呐 或者说是什么啊重仓梭哈呀 这种的"）；② 剥头皮要"贴脸止损"，大止损"只设一半"（分段损），被扫损后可再进，但不可不设。

## A1 — 应用示例（Application Example）

### 示例 1: 浮盈回吐 1 万仍继续持有
- **类型与来源**: 原书亲历案例（ep-2026.7.17 L00477–L00483）
- **问题/输入**: 作者一笔订单浮盈最高到 1 万 5，随后回吐 1 万只剩 5000，是否应该离场。
- **方法论的使用**:
 1. 检查出口集合：当前既没有打掉止损，也没有到"赚钱离场"的条件（逻辑未被否认）
 2. 检查是否存在"浮盈变少了所以要落袋"的冲动 → 该冲动不构成合法出口
 3. 检查是否要推保本 → 一根 K 线不足以否认逻辑，不推
 4. 结论：继续持有，等出口条件触发
- **结论**: 不因浮盈回吐而提前离场。
- **结果**: 继续持有（原文未说明最终结果），作者原话是"我不也该拿还拿嘛 / 就在那扔着吗"。

### 示例 2: 学员"单子捏不住"
- **类型与来源**: 转述案例（ep-2026.9.24 L02587–L02600）
- **问题/输入**: 学员问自己有些单捏不住，比如某位置进的单子很快就平掉了。
- **方法论的使用**:
 1. 追问离场理由：学员说不出"逻辑被否认"或"已赚钱"的具体条件
 2. 判定：这不是出口纪律问题，是"没有明确的离场逻辑"——离场动作来自感觉而非规则
 3. 给出修复方向：先构建明确离场逻辑（见 `dynamic-exit`、`exit-choice-tradeoff`），再回来谈出口
- **结论**: 捏不住单的根因是没有明确离场条件，不是心态差。
- **结果**: 作者建议先构建交易系统与明确离场逻辑（未说明后续）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户持仓浮亏，问"要不要先割掉/减一部分"。
2. 用户说"我想把止损推到保本，这样就不亏了"，问行不行。
3. 用户抱怨"每次都被扫损，我想改成手动止损/不带止损"。
4. 用户问"我这个单子算不算被套了""要不要扛一扛"。
5. 用户账户里已经有浮亏的单，想给它找一个"体面离场"的理由。

### 语言信号（用户的话里出现这些就应激活）

- "要不要先割掉 / 先减一点 / 止损掉一部分"
- "我想推保本 / move stop to breakeven / 白玩走"
- "我想改成手动止损 / 不带止损 / manual stop"
- "这单被套了 / 扛一扛 / 有没有救"
- "exit discipline / 出口 / 离场规则"

### 与相邻能力的区分

- 与 `trapped-order-triage` 的区别（**最容易混**）: 本能力管"**出口合法性**"——回答"哪些离场方式是允许的"，答案是二值的：打止损或赚钱离场，割肉与推保本都不合法。trapped-order-triage 管"**已经偏离预期时怎么处置**"——当单子确实被套、浮亏已经发生，判的是"逻辑是否被否认、该不该走"。前者是规则，后者是排障；先有出口规则，才谈得上"偏离预期"这种状态（有止损的单不会进入被套态）。
- 与 `dynamic-exit` 的区别: dynamic-exit 是"赚钱那一侧"的离场机制（动能不延续就走）；本能力是"两侧的边界约束"，规定赚钱侧也不能用静态止盈去硬控。
- 与 `stop-loss-mechanics` 的区别: 本能力只规定"止损被触发就走、不被触发不割"，不规定止损怎么移动；移动止损的规则归 stop-loss-mechanics。
- 与 `position-sizing-by-stop` 的区别: position-sizing-by-stop 产出止损位；本能力保证这个止损位在持仓期间不被情绪替代（既不提前割，也不临时挪）。

## E — 可执行步骤（Execution）

**必需输入**: 持仓方向与进场价；初始止损价（逻辑否认点）；当前价；这笔单的进场逻辑（一句话）；用户当下的离场冲动及其理由。缺失进场逻辑或止损位时，先回到 `position-sizing-by-stop` 补齐，否则本流程无输入。

**交付物与完成标准**: 输出一份**出口判定** —— `当前出口类型`（打止损 / 赚钱离场 / 无出口，继续持有）、`判定依据`、`被拒绝的非法出口`及其理由。完成标准：出口类型只能取上述三个值之一；若判定为"继续持有"，必须同时写明"触发出口的条件是什么"。

**实现约定**: 原文给出的是出口的**二值规则**（打止损或赚钱离场），未给出"赚钱离场"的具体量化门槛，也未给"一根 K 线不足以否认逻辑"的精确判据。本卡把"赚钱离场"的判定交给 `dynamic-exit`，把"一根 K 线"的口径标为**实现约定**：至少需要一根收盘确认的转向 K 线，或一根打破最近防守位/发力点的 K 线，二者之一。

**补充（新材料）**: 止损的形态按场景区分——剥头皮用"贴脸止损"（离进场价极近）；大止损"只设一半"（分段损），即把计划止损拆成两段、先设其中一段（ep-2026-03-16 L0086）。原文未给"一半"的具体比例与两段的间距（**原文未给**，需使用者自行设定）。

1. **确认出口规则已就位**
 - 完成标准: 这笔单有明确止损价（挂在逻辑否认点），且有进场逻辑的一句话表述。
 - 判停条件: 若没有止损位 → 终止本流程，回到 `position-sizing-by-stop`，不要在本流程里补一个"临时止损"。
2. **检查是否触发打止损**
 - 完成标准: 当前价是否触及/穿越止损价，给出是/否。
 - 判停条件: 若是 → 出口 = 打止损，**立即执行，不再评估其他**，跳到步骤 6。
3. **检查是否满足赚钱离场**
 - 完成标准: 按 `dynamic-exit` 的动能/节奏判定给出是/否。
 - 判停条件: 若是 → 出口 = 赚钱离场，跳到步骤 6。
4. **拦截非法出口**
 - 完成标准: 逐条检查是否存在"未打止损但想割肉""想推保本""想改手动止损""想扛单等解套"的冲动，并写明每一条为什么被拒（不属于出口集合 / 一根 K 线不足以否认逻辑 / 意志力是消耗品）。
5. **输出"继续持有"及其触发条件**
 - 完成标准: 写明"价格走到哪里、或出现什么结构/K 线，我才离场"。
6. **记录出口**
 - 完成标准: 写下最终出口类型、时间、价格与理由；若是被拒的非法出口，一并记下被拒理由，供复盘口径使用。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **订单已经处于被套状态时**。这时第一步不是查出口规则，而是走 `trapped-order-triage`：先判逻辑是否被否认。本能力假定"带止损"这一前提成立，前提不成立的单子不适用。
- **被动平仓场景**（平台停盘、合约到期、强制减仓）。这些不是"出口选择"，本能力无法覆盖。
- **用它为"不止损硬扛"背书**。本能力说"不割肉"，前提是"止损已经在场"；把"不割肉"读成"不认错"是反向误用。

### 作者警告的失败模式

- **被套扛单 / 补仓解套**（ep-2026.8.14 L01344–L01349）。陷阱：不带止损、被套后补仓扛单，指望价格回来解套；也指卖飞/错过之后转为扛单或无限试单、一路抄底。机制：做多的前提是认为它会涨，它没涨就说明进场逻辑已被否认；不认错、舍不得止损成本、怕损了再回来，就会越补越多、越扛越深。预警信号："我补补仓一下子就回来了""某某价位的多有没有救""我不想止损""怕损了再回来"。
- **止损借口 → 取消止损**（ep-2026.8.14 L01367–L01379）。陷阱：以"浮亏不算亏""止损会被狗庄扫走"为由取消止损，自作聪明地把问题"解决"掉。机制：把可承受的常规成本换成不可逆的爆仓风险；能赢 99 次，输一次就下不了桌。预警信号："浮亏不算亏""脑袋一转就不设止损""我害怕我止损都给狗庄赚了"。
- **改用手动止损**（ep-2026.9.10 L02461）。陷阱：从严格止损改为手动止损。机制：意志力是消耗品，市场反复刺激，犹豫一次就输，且会形成连续犹豫。预警信号："手动止损""屡屡破止损线"。
- **不设止损 / 手动点叉**（ep-2026-04-09 L2760）。陷阱：因嫌麻烦或自恃手速快，进场后不设止损、打算手动点叉平仓。机制：原文"这个是大忌啊 这个是大忌 不要不设止损"——进场后第一件事就是拉止损；手速不行、设不了止损的人直接做不了剥头皮。预警信号："我手速快，不设止损手动点叉""进场先不拉止损"。
- **不设止损 / 心理止损**（ep-2026-10-01 L37、L60）。陷阱：认为"只要我不设止损我就不亏、浮亏不算亏"，或声称"我在心理止损了"。机制：这是掩耳盗铃、自欺欺人——风险被无限放大，可赢 99 次但输 1 次就被清下牌桌；"心理止损"不可控、不可复制、模糊，且亏损过多时沉没成本会让你无法割肉，无法长期执行。预警信号："不设止损就不亏""浮亏不算亏""我在心理止损"。

### 作者的盲点 / 时代局限

- **"打止损或赚钱走"是二值规则，未覆盖灰色地带**：如部分减仓、分批离场。作者自己在实盘中用过"两笔半仓""先清半仓"的做法，规则表述比实操更绝对。
- **"一根 K 线不足以否认逻辑"未量化**，实际操作中"这根算不算"仍靠主观判断。
- **前提依赖以损定仓**：若使用者根本没有止损位，本能力的全部约束落空；作者把这类人直接判为"赌狗"，但没有给"从零建立出口纪律"的过渡路径。
- **标的与平台语境**。内容围绕黄金 CFD 与加密合约，作者自承数据行情滑点极大，"按价成交"的假设会失效；这类平台在中国大陆不受法律保护，作者本人也承认"不敢说自己是做这个的"。全篇不构成投资建议。

### 容易混淆的邻近方法论

- **"止损就是用来被扫的"**：那是承认概率损是成本；本能力说的是"被扫就走、不被扫就不走"，不是"故意去送止损"。
- **"浮盈落袋为安"**：那是把浮盈回吐当亏损；本能力明确不因回吐提前离场（见示例 1）。
