# 投资与投机判定

## R — 原文（Reading）

> 那就是如果这家公司明天宣布退市5年内不再上市你今天还敢不敢按照这个价格买入...如果你是想低买高卖赚取价格的变化不论你持有了多长时间那你都是投机

— 交易员江河，ep-2026.5.29 L415

## I — 方法论骨架（Interpretation）

这张卡回答一个判定问题：**我到底是在投资，还是在投机？** 作者给两条判据。

**判据一——退市测试。** 假设这家公司明天宣布退市、5 年内不再上市，你今天还敢不敢按这个价格买入？敢 = 你买的是**公司的一部分**（靠公司未来利润与分红回本）= 投资；不敢 = 你买的是**价格变化** = 投机。

**判据二——出发点。** 只要你是想"低买高卖赚取价格的变化"，不论持有多长时间，都是投机。

**核心：区别不在持有时间。** 长期持有 ≠ 投资；被套了不卖 ≠ 投资。判据只看出发点——买的是公司价值，还是价格波动。把时间长短当判据是这条方法最常被误用的地方。

**在交易语境里的用途。** 作者是在界定自己做的事：交易赚的就是价格变化，因此本质是投机；不要用"长期持有"给自己贴投资的标签。这条判定也解释了为什么交易的核心是"成本可控、收益由市场决定"（见 `controllable-cost-exchange`）——投机赚的是价格差，不靠公司分红。

## A1 — 应用示例（Application Example）

### 示例 1: 用退市测试判定"长期持有"（合成演练）
- **类型与来源**: 素材仅 1 条、无完整原始案例，以下为**合成演练**（依据 ep-2026.5.29 L415）
- **问题/输入**: 某人以"看好这家公司、打算拿 5 年"为由买入某股票。
- **方法论的使用**: ①做退市测试——若这家公司明天退市、5 年不上市，你还敢按这个价买吗？②若答案是"不敢"、其实心里想的是涨了卖掉 → 按出发点判据，无论计划持有多久，都是**投机**。
- **结论**: 持有时间长不改变判定；动机是赚价格差 → 投机。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户问"我这算是投资还是投机"。
2. 用户说"我打算长期持有，所以我在投资"。
3. 用户问"被套了不卖，是不是就变成投资了"。
4. 用户想给一个赚价格差的交易贴上"投资"的标签。

### 语言信号（用户的话里出现这些就应激活）

- "投资还是投机 / invest or speculate"
- "长期持有就是投资 / 拿几年算投资吗"
- "被套了不卖 / 装死 / 熬回来"
- "低买高卖 / 赚价差"

### 与相邻能力的区分

- 与 `growth-path` 的区别: 那张卡讲成长与学习的阶段（先活下去→积累财富→守财）；本卡是一个**界定性**判定，用来分清自己在做哪类事，本身不产出阶段动作。
- 与 `capital-and-reserve` 的区别: 那张卡管"入金多少、留多少备用金"；本卡管"这笔买入的出发点是什么"。两者都属入金/买入前的前置判断，但一个算金额、一个定性。

## E — 可执行步骤（Execution）

**必需输入**:
- 买入理由（是看重公司价值/分红，还是想赚价格差）。
- 一个可回答的"退市测试"问题（标的有无对应概念，见 B 段）。

**交付物与完成标准**: 输出一个**二值判定**——"投资"或"投机"，并写明依据是哪条判据。完成标准：判定不依赖持有时间长短。

当能力被激活后，agent 应按以下步骤执行：

1. **做退市测试**
 - 完成标准: 问"若该标的明天退市、5 年内不再上市，你还敢按此价买入吗"，得到"敢/不敢"。
2. **问出发点**
 - 完成标准: 明确用户是想赚公司利润/分红，还是想低买高卖赚价差。
3. **给二值结论**
 - 完成标准: 敢 + 买公司价值 → 投资；否则（含"不论持有多久、想赚价差"）→ 投机。
4. **排除时间干扰**
 - 完成标准: 明确写出"持有时间长短不影响判定"，纠正用户可能的时间锚定。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **拿持有时间当判据时**。作者明确：不论持有多长时间，想赚价格变化就是投机。
- **把"被套不卖"当成投资时**。被动持有不改变出发点，不构成投资。
- **当成投资建议或标的推荐时**。本卡只做定性判定，不评估任何标的的好坏。

### 作者的盲点 / 时代局限

- **"公司价值如何评估"原文未给**。原文只给判定口径，未给"未来利润与分红怎么算、值不值这个价"的方法。
- **混合动机未讨论**。现实中"既看价值、又想赚价差"的情况很常见，原文未给判定规则。
- **退市测试的适用面**。该测试以"公司退市"为前提，直接适用于股票；迁移到黄金、加密等无现金流标的时，"退市测试"需改造（如"若该标的 5 年无法卖出/无法变现，你还敢按此价持有吗"），原文未涉及此类标的。全篇不构成投资建议。

### 容易混淆的邻近方法论

- **"长期持有 = 投资"的通俗说法**：本卡明确反对——持有时间是表象，出发点才是判据。
- **价值投资 vs 趋势交易**：这是两种风格标签；本卡不评价风格优劣，只判定"买的是价值还是价差"。
