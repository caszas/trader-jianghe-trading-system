## I — 方法论骨架（Interpretation）

关键位被"打破"之后，价格是继续走还是收回去，作者用两个条件来区分真突破与假突破：

1. **实体拉出距离**：突破那一根K线的实体要走出去 50% 以上（引线也算进去），即"拉开的距离"够不够；
2. **第二根跟随**：紧随其后要有一根沿同方向的 K 线跟随（延续）。

两条都满足，视为真突破，此位"彻底不去考虑"；两条都没走出来、直接往回收，视为假突破。若证据互相矛盾（算影线没到 50%、只算实体又打开了一段），谨慎的处理是不做，把它当作"啥也不是"的第三种状态，等价格回到上方或走出延续再定。

还有一个硬性前提：突破单必须是**双周期**——主周期定方向，次周期找进场，绝不做单周期的突破。假突破本身也有信息量：它对防守位起到"消耗"作用，可关注后续的右侧或共振机会。

### 补充判据（新材料并入）

**以实体为准，影线不算**（ep-2026.7.27 L407、ep-2026.7.28 L90）：判突破关键位时以实体 K 线为准，影线扫过视为假突破。这是对"实体拉出 50%"的前置限定——连实体都没过，直接归假。原文未给实体收盘需超出关键位的幅度标准。

**二次确认法过滤假突破**（ep-2025.11.9 L78、L137）：大周期 K 线打破关键节点时，切到小周期等一个结构型（N 字）突破的二次确认；小周期成功打破并收 K 后进场；若小周期始终无二次确认，则判为假突破、不进场。原文未给大小周期的具体搭配（如 5 分钟配 1 小时）。

**双突破四要点**（ep-2025.12.12 L57、L167）：真突破需满足——①突破后价格与原有空间拉开一定距离；②有连续跟随（连续同向 K 线、不立刻收回）；③K 线持续站在均线一侧多根；④回调未拉回原空间。满足则视为真突破、可跟随。原文未给"拉开距离"与"持续多根"的量化标准。

**顺势优先**（ep-2025.11.9 L255）：做突破订单尽量顺势（顺市场明确方向），成功可能性大于对抗市场方向；逆势突破订单尽量放弃。

**窄幅突破优先**（ep-2026.7.28 L19；ep-2026.7.29 L204；ep-2026.7.30 L508）：横向距离窄（构成时间短）的窄幅突破＝挤压式突破，能量强；宽幅突破能量弱，应放弃。用于筛选高胜率突破单。原文未给窄/宽幅的量化宽度或时间阈值。

**结构型突破与震荡型突破的执行形态**（新材料并入，属进场流程）：结构型——大周期画 N 字形并标前高关键位 → 等价格到关键位切小周期 → 小周期创高点后画水平线 → 等回落再突破该水平线时进场 → 止损放 N 字形极值点 → 拿一比一盈亏比（ep-2026.7.29 L86、L102、L122）。震荡型三模型——①常规震荡突破（突破上/下沿后小周期 N 字形再破前高进场）；②宽幅震荡压缩成窄幅震荡后按①逻辑进场；③假突破（突破后未回踩未延续、反向形成 N 字形，反手做）（ep-2026.7.29 L300、L448、L585）。原文未给"宽幅/窄幅震荡"的量化边界与"突破"需实体还是影线的明确要求（其他课提到实体）。

## A1 — 应用示例（Application Example）

### 示例 1: 8.10 低多订单——"扣0"还是"扣2"
- **类型与来源**: 原书演示（ep-2026.8.10 L0496–L0538）
- **问题/输入**: 当天唯一有逻辑的低多订单，作者让学员标注做在哪个位置（前面坐上扣 0、后面坐上扣 2）。
- **方法论的使用**: 做 0 是"打破+回抽"前的左侧位置，太左、不是他的风格；做 2 是"打破+回抽"之后、结构已走出右侧的位置。判断"2"是否成立，要看这一段是不是"把之前的下跌看成趋势"与"顺势空被打破、反转二推不破"两个逻辑的重合处。
- **结论**: "2"是最佳位置（打破+回抽后、成本不高的一段都合理）。
- **结果**: 多数人扣 2；作者认为"二"最佳（原书交代）。

### 示例 2: 8.3 同样是"吞没"信号，两处结果相反
- **类型与来源**: 原书演示（ep-2026.8.3 L1216–L1226）
- **问题/输入**: 图上两处都出现"吞没"信号，学员问为什么结局不同。
- **方法论的使用**: 不单看信号本身，要看它是否满足"拉出距离 + 跟随"，以及它出现的位置是否与方向一致——一处稍微浮盈就被套死，一处就盈利。
- **结论**: 单看信号没有意义，必须结合方向与位置做组合判断；突破判定同样要落到"位置 + 双周期"上。
- **结果**: 原书为假设演示，未说明实际成交结果。

### 示例 3: 2025-12-12 突破 + 趋势追踪空单（双突破，盈亏比 4.92）
- **类型与来源**: 作者亲历实盘（ep-2025.12.12 L57、L167、L486）
- **问题/输入**: 价格脱离宽震荡空间。
- **方法论的使用**: 价格与原有空间边缘拉开距离、有连续阴线跟随、K 线站均线下方多根（双突破），判为真突破并看空延续；第二根阴线收 K 进场，止损放上方；回踩"攻防一体位"加仓一笔；到关键区域"二推不创新低"即离场。
- **结论**: 满足"拉开距离 + 跟随 + 站均线一侧"即按真突破跟随。
- **结果**: 作者自述该单盈亏比 1:4.92。原文未给"拉开距离"的量化标准。

### 示例 4: 2025-12-23 突破回踩空单（加仓 + 部分止盈）
- **类型与来源**: 作者亲历实盘（ep-2025.12.23 L133、L286、L339）
- **问题/输入**: 盘前判断主趋势下跌、次趋势为回调。
- **方法论的使用**: 窄震荡空间向下突破后，等第二根 K 线跟随确认（收弱阳线）做回调空单，仓位很轻、止损放前高；价格回成本区收阴线加仓；到起涨点先平部分仓位（因阴线延续性强），剩余仓位止损下移保护利润。
- **结论**: 突破回踩单用"第二根跟随"确认，加仓与止盈分批处理。
- **结果**: 作者亲历（原文未给加仓与部分止盈的比例）。

### 示例 5: 小黄鱼一小时突破 → 5 分钟二推不破做多并加仓
- **类型与来源**: 作者亲历实盘（ep-2026.4.12 L0094）
- **问题/输入**: 一小时强势突破 + 跟随。
- **方法论的使用**: 建立做多偏向；切 5 分钟等浅回撤 + 二推不破进场，止盈目标设一小时前高实体；进场后差一点被扫损，价格回到成本区又出现更强的进场理由（大实体阳线），于是加仓，并把两笔止损止盈统一预设。
- **结论**: 一小时突破定偏向，5 分钟找进场；成本区出现更强理由可加仓。
- **结果**: 作者自述有惊无险止盈（原文未给盈亏数值）。

### 示例 6: 10 分钟多单赚 26000 美金（碾压式突破）
- **类型与来源**: 作者亲历实盘（ep-2026.6.30 L95、L192）
- **问题/输入**: 5 分钟主周期、1 分钟细化进场。
- **方法论的使用**: 空头最近发力点被多头打掉并有明确跟随（第二根仍收强阳），判为"碾压式突破"（区别于消耗式）、加分项高；价格回抽后微弱回调被否认（强弱强），进场拿第二推动利润。
- **结论**: 强跟随 + 打掉发力点 = 碾压式突破，是加分项。
- **结果**: 作者自述 10 分钟左右浮盈超 3 万美金，到预期位上移止损离场；并强调这种高盈亏比是小概率事件。

### 示例 7: 结构型突破两个实盘案例
- **类型与来源**: 作者亲历实盘（ep-2026.7.29 L88、L136、L153）
- **问题/输入**: 15 分钟 N 字形到前高关键位。
- **方法论的使用**: 切一分钟观察 → 一分钟回落再突破前高时进场 → 止损放 N 字形极值点 → 拿一比一。
- **结论**: 结构型突破按"到关键位切小周期、回落再破前高进场"执行。
- **结果**: 作者自述两单均顺利止盈（原文未给具体盈亏金额）。

### 与相邻能力的区分

- 与 `key-level-reading` 的区别: `key-level-reading` 负责"位在哪、是什么角色、还准不准"；本能力只在"位已经被打破"之后启动，判定这次打破是真是假。
- 与 `range-market-playbook` 的区别: 震荡区间边缘的"假突破"判定属于本能力；把上下两沿组织成高空低多的操作框架属于 `range-market-playbook`。两者常配合：区间边缘先做真假判定，再决定是否反向。
- 与 `entry-model-taxonomy` 的区别: 本能力产出"真/假/啥也不是"三态；`entry-model-taxonomy` 把进场位置分成左中左、右中右等模型，并区分左侧要点位优势、右侧只帮你少亏。
- 与 `trend-definition` 的区别: 本能力判定"突破"本身；`trend-definition` 判定"打破之后有没有走出结构延续"，即方向是否真正改变。
- 与 `necessary-conditions` 的区别: 本能力判"突破"这一个动作的真假；necessary-conditions 判定"下单还差哪些必要条件"，真假突破只是其中一条输入。

## E — 可执行步骤（Execution）

**必需输入**: 被打破的关键位价格（或区域边界）；主周期与次周期设定；突破那一根及之后至少一根 K 线的数据（开/高/低/收）；突破方向相对市场主趋势（顺/逆）；突破形态的横向宽度/构成时间（窄/宽）。
**交付物与完成标准**: 三态判定之一——`真突破` / `假突破` / `啥也不是`，并附判定依据（是否拉出 50%、是否有第二根跟随）与后续动作。

当能力被激活后，agent 应按以下步骤执行：

1. **确认关键位与周期配置**
 - 完成标准: 写出被打破的关键位价格、主周期、次周期；主次周期不同（双周期）才算配置完成。
 - 判停条件: 若用户只看单周期（如仅一分钟）→ 先补齐主周期，否则本流程不启动。
2. **量取实体拉出距离**
 - 完成标准: 给出"实体超出关键位的距离"与"参照段长度"的比值，判断是否 ≥ 50%（引线计入）。
3. **检查第二根跟随**
 - 完成标准: 明确第二根 K 线是否沿同方向收出实体（跟随/不跟随），并写出该 K 线的方向与收盘位置。
4. **给出三态判定**
 - 完成标准: 两条件均满足→真突破；两条件均不满足且直接收回→假突破；证据互相矛盾→"啥也不是"。
 - 判停条件: 若判为"啥也不是" → 停止追单，等价格回到上方或走出延续再重新走本流程。
5. **输出后续动作**
 - 完成标准: 真突破→按双周期在次周期找进场；假突破→可关注反向与防守位"消耗"后的右侧/共振机会；两者都要写明失效条件。
6. **实体确认（前置）**
 - 完成标准: 判定突破当根是否为实体收过关键位；若仅影线扫过 → 直接归假突破，不再走后续。
7. **二次确认（可选强化）**
 - 完成标准: 大周期打破关键节点后，到小周期等一个 N 字形结构突破的二次确认；小周期成功打破并收 K → 进场；始终无二次确认 → 判假突破、不进场。（大小周期搭配原文未给，为**实现约定**）
8. **顺势与宽窄筛选**
 - 完成标准: 优先顺势突破、优先窄幅（挤压式）突破；逆势或宽幅突破标为"放弃/少做"。（窄/宽幅量化阈值原文未给，为**实现约定**）

**实现约定**: 原文明确"50% 相对哪一段量取、适用于哪个周期、跟随的 K 线根数、不同品种是否相同"均未给出；本卡的"50% 阈值""第二根跟随（1 根）"为**实现约定**，取值不改变"拉出距离 + 跟随 = 真，二者皆无 = 假"这一原意。新材料补充："实体为准（影线不算）""顺势优先""窄幅优先""小周期 N 字形二次确认"均为原文判据（ep-2026.7.27、ep-2025.11.9、ep-2026.7.28），其量化边界（大小周期搭配、窄/宽阈值）原文未给，本卡取值属**实现约定**。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **只在单周期上做突破**。作者明确"绝不做单周期突破"，必须双周期；单周期判定等于没有方向过滤。
- **把"啥也不是"硬判成假突破**。证据矛盾时应选择不做，而不是胆大地当假突破反向操作。
- **用它给"第一次转向就进场"背书**。第一次转向常是欺骗性行为，不能因"看着像突破"就提前进（见 ）。
- **平台与合规语境**。本内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护，作者本人自承"不敢说自己是做这个的"。本能力是盘中形态判定，不构成投资建议，也不适用于受监管市场的合规下单。

### 作者警告的失败模式

- **第一次转向就进场**（ep-2026.8.5 L0496–L0502）。陷阱：在第一次转向时就进场做空/做多。机制：第一次转向常是假动作、欺骗性行为，因为结构太强、很难一次被喂下去，所以"等彻底转向再折腾"。预警信号："第一次转向就追""刚转向就做"。
- **把"啥也不是"当成假突破**（ep-2026.9.22 L743、ep-2026.9.25 L0859–L0891）。陷阱：突破未跟随、未拉开距离时，直接把矛盾证据合并成"假突破"并反向做。机制：真突破（跟随、拉开距离）≠ 假突破（无跟随、未过 50%）≠ "啥也不是"；证据矛盾时宁可判"啥也不是"，作者说"谨慎一点的话就不把这个当假突破"。预警信号："这不就是假突破吗，反手做""影线到了就算破了吧"。
- **做宽幅突破单**（ep-2026.7.28 L44；ep-2026.7.30 L514）。陷阱：做宽幅突破（横向距离宽、构成时间长）的突破单或 N 字形。机制：宽幅突破动能弱，不适合突破式交易；作者建议"尽量放弃/少做宽幅突破 N 字形"。预警信号："这个区间很宽也做突破""宽幅 N 字也追"。

### 作者的盲点 / 时代局限

- **50% 的参照段与适用周期未定义**。原文只说"实体出来 50% 以上""你要把引线算上"，没说是相对哪一段量取、在哪个周期适用，也没有说明不同品种是否相同；本卡按"被打破关键位的实体拉出距离"操作化，属实现约定。
- **"跟随"的根数未定**。作者说"第二根 K 线给我走出一根跟随"，但没说明若第二根只是小实体、或第三根才跟随如何算。
- **平台语境与滑点**。黄金 CFD 与加密合约在数据行情下滑点极大，突破当根的实际成交价可能与判定所用的收盘价差异明显，本能力无法覆盖。
- **素材为直播口语**。同一场直播内对"假突破"的表述有松紧变化（"胆大的才当假突破合并处理"），本卡以 的"啥也不是"第三态为准。
- **宽窄与二次确认的量化未给**。"窄幅/宽幅""二次确认"的大小周期搭配原文均未给量化边界。

### 容易混淆的邻近方法论

- **"假突破反手"策略（fade the breakout）**：常见做法是突破失败就无条件反手；本能力要求先区分"假突破"与"啥也不是"，矛盾时不做。
- **突破追单（momentum breakout）**：只看价格穿线就追，不看实体距离与跟随；与本能力"两条件都满足才算真"相反。
- **单周期突破**：只在一个周期上判定，作者明确禁止。
- **"影线突破也算破"**：只看影线扫过关键位就判突破；本能力以实体为准，影线视为假突破。
- **"逆势突破也能做"**：不做方向过滤地做突破；作者要求尽量顺势、放弃逆势。
