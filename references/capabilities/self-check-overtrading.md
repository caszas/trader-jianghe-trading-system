# 过手瘾 / 假想稳定自检

## I — 方法论骨架（Interpretation）

自检两件事。

**第一件：做单的动机是赚钱还是爽（过手瘾）。** 判断标准不是"做了几单"，而是"不做的时候难不难受"。若答案是"不做我难受、我要有参与感、我享受下单的快感"，那交易目的已经从赚钱变成了获取多巴胺——这时频繁交易不是策略问题，是动机问题。作者用"过手瘾""找屎吃"来形容。

**第二件：有没有把单日收益外推成年收益（假想稳定）。** 典型算法是"今天赚了 1000，那一年就是 36.5 万"。作者指出"稳定"只能用于总结过去，不能用于预测未来；不存在稳定的技术／系统，只有稳定的人。把单日收益线性外推，会制造出一个虚高的预期，而这个预期会反过来逼你每天必须做单——"今天不捡钱就算丢钱"，把等待当成损失，于是没机会也硬做。

两件事互相喂养：外推出来的假想稳定 → 每天必须做 → 过手瘾 → 更频繁 → 亏损。

频率的正确判据不是数量，而是**是否由交易系统触发**：触发 15 单做 15 单不算频繁；系统一单没触发却做了两单，就是频繁交易。

补一个**自我诊断的维度模型**：第一维度——只通过账户资金变化做交易（亏了死扛、赚了就跑）；第二维度——既看资金又看行情，左右脑互搏、管不住手；第三维度——只看 K 线、只跟行情节奏，不跟情绪、不跟账户资金变化。前两维是亏损根源，目标是升到第三维；情绪上来时先停一停、缓一缓（ep-2026.8.5 L11、L47、L111）。各维度的量化判定标准与进阶时长**原文未给**。

关于频率，作者还有两条立场：**80% 的利润来自 20% 的时间，剩下 80% 的时间需要的是等待而非行动**（ep-2026.6.28 L112）；**交易的本质不是勤奋、不是证明、不是刺激，而是等待与选择，是把有限的子弹打到最有把握的地方**（ep-2026.8.29 L111、L115、ep-2026.8.23 L88、ep-2026.10.4 L58）。据此把交易者分两类：**感觉交易者**（被市场控制、沉迷买卖多巴胺、因为想做而做）与**机会交易者**（触发系统与规则才出手）——本卡自检的落点是后者。

## A1 — 应用示例（Application Example）

### 示例 1: 合成演练——自检清单打分
- **类型与来源**: 原书未提供自检表；以下为合成演练，判据取自 ep-2026.9.14 L01664、ep-2026.9.14 L02690–L02698、ep-2026.9.22 L01820。
- **问题/输入**: 用户说"我每天不做几单就难受，一天两单太少想多做十几单"。
- **方法论的使用**:
 1. 做单动机题：如果今天系统不触发，你还会做吗？→ 用户答"会"。判定：过手瘾。
 2. 系统触发题：今天的单是系统触发还是想做的？→ 用户答"想做的"。判定：频繁交易。
 3. 假想稳定题：有没有用今天赚的 1000 推算"一年 36.5 万"？→ 用户承认。判定：假想稳定。
- **结论**: 三项全中，问题不在技术而在动机与预期。
- **结果**: 未说明（合成演练）。

### 示例 2: 原书转述——送外卖学员
- **类型与来源**: 原书转述（cB3-18，ep-2026.9.3 L03183–L03209）。
- **问题/输入**: 学员刚毕业、交易两年一直亏，"喜欢重仓、频繁交易（小赚大亏）"，爆仓后只剩约 200U。
- **方法论的使用**: 这是"过手瘾 + 指望一笔改命"的复合样本——频繁交易与小赚大亏同时出现，符合自检清单中"动机为爽"和"外推暴富"两项。
- **结论**: 作者给的处置是"把交易当成生命中最后一件事做就不急了"，先隔绝外界信息、专注。
- **结果**: 爆仓、只剩约 200U（未说明后续）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户一天做很多单，说"不做就难受 / 手痒"。
2. 用户给自己定"今天必须开 N 单"的任务量。
3. 用户用单日收益推算年收益（"今天赚 1000，一年就 36.5 万"）。
4. 用户几天没机会就焦虑，觉得"没赚到就是亏了"。
5. 用户想提高收益，问"是不是该多做几单"。

### 语言信号（用户的话里出现这些就应激活）

- "我不做难受 / 手痒 / 过手瘾 / 有参与感"
- "今天必须开几单 / 任务量 / 我一天做两单太少"
- "今天没赚到就是亏了 / 不捡钱就算丢钱"
- "按今天这样一年就是 XX 万"
- "overtrading / 假想稳定 / 稳定盈利"

### 与相邻能力的区分

- 与 `review-scope` 的区别: review-scope 管复盘口径（只看实际结果、卖飞是假盈利）；本能力管**动机与预期**的自检（为什么做、预期是否外推）。前者看结果，后者看动机。
- 与 `setup-gate` 的区别: setup-gate 判断单笔该不该做；本能力判断**整体做单行为**是否被"爽"和"假想稳定"驱动。
- 与 `emotion-three-step` 的区别: 三步法处理亏损后的动作；本能力是**事前**动机自检。
- 与 `advantage-amplification` 的区别: 后者讲"想多赚从仓位／风控下手，不从技术下手"；本能力补充"增加频率是最傻的一种方式"。

## E — 可执行步骤（Execution）

**必需输入**: 用户近期的做单记录（笔数、是否由系统触发）；用户的收益预期来源；用户"不做单时"的感受描述。缺失时问："如果今天系统不触发，你会做单吗？""你有没有用一天的收益去推算一年？"

**交付物与完成标准**: 一张**可勾选自检清单**，至少含三栏问题，每栏给出"是／否"，并在任一"是"时给出判定。

- ① 做单动机：如果今天完全没有机会，我还会想开单吗？（勾"是" → 过手瘾）
- ② 频率是否由系统触发：今天的每一单，都能对应到系统的一条触发条件吗？（勾"否" → 频繁交易）
- ③ 是否把单日收益外推成年收益：我有没有用今天／本周的收益推算过"一年能赚多少"？（勾"是" → 假想稳定）

完成标准：三栏都作答；若任一栏命中，明确写出对应的修正动作（动机命中 → 回到"交易是为赚钱"；频率命中 → 只做系统触发；外推命中 → 撤销该预期）。

**实现约定**: "过手瘾""假想稳定"出自原文；"三栏可勾选清单"及其判定为**实现约定**，原文未给清单。

1. **收集近期做单记录**
 - 完成标准: 至少覆盖最近一段时间的笔数，并标注每单是否由系统触发。
2. **做动机自检**
 - 完成标准: 回答"无机会时是否仍想开单"，勾是／否。
3. **做频率自检**
 - 完成标准: 逐单核对是否对应系统触发；统计"未触发却做了"的笔数。
 - 判停条件: 若存在未触发却做的单 → 判定频繁交易，处方 = 只做系统触发（`trade-system-build`）。
4. **做假想稳定自检**
 - 完成标准: 明确是否做过"单日→年"的外推；若有，写出被外推的数字。
 - 判停条件: 若存在外推 → 判定假想稳定，撤销该预期（`capital-and-reserve` / `advantage-amplification`）。
5. **输出结论与修正动作**
 - 完成标准: 三项逐一给出判定 + 一个可执行的修正动作。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **把"频率低"当成目标**。作者的标准是"是否由系统触发"，不是越少越好；触发多就该做多。
- **在逻辑错误时用"减少频率"自救**。作者指出：逻辑正确时多做可能多赚，逻辑错误时越谨慎越亏——减少频率不是万能解。
- **把自检当成自责**。清单是诊断工具，命中不等于"我有病"。

### 作者警告的失败模式

- **为做而做 / 过手瘾**（ep-2026.9.14 L01664）。陷阱：交易目的是下单快感而非赚钱；机制：把情绪／快感置于客观事实之上，导致频繁无效下单；预警信号："我不做难受""要有参与感""享受买卖的多巴胺"。
- **频繁交易（未触发系统也做）**（ep-2026.9.22 L01820）。陷阱：系统未触发却做单，或为多赚刻意提高频率；机制：是否频繁由"是否触发系统"决定，多赚应通过少亏／加品种，增加频率是最傻的方式；预警信号："今天没触发系统却做了两单""三四天开不出一单就焦虑"。
- **打工思维 / 拿任务量做交易**（ep-2026.9.25 L01571–L01589）。陷阱：给自己定"今天必须开多少单"；机制：交易的钱不是等值付出换来的，把"参与"当安全感与"等机会"冲突；预警信号："我必须得开 100 单""每天规定开单数量"。
- **假想盈利 /"今天不捡钱就算丢钱"**（ep-2026.8.5 L01764）。陷阱：把"没赚到"当"亏了"，逼自己每天做单；机制：把等待当损失，于是没机会也硬做；预警信号："今天不捡钱就算丢钱""我没赚钱就等于丢钱了"。
- **小资金不当钱 → 恶性重复梭哈**（ep-2026.10.2 L01091–L01096）。陷阱：小资金不做资金管理、连损两单后梭哈；机制：钱太易得就不珍惜，永远觉得"还有子弹"；预警信号："小资金无所谓""这是最后一次 50 了"。
- **做得多等于赚得多 / 追求高频**（ep-2026.6.28 L92、L100）。陷阱：追求高频、什么行情都做（强趋势、弱趋势、震荡、反转都不放过）。机制：本末倒置——做交易的目的是赚钱而不是"为了做"；一天做十单赚 1 万，不如一天做一单赚 1 万。预警信号："多做几单多赚点""什么行情都想做"。
- **感觉交易者（为做而做、追多巴胺）**（ep-2026.8.29 L36、L39）。陷阱：被市场控制、沉迷买卖多巴胺、因为想做所以做。机制："为了交易而交易"必然为自己的行为买单；应做机会交易者——触发系统与规则才出手。预警信号："不做难受""买卖有快感""我就是想下单"。

### 作者的盲点 / 时代局限

- **"是否由系统触发"依赖用户已有一个可信的系统**；没有系统的人无法用这条自检，会退化成"凭感觉判断自己是不是过手瘾"。
- **"没有稳定的事，只有稳定的人"是立场而非可验证结论**；作者未给"假想稳定"与"合理预期"的分界数值。
- **标的与平台语境**。内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护；本能力是自检工具，不构成投资建议。

### 容易混淆的邻近方法论

- **交易频率管理**：通常以"降低频率"为目标；本能力以"是否由系统触发"为判据。
- **收益预期管理**：一般讲设定合理目标；本能力专指"单日外推成年"这一类失真。
