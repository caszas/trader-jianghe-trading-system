## I — 方法论骨架（Interpretation）

新人常问"怎么修心""怎么提高自控力"，作者的回答是：别修，修不了。他不相信自己的心态、情绪、人性，只相信规则。

原因是他观察到意志力是**消耗品**——不是一种恒定能力，而是像体力一样会被耗尽。市场反复刺激（连亏、浮盈回吐、卖飞）会持续消耗它，而它恰好在压力最大的峰值处失效。所以"靠意志力管住手"这个方案有结构性缺陷：它在你最需要它的时候最弱。

替代方案是用外部规则约束行为，把决策从"当时想不想"挪到"规则允不允许"。规则可以来自平台工具（限手数、锁杠杆），也可以来自自己写的系统（连损停手、当日熔断、资金隔离）。前期靠规则约束，重复执行到成为肌肉记忆，最后"规则内化"。

要区分两件事：**规则约束的是行为，不是情绪**。作者不否认自己有情绪（"牙打碎了咽自己肚子里"），他不追求"没有情绪"，只追求"情绪不改变行为"。

**补全（2026 新素材）——"用规则替代意志力"的三条更具体机制**：

其一，**规则要放在盘前，盘中只执行**。作者："你在盘中的时候是不需要任何分析思考的行为的……你在盘中所有的思考本质上都是对你自己交易计划的背叛"——把动脑全部前置到交易前（构建系统、复盘数据、设计预案），开盘后按系统条件执行，触发进场条件就进、触发离场条件就出（ep-2026.5.10 L19、L28、L38）。盘中看图说话找理由属"盘感交易"，会导致行为不一致（ep-2026.5.10 L49、L55）。

其二，**源头防范优于事后补救**。针对"上头"，作者的方案不是"上头之后怎么做"，而是"如何做到不上头"；最简做法是资金隔断——交易账户只放当日最大交易限额，再配连损熔断、同位置反复止损后放弃、下单前按预设逻辑打分（ep-2026.7.29 L28–L33、L60–L66）。

其三，**重复执行的目的是让概率优势显现**。不论上一笔结果如何，这一笔仍执行原系统，样本足够多概率才显现——"有概率优势并不能让你赚钱，而让概率优势显现，才能让你赚到钱"（ep-2025.11.23 L120、L126）。作者用"因果—习惯复利"解释为何要重复：每个行为都在留下潜意识与习惯，好习惯与坏习惯都会复利（ep-2026.7.20 L11、L37、L44、L210）。

**修正性补充**：本能力说的"重复执行"应落到**逻辑一致性**，而非刻板的行为一致性。作者："一致性的是逻辑不是行为……不要追求那种贼刻板的那种，比如说一个回调的定义就是几根几根"（ep-2026.7.25 L1239、L1667）——固化的是判断逻辑，不是把每个动作数据化。

## A1 — 应用示例（Application Example）

### 示例 1: 合成演练——把"我要自律"翻译成规则
- **类型与来源**: 原书未提供逐步改写案例；以下为合成演练，依据 ep-2026.8.5 L01083–L01095、ep-2026.9.10 L02479–L02484。
- **问题/输入**: 用户说"我总是连亏两单后就想重仓打回来，我要靠自律管住自己"。
- **方法论的使用**:
 1. 识别"靠自律"是一个会失效的方案（意志力在峰值处失效）。
 2. 把它改写成外部规则：账户只放当日最大回撤额度（物理上重仓不了）+ 同一逻辑连损两次即当日停手。
 3. 用平台工具把规则落地（设手数上限、把多余资金提出）。
 4. 重复执行，直到"停手"不需要做决定。
- **结论**: 方案从"我要忍住"变成"我忍不住也没关系，规则不让我做"。
- **结果**: 未说明（合成演练）。

### 示例 2: 原书亲历——作者自述"只相信规则"（pB1-10）
- **类型与来源**: 原书亲历（8.5 L1083–L1095）。
- **问题/输入**: 作者面对自己也会情绪化、亏钱也难受的事实。
- **方法论的使用**: 他不把希望寄托在"我心态好"，而是用外在规则约束自己（账户只放最大可承受亏损额、一个位置错两次就停、单日最大回撤 10%）。
- **结论**: 承认情绪存在，但用规则隔开情绪与行为。
- **结果**: 未说明（作为原则陈述）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户说"我知道不该做，但我控制不住自己"。
2. 用户尝试过"修心／冥想／提高自控力"，短期有效长期失效。
3. 用户连亏后反复重仓，想找"管住手"的方法。
4. 用户问"我是不是心态不行，要不要先练心态再做"。
5. 用户在用高杠杆、无手数上限的账户，希望靠自律控制风险。
6. 用户盘中反复看图、临时给订单找理由（"盘感交易"，ep-2026.5.10 L49、L55）。

### 语言信号（用户的话里出现这些就应激活）

- "我自控力差 / 我管不住自己 / 靠意志力硬扛"
- "修心 / 心态 / 自律 / self-discipline / willpower"
- "我知道该停手但停不下来"
- "我要练好心态再做交易"
- "规则约束 / 用工具管住手 / rule over mindset"

### 与相邻能力的区分

- 与 `execution-root-cause` 的区别: execution-root-cause 是**分诊**——先判断"管不住手"的根因（无逻辑／逻辑不全／心理问题）；本能力是针对"心理／习惯层"的**处方**（用外部规则替代意志力）。顺序是先分诊、再决定是否开这个处方；若根因是"无逻辑"，开规则处方无效，应先建逻辑。
- 与 `emotion-three-step` 的区别: 三步法处理亏损**当场**的动作；本能力是**平时**的行为约束设计。
- 与 `write-loss-action` 的区别: write-loss-action 写的是系统里"亏损后动作"那一段；本能力是"为什么要用规则而不是意志力"的总体立场，并把规则落到多个环节（仓位、熔断、资金隔离）。
- 与 `state-and-event-guard` 的区别: 后者管精力／数据行情；本能力管"意志力不可靠"这一根本假设。

## E — 可执行步骤（Execution）

**必需输入**: 用户想用意志力／自律解决的具体行为；该行为发生的场景；可用平台工具（手数上限、杠杆、出入金）；账户资金结构。缺失时问："你想管住的具体是哪个动作？""这个动作通常什么情况下发生？"

**交付物与完成标准**: 一份"行为 → 外部规则"映射表，每行含 `目标行为` / `触发条件` / `外部约束手段` / `约束是否可自动生效`。完成标准：对每一个目标行为，都存在一条**不依赖当下意志力**的约束（要么物理限制，要么由平台／规则自动触发）；若某行为只能靠"我记住就行"，判为未完成。

**实现约定**: "不靠自控力、用规则约束"出自原文；映射表格式、"约束必须可自动生效"为**实现约定**。

1. **列出想靠意志力解决的行为**
 - 完成标准: 至少写出一个具体动作（如"连亏后加仓"），而非笼统的"控制情绪"。
2. **确认它不是"无逻辑"造成的**
 - 完成标准: 该行为背后有明确的系统规则（知道该做什么却做不到）；若说不清该做什么 → 判停，转 `execution-root-cause`。
 - 判停条件: 若用户答不出"正确做法是什么" → 回到 `execution-root-cause` 分诊。
3. **为每个行为设计外部约束**
 - 完成标准: 约束是外部的（平台设置、账户结构、资金隔离），不依赖"当时忍不忍"。
 - 补全（2026 新素材）: 常用手段——资金隔断（账户只放当日最大交易限额）、连损熔断、同位置反复止损后放弃、下单前按预设逻辑打分（ep-2026.7.29 L33、L60、L66）。资金隔断的具体额度比例原文未给（**实现约定**：以当日最大可承受回撤为上限）。
4. **检查约束能否自动生效**
 - 完成标准: 该约束在用户"想违反"时仍然拦得住（如手数上限锁死、资金已提出）。
 - 判停条件: 若约束只在"用户自觉"时才生效 → 视为无效，重新设计。
5. **设定重复执行与内化目标**
 - 完成标准: 明确"重复执行到成为肌肉记忆"这一目标，并说明在未内化前始终保留外部约束。
6. **把思考前置到盘前**
 - 完成标准: 明确"构建系统／复盘／预案"发生在盘前，盘中只按系统条件执行、不做临时分析（ep-2026.5.10 L19、L28、L38）。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **在根因是"无逻辑"时开这个处方**。若用户根本不知道该做什么，规则约束无从谈起，应先 `execution-root-cause`。
- **把"规则约束"当成"不需要理解逻辑"**。规则是约束行为，不是替代认知；不理解为什么，规则会在边界情况下失效。
- **用"外部规则"替自己免责**。作者明确反对"靠平台规则管住手"的自我欺骗（见失败模式）。

### 作者警告的失败模式

- **靠自控力 / 意志力对抗上头**（ep-2026.8.5 L01095–L01098）。陷阱：指望上头发生时靠自制力管住自己；机制：自控力在压力峰值时失效——"能管住就不叫上头了"；预警信号："我只靠意志力""我心态好我牛逼""连错三单四单想靠意志硬扛"。
- **考试盘速通 / 靠外部规则管住手**（ep-2026.9.23 L02307–L02313）。陷阱：想靠考试盘规则、平台规则来"管住手"；机制：管住手是内驱的事，平台设规则不代表你就能管住手，有些人是自我洗脑、自我欺骗；预警信号："能不能速通考试盘""靠平台规则管手"。**注意：这与本能力不矛盾——本能力说的是用规则约束行为，作者反对的是"把管住手外包给平台"的自我欺骗。**
- **盘感交易 / 盘中分析找理由**（ep-2026.5.10 L49、L55）。陷阱：盘中左思右想、看图说话、给自己的订单找理由。机制：这属于盘感交易，会导致行为不一致（同样行情这次做多下次做空、这次重仓下次清仓），行为不一致就永远发挥不出概率优势、更谈不上复利。预警信号："盘中再分析一下""给这笔单找找理由"。
- **上头后才想控制情绪**（ep-2026.7.29 L28、L31）。陷阱：等上头发生了再想办法控制。机制：一旦上头就绝对控制不住——"能控制住的那绝对不叫上头"；应从源头（资金隔断＋规则化）防范，而非事后补救。预警信号："我这单上头了怎么办"。

### 作者的盲点 / 时代局限

- **作者自己说"能解决的心态问题就不是心态问题"**，把一部分"管不住手"归为不可解的心理问题（只能靠亏疼）——这等于承认本能力有覆盖不到的区段。
- **"意志力是消耗品"来自作者引用的通俗心理学**（"你可以上网搜一下"），未给严谨出处；把它当作绝对定律使用需谨慎。
- **标的与平台语境**。内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护；本能力是行为纪律工具，不构成投资建议。

### 容易混淆的邻近方法论

- **正念 / 自律训练**：目标是增强内在控制力；本能力假设内在控制力不可靠，改用外部约束。
- **交易系统**：系统是"做什么"的知识体系；本能力是"用什么手段保证做到"的约束体系。
- **"行为一致性 = 每次都做一模一样的动作"**：作者口径是"一致性的是逻辑不是行为"（ep-2026.7.25 L1239、L1667）——逻辑固定化即可，行为留容错空间，不把回调定义成固定几根 K 线。
