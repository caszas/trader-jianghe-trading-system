# 不做二极管思维（一笔订单的因子拆解）

## R — 原文（Reading）

> 就是以条件为主导／能懂吗／就是以条件去讲／对具体的问题具体分析／具体的问题具体分析／不要去套用其他人的观点／硬套会吃大亏

— 交易员江河，ep-2026.8.3 L01049–L01054

---

> 不能做多／不代表直接就能做空／能懂什么意思吗

— 交易员江河，ep-2026.8.17 L01673

---

## I — 方法论骨架（Interpretation）

这套方法的靶子是把交易问题压缩成二选一的思维。"不能做多，那就做空"是最典型的形态：它假定一笔订单只有"买／卖"两个取值，且二者互斥互补。作者直接否掉这个假定——不能做多只说明"做多这一支被排除"，不推出"做空成立"。理由在于一笔订单的变量远不止买卖方向：仓位、止损位、进场方式（左／右）、出场方式都还是可变因子，其中任何一个不成立，这笔单就不存在。

由此引出一个更一般的框架：定方向是排除法，不是指令。主周期定成空头，得到的结论是"做不了任何多单"；而"可做空单"仍然只是"可以考虑做"，还要继续走完位置、节奏、信号。方向被从"指令"降级为"过滤器"，这正是反二极管思维的正面表述。

第二个靶子是硬归因：把某笔成功订单里的某个加分项（比如某个关键位）当成必要条件，然后到处套用——"这也是关键位，你咋不做"。作者的判词是加分项不等于必要条件；从单次结果反推逻辑，是把偶然当必然。第三个靶子是硬套理论：把学到的知识点往既有概念上硬贴，或把不同体系的概念混用（拿 A 往 B 上套），结果是分析与行为脱节，变成左右脑互搏。

最后一条推论是"具体问题具体分析，没有标准答案"。市场节奏动态变化，很多东西无法量化；能量化的只有"逻辑"。追求标准答案、固定 K 线根数、固定盈亏比，都是刻舟求剑。作者甚至说不同人适合的方式不同，用小马过河作比——同一套规则，深浅因人而异。

## A1 — 应用示例（Application Example）

### 示例 1: "多头不能做了，那我做空"——因子拆解
- **类型与来源**: 原书未提供该对话案例，以下为合成演练（判据口径来自 与 定方向＝排除法）
- **问题/输入**: 使用者判断当前不适合做多，随即提出"那就反手做空"，问能不能进。
- **方法论的使用**:
 1. 识别被二值化的判断："不能做多 → 能做空"；
 2. 列出这笔单的全部可变因子：方向、位置、节奏、信号、仓位、止损、进场方式、出场方式；
 3. 逐项判定：方向这一支（做多）被排除；"做空"这一支是否成立，还要看位置（是否顶着关键位）、节奏、信号是否齐备；
 4. 把"不能做多"翻译成"做多这一支被排除"，不翻译成"做空成立"；
 5. 检查可做集合：若做空所需的位置／节奏／信号也不满足，可做集合为空。
- **结论**: 可做集合为空 → 不做；"不能做多"不构成做空理由。
- **结果**: 合成演练，无真实成交结果（未说明）。

### 示例 2: 19 岁学员问"小资金该重仓还是轻仓"
- **类型与来源**: 原书转述的连麦案例（ep-2026.9.3 L01713、L01826、L01836）
- **问题/输入**: 学员一年多亏八九万、爆仓、休学在家，问小资金做大该重仓还是轻仓——一个典型的二选一提问。
- **方法论的使用**: 作者不接受这个二选一，指出两极化思维（要么单笔 2%、要么百分百梭哈）不可取；应"该轻的时候轻、该重的时候重"，用筹码分配做相对轻重——即把"仓位"这个因子从二值展开成连续量。
- **结论**: 仓位不是重／轻二选一，而是按订单质量分档（没加分项 50 美金、有加分项 150 美金，原文口径）。
- **结果**: 原书交代：学员此前已爆仓（剩少量资金），作者判定其当前不具备赚钱能力。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户说"不能做多，那就做空"。
2. 用户学一个流派没赚钱就全盘否认，想立刻换一个。
3. 用户问"小资金该重仓还是轻仓"这类二选一问题。
4. 用户把某笔成功单的加分项当必要条件，到处问"这也是关键位你咋不做"。
5. 用户想给所有情况找标准答案（固定 K 线根数、固定盈亏比、固定入场模板）。

### 语言信号（用户的话里出现这些就应激活）

- "不能做多那就做空"
- "要么……要么…… / either...or..."
- "binary thinking / 非黑即白 / 二极管"
- "这也是关键位，为什么这个能做那个不能做"
- "有没有标准答案 / 几根 K 线算 / 固定盈亏比"

### 与相邻能力的区分

- 与 `setup-gate` 的区别: setup-gate 的结论本身就是二值的（做／不做）；本能力反对的是把**因子**二值化。二值化只允许出现在最终决策层，不能出现在因子层。
- 与 `necessary-conditions` 的区别: necessary-conditions 是正向清单（四要素齐备才做）；本能力是纠偏框架，处理"条件不齐时剩下的空间"——解释为什么"缺一项"不等于"换一项"。
- 与 `two-way-playbook` 的区别: 本能力解释"为什么不能二选一站队"；two-way-playbook 给出"不站队时具体怎么做"（上涨／下跌／震荡多套预案）。
- 与 `entry-model-taxonomy` 的区别: entry-model-taxonomy 把进场分成左中左／左中右／右中左／右中右／共振五类；本能力提醒这五类不是"二选一"的对立选项，而是可细分的位置谱。

## E — 可执行步骤（Execution）

**必需输入**: 用户给出的二选一判断原句（如"不能做多那就做空"）；该笔订单的因子清单（方向、位置、节奏、信号、仓位、止损、进场方式、出场方式）。因子清单缺失时，先与用户逐项确认，不得默认。

**交付物与完成标准**: 输出一张因子拆解表（每行一个因子：因子名／当前取值／是否可调／结论）＋ 一句重述后的"可做集合"（可能为空集）。完成标准：表中因子数 ≥5，且"可做集合"必须由逐项判定得出，不能由"不能做 A"直接推出"能做 B"。

**实现约定**: 原文未给"哪些因子可调、可调到什么程度"的规则；本卡以"方向／位置／节奏／信号／仓位／止损／进场方式／出场方式"作为因子清单的**实现约定**，使用者可增删，不改变"因子不止买卖"的原意。

当能力被激活后，agent 应按以下步骤执行：

1. **识别被二值化的判断**
 - 完成标准: 能原样复述用户那句二选一（如"不能做多 → 做空"）。
2. **列出全部可变因子**
 - 完成标准: 因子数 ≥5，且覆盖方向、位置、仓位、止损、进出场。
3. **逐因子判定"确定／可调"**
 - 完成标准: 每个因子有明确结论，无空白。
4. **翻译"不能做 A"**
 - 完成标准: 只输出"A 这一支被排除"，**禁止**输出"B 成立"。
5. **构造可做集合**
 - 完成标准: 逐一检查 B 方向所需的位置／节奏／信号是否满足，得到可做集合（可能为空）。
 - 判停条件: 可做集合为空 → 回到 `setup-gate` 判 `不做`，终止。
6. **输出因子表与可做集合**
 - 完成标准: 用户能据此说出"我现在缺的是哪几个因子"，而不是"我该做多还是做空"。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **用来给"多空都做"找理由**。本能力反对的是错误的对立推演，不是鼓励在同一时间同时持有多空。
- **在最终决策层拒绝二值化**。做／不做的结论仍必须是二值的（见 `setup-gate`）；本能力只针对因子层。
- **当作"不用下结论"的借口**。具体问题具体分析不等于永远不下结论。
- **替代 `entry-model-taxonomy`**。把进场分成五类是位置维度的专门工作，本能力只提供"不要二选一"的一般提醒。

### 作者警告的失败模式

- **非黑即白／死板（学一个流派没赚钱就全盘否认）**（ep-2026.8.17 L01700、ep-2026.9.16 L02470、ep-2026.9.24 L01418）。陷阱：认为"不能做多就直接做空"；学 SMC 没赚钱就把 SMC 全盘否定，再换价格行为，循环往复。机制：市场有强势下跌、弱势下跌、横盘、收回等多种可能，应看触发了哪种用对应方案；非黑即白会漏掉中间态，一杆子打死等于给自己画圈。预警信号："不能做多那就做空""要么用 A 要么用 B""必须找模板""一杆子打死"。
- **条件混乱（不能做多 ≠ 能做空）**（ep-2026.3.21 L0193）。陷阱：等不到做多机会就慌乱做空，把"不能做多"误当成"能做空"；被盘面带着情绪走、看到阴线就做空，往往进场即被套。原文："一个位置做不了多了啊 也不代表着它就一定能去做空 做多需要做多的条件去支撑 那么反过来做空呢 也是需要有一个做空的条件去支撑的"。机制：做多/做空各有独立的支撑条件，条件不能混用。预警信号："不能做多那就做空""等不到多头就慌着做空"。
- **两极化思维**（ep-2026.9.3 L01837）。陷阱：仓位只有两个极端——一律单笔 2%，或百分百梭哈。机制：现实中存在中间地带，应"该轻的时候轻、该重的时候重"。预警信号："网上都说单笔 2% 就单笔 2%""要么就百分百梭哈"。
- **硬套理论／跨体系混用**（ep-2026.8.3 L01446–L01463、ep-2026.9.9 L01764、ep-2026.9.29 L01761）。陷阱：套一大堆理论但与自己的实际操作行为没有关系；把不同知识点／不同体系混用，拿 A 往 B 上套。机制：分析与行为脱节，反而左右脑互搏；不同知识点是独立体系，混用会导致逻辑错乱。预警信号："咔咔咔一顿分析上来分析十个点结果只指导第一个因子""这不就双顶吗""把课里两个不同知识点拼在一起用"。
- **硬归因**（／，ep-2026.8.3 L01054）。陷阱：把某笔成功订单里的加分项当成必要条件，到处套用。机制：加分项≠必要条件，从单次结果反推逻辑是本能力反复批评的误区。预警信号："这也是关键位，你咋不做"。

### 作者的盲点 / 时代局限

- **"具体问题具体分析"没有可评测的标准**。作者自己承认"交易没有标准答案，每个人适合的方式不同"，这意味着本能力很难被外部验证，容易变成"怎么说都对"。
- **因子清单与可调范围原文未给**。哪些因子可调、可调到什么程度， 未展开，本卡的清单属实现约定。
- **反二极管的边界未被作者明确**。作者反对"多空二选一"，却又强调"不逆势""不顶着关键位做"等硬约束；哪些地方允许灰度、哪些地方必须硬性，原文没有给出统一判据。
- **合规与平台语境**。内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护，作者本人也承认"不敢说自己是做这个的"。与平台规则绑定的操作不蒸馏为通用能力，仅作风险提示；本卡不构成投资建议。

### 容易混淆的邻近方法论

- **"灵活应变"**：应变的前提是有预案（`two-way-playbook`）；本能力是"不要站队"，应变是"怎么应对"，两者互补但不相同。
- **"多空对冲"**：那是同时持有两个方向，与本能力"不把 A 的否定推成 B"无关。
- **"不设固定规则"**：作者反对的是"没有一致性的定义"，不是"不要规则"；本能力不主张随意。
