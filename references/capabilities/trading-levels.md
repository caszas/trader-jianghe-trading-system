## I — 方法论骨架（Interpretation）

这套层次回答的不是"进场模型长什么样"，而是一个更前置的问题：**手上几套方案、该停在哪一层**。三层是并列的可选站位，不是从低到高的成长阶段，也不按进场结构分类。

- **第一层 · 碰撞测试型**：不管市场出什么状态，都执行同一套 A 方案，像石头剪刀布永远出布。只在状态恰好匹配时赚，其余状态都亏，长期磨损严重且痛苦。
- **第二层 · 条件专用型**：识别出 A 方案只适用于"一号条件"，二号到五号状态出现时就不碰。靠缩小适用范围减少误判与磨损，是作者建议停留的层次。
- **第三层 · 多方案匹配型**：一号用 A、二号用 B、三号用 C，理论上可行，但要同时判断多种行情、执行多套策略，各策略的磨损叠加、判断本身也有误判磨损，实际收益不增反更累。

关键取舍：作者从第三层**主动退回**第二层，收益提升靠**仓位管理**而非增加逻辑或方案数量。选择层次的标准是"能不能稳定执行、磨损是否可控"，不是"理论上层数越高越完整"。

## A1 — 应用示例（Application Example）

### 示例 1: 学员从第二层冲第三层又退回（直播转述案例）
- **类型与来源**: 转述案例（reported_case，ep-2026.11.17 L1983、L1996、L2016）；是作者对学员的观察，非作者本人交易。
- **问题/输入**: 一位学员账户放十几万美金，来找作者时已经能稳定盈利，明确想找其他方式赚更多。
- **方法论的使用**: 作者判断其原有方式合理，没有大改，只做微调与启发；学员凭已有的条件专用方式，去尝试多方案匹配。
- **结论**: 第三层实际效果与第二层差不多，但执行更累、磨损叠加；学员自行退回第二层、更加专注。收益提升靠专注与仓位，不靠增加方案。
- **结果**: 退回第二层、执行更顺。
- **缺口**: 原文未给该学员的具体交易方式、仓位数值与盈亏金额。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户问"我该用几套方案 / 一套够不够 / 要不要多学几招"。
2. 用户主张"行情不同就该用不同方法"，想用多套策略覆盖所有行情。
3. 用户发现"回测很好，实盘做不到"，多套策略执行跟不上、越做越累。
4. 用户用同一招应对所有行情，"匹配时赚、不匹配时亏"，长期磨损严重。
5. 用户已有一套能盈利的方法，想再找别的方式赚更多，问该不该加方案。
6. 用户问"收益怎么提升 / 是不是要再加逻辑"，需要被引导到仓位管理上。

### 语言信号（用户的话里出现这些就应激活）

- "几套方案 / 几个系统 / 一套还是多套 / 用几个方法"
- "停在哪一层 / 要不要升级 / 进阶 / 多方案匹配"
- "不同行情用不同策略 / 震荡高空低多 / 趋势顺势"
- "回测好但实盘做不到 / 执行不了 / 越做越累 / 磨损"
- "匹配就赚不匹配就亏 / 永远用一招 / 反复碰撞"
- "想赚更多 / 再加一套逻辑 / 提升收益"
- 英文信号："how many systems / one strategy or multiple / stop at which level / backtest good but live can't execute"

### 与相邻能力的区分

- 与 `growth-path` 的区别: growth-path 是成长阶段（四处求学→寻找适合→融会贯通），讲人随时间的认知进阶；本能力的三层是"用几套方案、停在哪一层"的并列选项，不是时间上的成长阶段，也不含"越高越好"。
- 与 `entry-model-taxonomy` 的区别: entry-model-taxonomy 按进场结构分类（左中左/右中右/逻辑共振等）；本能力按"方案数量与适用条件"分层，不描述进场模型长什么样。
- 与 `advantage-amplification` 的区别: 该卡讲放大优点、不补短板；本能力讲"几套方案、停在哪一层"，落到单一方案的适用条件与仓位，而非优点/短板的取舍。
- 与 `compounding-static` 的区别: 该卡讲固定比例静态复利与资金隔断；本能力决定从第三层退回第二层后靠仓位管理提收益，是"要不要加方案"的层次选择，不是具体复利计算。
- 与 `position-allocation` 的区别: 该卡按机会评分分配仓位（加分正常/不加分半仓）；本能力是它的上游——先决定停留在哪一层，退回第二层后的收益提升再交给仓位分配。

## E — 可执行步骤（Execution）

**必需输入**: 已掌握的多套方案清单；对每套方案适用条件（"一号条件"）的识别能力；当前执行状态（处于哪一层、磨损情况、能否稳定执行）。

**交付物与完成标准**: 一份"层次选择结论"——当前在哪一层、应停留在哪一层、收益提升路径（调仓而非加逻辑）。完成标准：结论建立在"可执行性 + 磨损可控"上，而非"理论上层数越多越完整"。

1. **盘点方案与条件**
 - 列出手上每一套方案及其适用条件。
 - 完成标准: 每套方案都能说出"只在什么条件下用"。
2. **判定当前所在层**
 - 固定一套应对所有行情 = 第一层；只识别一号条件专用、其余不碰 = 第二层；多条件多方案匹配 = 第三层。
 - 完成标准: 能明确指认当前处于哪一层。
3. **核对可执行性与磨损**
 - 判停条件: 若多套策略"回测好但实盘做不到"、各策略磨损叠加、判断本身也有误判磨损 → 第三层判为不可用，**退回第二层**。
 - 完成标准: 写下是否出现执行跟不上、磨损越来越重。
4. **决定停留层**
 - 默认停在第二层（条件专用型）；第一层磨损严重需升级到第二层，第三层执行困难需退回第二层。
 - 完成标准: 明确写出"停在第几层"，并给出可执行性理由，而非"理论上更全"。
5. **收益提升走仓位管理**
 - 退回第二层后，靠仓位管理提升收益，不靠增加逻辑或方案数量。
 - 完成标准: 写出仓位调整方向；具体仓位数值原文未给，按 `position-allocation` 的评分分档执行（实现约定）。
6. **缺口与实现约定**
 - "一号条件"的具体判定指标、"退回"的时机标准、各策略磨损的量化测算——原文未给。
 - 实现约定: 以"当前方案是否明显不匹配、执行是否困难"作为人工判断依据，不脑补具体指标与阈值。

**实现约定**: 本卡的层次名称、退回动作与"靠仓位管理提收益"均来自原文口径；"一号条件"判定、退回时机、磨损测算与仓位数值原文只给方向未给数值，属**实现约定**，不改变"停在条件专用型、靠调仓而非加逻辑提收益"的原意。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **把三层当成长阶段时**。三层不是"越高越好"的成长路径，第三层理论完整但作者主动退回；不要把它当成从第一层一路升到第三层的进阶表。
- **把三层当进场模型分类时**。三层按"方案数量与适用条件"分，不描述进场结构；进场分类交给 `entry-model-taxonomy`。
- **默认多方案匹配为目标时**。理论可行但执行难、磨损叠加，不要因为"方案越多越专业"就往上走。
- **想靠加逻辑/加方案提收益时**。作者靠仓位管理而非增加逻辑提升收益；收益问题不要用加方案解决。

### 作者警告的失败模式

- **反复碰撞测试型**（ep-2026.11.17 L1780、L1810、L1814）。陷阱: 不管市场出什么状态都执行同一方案，像石头剪刀布永远出布。机制: 方案只在匹配条件下有效，无差别执行把不匹配情形也纳入亏损，磨损严重且痛苦。预警信号: "用同一招应对所有行情""长期痛苦、磨损重"。
- **多逻辑多品种执行不到**（ep-2026.11.17 L1888、L1896、L1901）。陷阱: 想在不同行情用多套策略。机制: 不同市场的行为/因子/风格差异大，判断本身有误判磨损，各策略还有各自磨损，叠加后收益不增反更累。预警信号: "回测好但实盘做不到""磨损越来越大"。
- **已盈利仍加方式数量**（ep-2026.11.17 L1983、L1996、L2016）。陷阱: 已能稳定盈利仍想找更多方式赚更多。机制: 多方案执行更累、效果不增。预警信号: "我想再找别的方式"。

### 作者的盲点 / 时代局限

- **"一号条件"无判定指标**。原文未给具体判定指标，只能靠个人识别能力判断。
- **"退回"无时机标准**。原文未给何时从第三层退回第二层（实现约定: 以执行困难、磨损明显为准）。
- **磨损无量化测算**。原文未给各策略磨损的量化方法，也未给"回测好但实盘做不到"的判定阈值。
- **平台与合规语境**。内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护；杠杆与滑点会放大磨损假设。内容不构成投资建议。

### 容易混淆的邻近方法论

- **成长三阶段**（`growth-path`）: 讲人随时间的认知进阶；本能力的三层是并列站位、不是时间阶段。
- **进场模型五分类**（`entry-model-taxonomy`）: 按进场结构分类；本能力按方案数量与适用条件分层。
- **放大优势**（`advantage-amplification`）: 讲放大优点、不补短板；本能力讲停在哪一层与条件专用。
- **静态复利**（`compounding-static`）: 讲固定比例复利；本能力只决定层次，收益提升交给仓位管理。
