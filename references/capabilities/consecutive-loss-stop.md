# 连损熔断（同一逻辑两次即停）

## R — 原文（Reading）

> 我一般是一个位置 / 连续损两次之后就是会停了 / 就是怕上头就会停了

— 交易员江河，ep-2026.7.17 L00814–L00824

---

> 就我只允许我一个交易逻辑 / 同样这个位置我只能做两次 / 因为我感觉我做第三次我就上头了

— 交易员江河，ep-2026.8.26 L01270

---

## I — 方法论骨架（Interpretation）

连损熔断是一条硬规则：**同一个交易逻辑（也可理解为一个位置）连续被否认两次，就停手**。第三次即使再给信号也不做，卖飞也认。"再一再二不再三"。

为什么是两次？第一次可以当失误；第二次就说明"你的系统在这个位置不匹配，或者你的进场太敏感"。第三次即使做了，成本与收益也不匹配——成本里除了钱还有**情绪成本**：单笔 2%、两笔 4% 尚可，连亏三笔 6% 之后情绪一上来，会"导致后面很多决策都是错误的"。所以停的不是这一天，停的是**这个逻辑**。

停 ≠ 当天不做了。正确姿势是：等这个逻辑走完、价格走出这个区域之后，再找下一次机会。而且"同一位置第一笔被损后，若逻辑并未被否认（例如只是插针打损），可以再做"——是否继续，判据是逻辑有没有被否认，不是单子有没有被打掉。

这条机制同时是**情绪与行情的双重过滤器**：连损两次往往代表"当前行情与你的逻辑不匹配"，用数据硬过滤，就不必靠主观判断"现在是不是震荡"。它是作者所说的"会两件事就爆不了仓"里的第二件事（第一件是带止损 + 以损定仓）。

补充判据（复仇模型）：假突破扫掉止损后，若价格反向出现"二次确认/二次推动"，可反手做一笔（先空后多或先多后空）。原文："这个时候我们可以反手干一件什么事 反手再多也就是一个复仇啊……所以说啊你只有两次机会 你只有两次机会 也就是你可以做一次复仇啊 你可以做一次复仇"（ep-2026-08-03 L576–L776）。反手这一笔计入"两次机会"：先反手一进，未接上可等二次进场信号（二进），只做一次复仇、拒绝第三次。原文未给"二次确认"的量化判据（**原文未给**）。

## A1 — 应用示例（Application Example）

### 示例 1: 学员反转策略每天五单、每单 3%、连损五单
- **类型与来源**: 转述案例（ep-2026.9.3 L04098–L04116）
- **问题/输入**: 学员自述专注 5 分钟做反转/深度回调，平均每天五单、每单 3% 止损；每隔几天会有亏损日，连亏五单（回撤 15%），往往靠晚间盘打回。
- **方法论的使用**:
 1. 数连损上限：五单 × 3% = 15%，远超"两次即停"的尺度 → 上限太高，必会上头
 2. 指出"回测数据告诉我下一单能打回来"正是侥幸心理，是上头最可怕的部分
 3. 给出修正：把连损上限从五单（15%）压到 10% 以内（对应同一逻辑两次即停的量级）
 4. 提醒：只经历两三个月、没经历牛熊周期，会遇到"千日砍柴一日烧"
- **结论**: 连损上限必须下调，同一逻辑两次即停。
- **结果**: 学员称大多能打回；作者预测其必会上头、会遇到大坑（未说明最终结果）。

### 示例 2: 学员"周一周二把周三到周五赚的钱亏完"
- **类型与来源**: 转述案例（ep-2026.9.9 L02600）
- **问题/输入**: 学员说"我容易周三周四周五赚，然后周一周二把赚的钱亏完，甚至还亏本金"，且这种情况已持续很久。
- **方法论的使用**:
 1. 先破归因：这不是"周几"的问题，是行情与逻辑不匹配
 2. 检查机制缺位：该学员没有连损熔断，前面亏损容易导致后续上头
 3. 给出三步：连损熔断 + 找出亏损行情的过滤器 + 提钱（资金隔离）
 4. 强调连损熔断的作用是"用数据硬过滤劣势行情"，不靠主观判断
- **结论**: 加装连损熔断，并按同一逻辑两次即停执行。
- **结果**: 原文未说明（作者给出连损熔断 + 提钱 + 行情过滤方案）。

### 示例 3: 扫损后翻盘——4 笔订单 3 盈 1 亏
- **类型与来源**: 作者亲历实盘（ep-2026-09-22 L126–L190）
- **问题/输入**: 在攻防一体位做空，第一笔被扫损，但整体逻辑未被否认（未创新高）。作者原话："然后我在这个位置只损了一次嘛……因为再一再二不再三……好像是一共做了四笔订单吧 然后其中有三笔盈利 然后一笔亏损啊"。
- **方法论的使用**:
 1. 判定"只损了一次、逻辑未被否认" → 同位置再进第二笔
 2. 第三笔机会按共振逻辑做
 3. 全天共 4 笔订单、3 盈 1 亏，无乱做行为；其中一笔扫损被作者视为"合理的扫损"
- **结论**: 同一逻辑同位置最多损两次；扫损不等于逻辑被否认，用"再一再二不再三"约束次数。
- **结果**: 3 盈 1 亏（原文未给各笔具体盈利金额，**原文未给**）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户刚连亏两单，问"还能不能在这个位置再做一次"。
2. 用户问"连损之后怎么办""要不要停手"。
3. 用户想给自己的交易系统加一条连损限度，问设几次合适。
4. 用户说"我每次连损之后就想把亏的打回来"。
5. 用户复盘发现自己总在某几天/某类行情里把利润亏光。

### 语言信号（用户的话里出现这些就应激活）

- "连损 / 连续止损 / 连亏几单"
- "要不要停手 / 熔断 / circuit breaker / max consecutive losses"
- "再一再二不再三 / 一个位置只做两次"
- "上头 / 想打回来 / 报复性交易"
- "千日砍柴一日烧 / 把利润亏光"

### 与相邻能力的区分

- 与 `risk-budget-and-circuit-breaker` 的区别: risk-budget-and-circuit-breaker 管**单笔风险额度**与**当日回撤熔断**（亏到当日上限就停一整天）；本能力管**同一逻辑的连续被否认次数**（同一逻辑错两次就停这个逻辑，不代表当天全停）。两者是不同维度的熔断，可叠加使用。
- 与 `position-sizing-by-stop` 的区别: 本能力是"会两件事就爆不了仓"里的第二件，position-sizing-by-stop 是第一件；前者防情绪失控，后者防单笔敞口失控。二者共同构成防爆仓的最小组合。
- 与 `trapped-order-triage` 的区别: trapped-order-triage 处理单笔被套单的去留；本能力处理"同一逻辑连续被否认"时的停手。被套单若逻辑未被否认而"再做一次"，必须计入本能力的计数。
- 与 `emotion-three-step` 的区别: 本能力是**规则层**（预先设好上限，由计数触发停手）；emotion-three-step 是**事后处理层**（亏损后按事实—感受—动作三步走）。规则在前，情绪处理在后。

## E — 可执行步骤（Execution）

**必需输入**: 已止损订单的**逻辑标识**（每笔单的进场逻辑一句话）与**位置区域**（逻辑否认点/关键位所在的价位区间）；该逻辑的累计被否认次数；单笔亏损比例；当日累计亏损（用于与 `risk-budget-and-circuit-breaker` 叠加）。缺失逻辑标识时，先要求用户补写；无法补写则无法判定"同一逻辑"。

**交付物与完成标准**: 输出一份**熔断判定** —— `是否触发停手`（是/否）、`命中逻辑的标识`、`累计次数`、`停手范围`（仅该逻辑 / 该位置区域）、`恢复条件`。完成标准：判定为"是"时，必须写明"停的是哪一个逻辑/位置区域"以及"什么条件下可以重新做这个逻辑"；判定为"否"时必须给出当前计数。

**实现约定**（原文未给，以下均为本卡的实现约定）:
- **"同一逻辑"的界定**：以"进场理由的一句话"为键。两笔单若**方向相同**且**进场理由的表述可归为同一条**（例如都基于"某位置回踩不破做多"），即判为同一逻辑；方向相反不算同一逻辑。
- **"同一位置"的界定**：以逻辑否认点为锚，取该价位上下各一个**容忍带宽**（默认＝该品种主周期上最近 3 根 K 线的平均振幅的一半；无法计算时取进场价与逻辑否认点距离的 20%）。两笔单的逻辑否认点落在同一带宽内，即判为同一位置。
- **恢复条件**：需同时满足 ① 价格已**走出**该位置区域（收盘价离开容忍带宽之外）；② 该逻辑的结构被重新建立（出现新的确认信号）。满足后计数归零，重新开始计数。
- **计数口径**：只统计**被止损/逻辑被否认**的单；被手动平掉的、未设止损的单不计入（但应另行标记为系统之外的错）。

1. **补写逻辑标识**
 - 完成标准: 每笔单都有一句"我做这笔单是因为 X"。
 - 判停条件: 无法补写 → 提示无法判定"同一逻辑"，终止本流程。
2. **判定是否同一逻辑/同一位置**
 - 完成标准: 按上文的键与容忍带宽，给出"是/否"。
3. **累计计数**
 - 完成标准: 给出该逻辑当前累计被否认次数（同一逻辑跨天累计，不按自然日重置）。
4. **触发判定**
 - 完成标准: 计数 ≥ 2 → 触发停手；否则给出"还剩几次"。
 - 判停条件: 触发 → 跳到步骤 5。
5. **执行停手并声明范围**
 - 完成标准: 明确写出"停的是哪个逻辑/位置区域"，并声明"第三次即使给信号也不做，卖飞也认"。
6. **给出恢复条件与复核点**
 - 完成标准: 写出恢复条件（走出区域 + 结构重建），并约定复核时点（例如每日收盘后复核一次）。
7. **叠加当日熔断**
 - 完成标准: 检查是否同时触发 `risk-budget-and-circuit-breaker` 的当日熔断；若触发，按更严格的一条执行。
8. **记录台账**
 - 完成标准: 记下逻辑标识、次数、停手与恢复时间，供复盘统计连损分布。
9. **处理"假突破扫损"后的复仇再进**
 - 完成标准: 若首笔系假突破扫损（逻辑否认点未被收盘穿越）、且价格反向出现二次确认 → 允许反手一次（复仇），并明确这是"两次机会"中的一次；未接上可等二次进场信号（二进），拒绝第三次。
 - 判停条件: 无二次确认 → 不得反手；已用过一次复仇 → 不得再进。原文未给"二次确认"的量化判据（**原文未给**）。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **把"停手"理解成"当天不做任何单"**。本能力停的是被否认的那个逻辑/位置区域；其他逻辑不受影响（若当天亏损已到上限，则由 `risk-budget-and-circuit-breaker` 全停）。
- **逻辑未被否认的单**。插针打损、逻辑否认点未被收盘穿越，不算"同一逻辑被否认"，不应计数。
- **方向相反的两笔单**。做多被止损后立刻反手做空，不属于"同一逻辑"；但反手本身要接受 `setup-gate` 与出口规则的检验。
- **用来当"不敢做"的借口**。停手是规则触发的结果，不是情绪化回避。

### 作者警告的失败模式

- **连损 / 上头 → 重仓、报复性交易、多开瞎开**（ep-2026.7.29 L00807–L00814、ep-2026.8.7 L00431–L00433）。陷阱：连续止损后心态崩去重仓；上头时逆势加仓、频繁打损；亏损后马上想打回来、报复性重进；情绪上头后多开、瞎开单。机制：用主观情绪去对抗客观事实，形成恶性循环；情绪（尤其亏损后）促使多开/瞎开，是亏损单的主要因子。预警信号："连损之后重仓""我主要就是逆势加仓然后频繁打损""非常想马上打回来""情绪波动时频繁下单"。
- **上头侥幸心理（"下一单能打回"）**（ep-2026.9.3 L04204–L04215）。陷阱：连损后不甘心，靠"前面数据表明最后一单能打回来"的侥幸继续加码。机制：最可怕的不是怕，而是侥幸心理——看到回测数据后会认为下一单一定行，从而上头、放大仓位、变形。预警信号："连损了但我回测数据告诉我最后一单能打回""连损后想今天就赢回来"。
- **千日砍柴一日烧**（ep-2026.9.3 L04342–L04350）。陷阱：连续多日/多笔盈利后自认"行了、牛逼了"，加仓，遇到一次连损上头，一把亏光。机制：没经历过完整牛熊/市场转换，把连续盈利误当能力。预警信号："我连续赚了15天钱""上仓位后遇连损""只经历两三个月没经历牛熊"。
- **剥头皮"较真" → 上头**（ep-2026-04-09 L2168）。陷阱：剥头皮回撤一两单后"较真"、非要打回来，进而上头、重仓。机制：原文"剥头皮最怕啥 最怕较真……就回撤一单 两单之后的一个较真 这最可怕"；一旦较真基本就废了，作者建议剥头皮不看盈利数字、只看 K 线；控制不了情绪的人，遇到可能引发情绪的情况就停止开单，不给情绪出来的机会。预警信号："回撤一两单后较真""非要打回来"。
- **同一位置反复止损后仍继续做**（ep-2026-07-29 L74、ep-2026-08-03 L772）。陷阱：同一位置反复止损后不放弃、继续投入。机制：原文"一个位置反复止损之后呢 就放弃交易 避免你上投投入的沉没成本太多……容易上头……你只有两次机会"——投入越多沉没成本越大、越容易上头，新人自控力不强时尤甚，故复仇最多一次。预警信号："一个位置反复止损还在做""止损次数已很多还想再试"。

### 作者的盲点 / 时代局限

- **连损次数说法不统一**。原文明确记录"两次/三单"两种口径（原文 即指出这一点）；本卡以"两次即停"为准，但使用者在自己的系统里选几次仍要自定。
- **"同一逻辑/同一位置"的粒度与容差原文未给**。本卡给出的键、容忍带宽、恢复条件全部是实现约定，不同品种、不同周期下需要重新标定。
- **熔断只防情绪，不防"逻辑本身一直错"**。若某逻辑长期不匹配市场，停两次只是止损，真正该做的是回到 `order-deconstruction-backtest` 拆订单。
- **标的与平台语境**。内容围绕黄金 CFD 与加密合约，作者自承数据行情滑点极大，"止损次数"在高滑点下会被放大；这类平台在中国大陆不受法律保护，作者本人也承认"不敢说自己是做这个的"。全篇不构成投资建议。

### 容易混淆的邻近方法论

- **"止损问题的根本解法是停止交易"**：作者说的是"能亏几次是自己定的，连损两次后就不做，自然就没有后续亏损"；这与"当天全停"不同，停的范围要写清。
- **"靠自控力忍住不做"**：本能力明确反对；它要求用计数规则触发，而不是靠意志力（意志力是消耗品）。
