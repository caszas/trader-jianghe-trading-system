# 从K线倒推多空行为

## R — 原文（Reading）

> 是什么什么呈现的这个K线K线也是表象 / 什么体现K线是什么的载体呀 / K线是什么的载体 / 价格波动的载体吗对吧 / 价格波动的载体吗 / 那价格波动又是什么呀对吧 / 那价格波动有可能是资金 / 资金运转的一个过程嘛 / 资金的一个轨迹嘛对吧 / 那谁控制的资金呢 / 那资金轨迹是谁控制资金呢 / 那人嘛对吧

— 交易员江河，ep-2026.9.24 L01221–L01304

## I — 方法论骨架（Interpretation）

K线不是信息本身，它是载体。把这条链走完：K线承载价格波动，价格波动是资金运动的轨迹，资金由人操作，于是所有图形最终都指向同一个问题——**现在谁在赚钱、谁在亏钱、谁被套住了**。

因此看盘的第一步不是给走势贴形态名字（M顶、双底、收敛三角），而是把走势翻译成持仓状态：这段上涨把做空的人套在哪？这段回落把做多的人解套了没有？最近一次价格脱离某个区域，改变了哪一方的盈亏？

方向是否成立，也被这条链重新定义：一个方向能延续，是因为推动它的一方还在获利、对手方还没被解套；当"谁在赚钱"开始换人，方向才真正发生变化。所谓"不变的东西"不是某个图形，而是这套行为结构——图形只是它的一种表达。

由此得到两个推论。第一，同一个逻辑可以用不同图形表达，所以图形名字不可靠（详见 `forget-patterns`）。第二，既然问的是行为，就必须看"怎么走出来的"（过程），而不只是"走到哪"（结果），这决定了要不要切小周期看微观过程。

新材料补了一条更基础的读法：看K线看的不是单根K线，而是K线的**变化**——"我们看的永远不是K线 看的是K线的变化 这句话一定要记住 看的是什么 K线的变化"（ep-2026.4.9 L1193、L1154）。单根K线没有意义，要看实体大小、影线占比的变化。配套给出一条可判定的口径："如果说一个K线的实体部分占比整根K线的50%以上我们就可以认为它是趋势型K线反之如果说一个K线中的影线部分占比整根K线的50%以上我们就可以认为它是非趋势性K线"（ep-2026.5.29 L791）。即：实体占整根 >50% ＝趋势型K线（代表某方掌控，越大越好）；影线占 >50% ＝非趋势型K线（代表多空分歧，越小越标准）；强弱是相对的，需与左侧K线对比。

新材料还把"谁在赚钱"往上抬到**共识**层面：市场不是验证客观真伪的实验室，而是由参与者共识定价的博弈场——"市场里唯一的对就是你的方向与市场共识的方向一致唯一的错就是你站在了市场共识的对立面"（ep-2026.7.17 L56、L113）。因此决策依据不是自己的估值判断，而是"当下市场里绝大多数的人他们相信什么他们的共识方向是什么"（ep-2026.7.17 L180、L200）；要放弃估值执念、用价格走势与市场反应去验证共识，而不是用自己的判断定义市场。生存前提是"快半步赚钱、快十步会死"，即先活下来。共识何时转向、如何识别，原文未给客观标准。

## A1 — 应用示例（Application Example）

### 示例 1: 9.16 连麦学员一小时解盘，多空都做
- **类型与来源**: 原书转述案例（reported_case，ep-2026.9.16 L01905–L01954）
- **问题/输入**: 学员按点位解一小时盘，同一个盘面同时给出做多和做空两套目标位。
- **方法论的使用**: 先问"现在谁在掌控、谁被套"，再谈节奏，最后才谈位置。学员跳过前两步，直接给位置，等于没有回答"谁在赚钱"。
- **结论**: 一个点位既当防守位又当关键位，多空理由都能自圆其说，说明背后没有统一的持仓行为判断，属于"博"。
- **结果**: 作者判定其"没有逻辑、逻辑不明确"（原书交代）。

### 示例 2: 9.23 学员认定"知组互换+M"可做
- **类型与来源**: 原书转述案例（reported_case，ep-2026.9.23 L01441–L01536）
- **问题/输入**: 学员指着某处"知组互换+M"说要在这做单。
- **方法论的使用**: 把图形还原成行为，检验该位置的"谁被套/谁解套"是否与别处不同；作者反问"盘面上知组互换和 M 到处都是，为什么单做这一个"。
- **结论**: 处处都有同样行为，则该点不构成独立信息，把"看着它下来了"当成能做，是把单次结果当逻辑。
- **结果**: 作者结论"没有用，别统计单点的这种情况"（原书交代）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户贴一段图问"这波到底是谁买上去的""现在谁在赚钱"，需要把图形翻译成多空持仓状态。
2. 用户把某个形态名（M顶、双底、头肩）直接当成方向依据，需要把它拉回到"行为"层面。
3. 用户解盘时做多、做空的理由都能说，判不出方向。
4. 用户问"为什么要看次级别/微观过程"，需要解释"看过程才能看到行为"。
5. 用户想知道"这个位置被套的人解套了没有"。
6. 用户问"看K线到底看什么""单根K线能不能作为依据"，需要给出"看变化"与趋势型/非趋势型口径。
7. 用户纠结"市场到底有没有客观对错""该不该相信自己的估值判断"，需要共识博弈框架。

### 语言信号（用户的话里出现这些就应激活）

- "谁在赚钱 / 谁被套 / 谁在亏钱"
- "这波涨是谁买上去的 / 资金怎么走的"
- "从K线倒推 / 从走势看行为"
- "裸K / naked chart / price action / market reading"
- "这段是上涨还是下跌（只给图形不给行为）"
- "看K线看什么 / 单根K线有没有意义 / 趋势型K线"
- "市场共识 / 顺应市场 / 我的判断到底对不对"

### 与相邻能力的区分

- 与 `forget-patterns` 的区别: 本能力回答"K线背后正在发生什么"；`forget-patterns` 回答"不要拿形态名字当依据、形态只是载体"。两者是同一条链的正反两面，本能力给正面答案，`forget-patterns` 做纠偏。
- 与 `key-level-reading` 的区别: 本能力产出的是"谁被套/谁赚钱"的行为结论；`key-level-reading` 把这些行为落成具体的区域坐标（交易位/参考位、攻防一体位）。
- 与 `trend-definition` 的区别: 本能力是趋势判断的输入（先看谁在赚钱）；`trend-definition` 把它固化成可复述的高低点规则（低点抬高=多头等），解决"不能看一根K线改方向"。
- 与 `strength-and-momentum` 的区别: 本能力问"谁"（持仓状态）；`strength-and-momentum` 问"强不强、还能不能延续"（节奏与动能）。

## E — 可执行步骤（Execution）

**必需输入**: 品种、周期（如 5 分钟/1 小时/4 小时）、要解读的时间区间；观察者须能指出该区间的高点/低点序列。
**交付物与完成标准**: 一份"行为结论"——当前谁在赚钱、谁被套、最近一次变化把谁套住/解套了；并标注该结论适用的周期与失效条件。

当能力被激活后，agent 应按以下步骤执行：

1. **圈定要解读的一段K线**
 - 完成标准: 能报出该段的最高点、最低点及其出现时间，区间长度明确。
2. **找出被反复测试的位置**
 - 完成标准: 至少列出 1 个"价格多次到达并产生反应"的价位/区域。
 - 判停条件: 若找不到任何有反应的位置（盘面没有参照），则本段无行为可倒推 → 输出"不做/换周期"，终止本流程。
3. **翻译成持仓状态**
 - 完成标准: 写出"在 X 位置，做多的人成本在…、做空的人成本在…"，并标明当前谁浮盈、谁浮亏。
4. **找出最近一次状态改变**
 - 完成标准: 指出最近一次价格脱离该区域的方向，并写出"这次脱离把谁套住、把谁解套"。
5. **用一句话回答"现在谁在赚钱"**
 - 完成标准: 句子形式为"当前盈利的是 X 方，因为…；被套的是 Y 方，因为…"，句中不含"感觉""应该""大概"。
6. **标注周期与失效条件**
 - 完成标准: 写明"该结论基于 N 分钟图；若价格…则结论失效"。
7. **判定K线性质（趋势型 / 非趋势型，新增）**
 - 完成标准: 对关注K线给出判定——实体占整根 >50% ＝趋势型（某方掌控），影线占 >50% ＝非趋势型（多空分歧）；并说明"看的是变化"（与左侧K线对比），不孤立看单根。
 - 口径说明: 50% 阈值由原文给出（ep-2026.5.29 L791），不是实现约定；"与左侧K线对比判强弱"亦为原文口径。

**实现约定**: 本能力不引入任何新指标；"有反应的位置""状态改变"的力度阈值原文未给出，属使用者约定，取值不改变"把 K线还原成多空行为"这一原意。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **只有一根K线时**。单根K线不足以承载"谁被套/谁赚钱"的持仓状态，应等走出结构再看（转 `trend-definition`）。
- **想用它预测方向时**。本能力只还原已发生的行为，不产出未来预测；预测/埋伏的替代做法见 `two-way-playbook`。
- **平台与合规语境**。本内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护；作者本人自承"不敢说自己是做这个的"。本能力是一套看图方法，不构成投资建议，也不适用于受监管市场的合规下单或任何形式的代客操作。

### 作者警告的失败模式

- **单点思维**（ep-2026.8.3 L1194–L1245）。陷阱：只看方向、或只看位置/关键位、或只看某个信号（如金叉）就下单。机制：单因子在不同背景下结果相反，关键位到处都是、到处都出反应，单一因子必然抖损；决策是条件的总和。预警信号："有没有一招""就一个点""MACD金叉就买死叉就卖""这全是位置"。
- **用指标绕弯 / 号称裸K却加指标**（ep-2026.7.17 L0893–L0925）。陷阱：一边说用裸K，一边加一堆杂七杂八的指标。机制：明明能直接看价格行为，却非要"多干一步"绕远路，自相矛盾。预警信号："点开那些乱码七糟的指标""裸K加一些指标"。
- **拿图形去交易 / 预测市场**（ep-2026.8.10 L875–L896）。陷阱：沉迷画三角形、圈形、趋势线，以为形态本身能决定行情。机制：图形只能代表之前发生的事、只能提炼信息；市场不会因为画了三角形就按三角形走。预警信号："像不像收敛三角""研究形态/破三角形""把技术分析当画图游戏"。
- **把实体K线当影线合并**（ep-2026.9.9 L1159）。陷阱：把实体K线人为合并、当影线处理。机制：忽视K线给出的真实博弈信息，属于自我欺骗，"你他走出实体你都能把它当成影线，那你还看啥K线呢"。预警信号："给他合并一下""硬找理由"。

### 作者的盲点 / 时代局限

- **追问链的终点不可量化**。链条最后落到"人/逻辑"，但"谁被套了多少""这批订单是否还在"没有任何数据支撑，判定高度依赖主观读解；作者自己承认手工交易赚钱"取决于两个字——主观"。
- **原文未给量化标准**。"有反应""状态改变"的力度阈值、切到哪个次级别周期看过程，原文均未给出。
- **"共识转向"缺识别标准**。新材料把决策依据抬到"顺应市场共识"层面，但"共识何时转向/散场"原文未给客观识别标准；"顺应共识"落地时仍依赖对价格走势与市场反应的读解。
- **平台语境与极端行情**。黄金 CFD 与加密合约在数据行情下"杠杆会调、滑点非常大"，K线承载的行为信息在跳空与滑点中会失真，本能力无法覆盖。
- **素材为直播口语**。未讨论不同品种流动性差异对"行为"解读的影响，也未讨论同一逻辑在低流动性品种上的失效。

### 容易混淆的邻近方法论

- **缠论的"笔/线段/中枢"**：那套用固定规则把走势切成可复制的段，追求"同一图形同一结论"；本能力拒绝固定图形，只问持仓行为。
- **订单流 / 足迹图（footprint）**：同源于"看订单"，但订单流依赖逐笔成交与盘口数据；本能力只看K线（作者认为"指标儿能体现的东西 K线全能体现"）。
- **形态学（pattern recognition）**：以图形名字为交易依据，与本能力"图形是载体、行为才是内容"的立场相反。
