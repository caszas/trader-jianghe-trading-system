## I — 方法论骨架（Interpretation）

趋势不是感觉出来的，是用高低点定义出来的：低点不断降低、高点也不断降低 = 空头；低点不断抬高、高点也不断抬高 = 多头。所有"做结构"的趋势判断，本质上都归结为高低点的变化。

方向的改变（打破结构）需要**两条同时成立**：第一，原方向的**防守位被打掉**；第二，打掉之后**走出延续**（走出新结构，即"U 中 U"）。只满足第一条不算方向改变——那只是"可能发生结构转变"，必须再看到延续才算数。这正是"不能看一根K线改方向"的规则化表达：单根阴线/阳线不构成方向改变，方向改变是"防守位被打掉 + 走出延续"的联合事件。

另外，盘中只能识别"是不是初期"，识别不出中期与末期——中期/末期只有走出来之后才能知道，"能识别出末期全是意淫"。因此作者的划分只有两类：初期 / 非初期。到关键位也不代表末期，关键位只是"潜在的转折点"，且它本来就是用来被突破的。

**摆动高低点的确认（实体突破影线）**：为过滤噪音，作者"会习惯性的等待K线实体部分突破前方K线的影线部分，才认为这是一次新高点或者新低点的成立"；仅影线突破不算有效结构——ep-2025-11-23 L433。这为本卡"如何确认一个摆动高低点"补上了原文判据。

**最后回撤结束点与"回调变反转"**：判断趋势是否转变，可标记"最后一段趋势的回撤结束点"——一旦被后续价格打破，大概率趋势转变（或转震荡）；若再形成新的高低点变化则确认反转。特殊情况：回调离上次回撤终点很远、且连续很多根K线都无法回调结束，可判为回调直接变反转——ep-2025-10-12 L61、L130、L196（"离上次终点非常远""连续很多根K线"的量化标准**原文未给**）。

**强势市场很难直接反转，先转弱**：强势市场在结构未被打破前很难直接反转，节奏发生转变后一般先转弱（弱震荡／弱上涨）。因此不要一见反向K线就认定反转，可先按"转弱后延续原方向／转震荡"处理，除非最后防守位被打破——ep-2026-01-10 L0071、ep-2026-01-16 L0103（"强势／弱势"的量化标准**原文未给**）。对应的方向调整：原做多的发力点被一段强势下跌打破后，直接做多已很困难，更合理的是转为做空偏向，或等一小时形成明确的下跌结构延续再做空——ep-2026-04-03 L0008。

**有效回撤由流动性清扫判定**：回撤若清扫（吞没／突破）了前一根创造极值的K线的流动性，即为有效回撤、需要画；未清扫则为无效回撤、不画——ep-2026-07-28 L143、L157、L200（"清扫"的最小穿透幅度**原文未给**）。

**行情阶段的三分口径（与"初期/非初期"的调和）**：作者在另处用"初期／中期／末期"三分法表述——"行情阶段分为三个时期……初期 其次中期 最后末期"，并明确"末期跟初期不在我们的交易范围之内，我们的交易范围只是一个中期；初期是参考，中期是交易"——ep-2026-07-27 L9、L225。这与本卡"识别上只分初期／非初期"并不矛盾："中期"指初期确认后**走出延续的那一段**（≈本卡的"非初期"），是交易目标；"末期"仍只有走出来才知道、不做。**识别层不得预测中期／末期，交易层只做延续段。**

**取舍：只做趋势行情**：作者的原则是"简单的交易一般存在于趋势行情中，非趋势行情的交易是困难重重的"，非趋势（震荡）行情多为无序震荡，应谨慎或放弃——ep-2025-10-09 L243。这是本卡与 `range-market-playbook` 的分工依据：趋势不清即转震荡手册，不硬做。

## A1 — 应用示例（Application Example）

### 示例 1: 9.4 四小时黄金解盘三方案（含"走出结构延续"分支）
- **类型与来源**: 原书演示（ep-2026.9.4 L2324–L2340）
- **问题/输入**: 黄金四小时盘面，作者给出三种走向下的应对。
- **方法论的使用**: ①回到下方区域站稳 → 做低多；②没回到该位置、中途往上折并**走出一个结构延续** → 等回踩再做；③直接破下去 → 不管（不在认知逻辑内）。方案②正是"防守位被打掉 + 走出延续"这一方向改变判据的应用：光"折上去"不够，要走结构延续。
- **结论**: 方向改变要看到延续；没走出延续的折返不构成新方向。
- **结果**: 原书作为解盘演示，未交代后续实际走势结果。

### 示例 2: 合成演练——同一段走势的"改方向"判定
- **类型与来源**: 原书未提供该情景的独立案例，以下为合成演练（口径来源 ep-2026.9.24 L1908–L1928）
- **问题/输入**: 某品种 1 小时图，原本低点不断抬高（多头结构）；出现一根大阴线，收盘跌破最近一个"低点"（原防守位），用户问"是不是转空了"。
- **方法论的使用**: 按定义拆两步——第一步看防守位是否被打掉（已打掉）；第二步看是否走出延续（后续是否走出新的更低高点+更低低点的结构）。若只是打掉后价格又收回、没走出延续，则方向未改变。
- **结论**: 只满足第一条 → 判为"未改方向，仅结构可能转变"；须等延续确认。
- **结果**: 合成演练，无真实成交结果（未说明）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户问"现在是什么趋势 / 是多是空"，需要一个可复述的定义而不是感觉。
2. 用户看到一根阴线/阳线就说"方向变了"，需要把它拉回到"防守位 + 延续"两条判据。
3. 用户问"结构打破了没有 / 打掉了防守位算不算转势"。
4. 用户问"现在是行情的初期还是末期"。
5. 用户说"我一阳就改三观"，方案一天改几次。
6. 用户问"这次是回调还是反转""最后一段回撤的结束点在哪""强势的走成这样会不会直接反转"。
7. 用户问"哪次回撤值得画""这根算不算新高/新低（影线破了算不算）"。
8. 用户想"行情到末期了该反手了"，或问"现在做初期还是中期"。

### 语言信号（用户的话里出现这些就应激活）

- "趋势 / 方向 / trend / structure"
- "低点抬高了吗 / 高点降低了吗"
- "防守位被打掉了，是不是转势了"
- "结构延续 / U中U / 打破算不算延续"
- "这根阴线出来是不是要转空了"
- "回调还是反转 / 最后回撤结束点 / 有效回撤 / 流动性清扫 / 实体突破影线 / 能不能做中期"

### 与相邻能力的区分

- 与 `range-market-playbook` 的区别: 本能力判定"有趋势时方向是什么"；`range-market-playbook` 判定"无趋势（震荡）时怎么做"。画不出趋势就是震荡，两者是行情三分类的互补两面。
- 与 `internal-external-structure` 的区别: 本能力在主周期（外部结构）上定义趋势；`internal-external-structure` 说明内部结构的唯一作用是帮你明确外部结构，不能拿内部结构直接做决策。
- 与 `strength-and-momentum` 的区别: 本能力回答"方向是什么"；`strength-and-momentum` 回答"这个方向强不强、还能不能延续"。方向定义是强弱判断的前提。
- 与 `timeframe-contract` 的区别: 本能力的定义必须在某一确定的主周期上执行；主周期怎么选、次周期怎么配由 `timeframe-contract` 决定。

## E — 可执行步骤（Execution）

**必需输入**: 主周期 K 线图；可辨认的摆动高低点序列（至少 2 个高点 + 2 个低点）；原方向的防守位价格。
**交付物与完成标准**: 一个方向定义（多头/空头/未定义）+ 支撑该定义的高低点列表 + "是否发生方向改变"的两条判据结论。

当能力被激活后，agent 应按以下步骤执行：

1. **标注摆动高低点**
 - 完成标准: 在主周期上至少标出 2 个高点与 2 个低点，并给出各自价格。
 - 完成标准（确认规则）: 新高/新低以"K线实体部分突破前方K线的影线部分"为准；仅影线突破不算有效结构（ep-2025-11-23 L433）。
2. **用高低点变化定义方向**
 - 完成标准: 输出"多头/空头/未定义"——低点与高点同时抬高=多头，同时降低=空头，交替或混乱=未定义。
 - 判停条件: 若判为"未定义" → 转 `range-market-playbook` 判定是否震荡，本流程终止。
3. **标出原方向的防守位**
 - 完成标准: 给出一个明确价格（原方向上最近一个被确认的关键低点/高点），并说明"打掉它即代表原方向可能被否认"。
4. **判定防守位是否被打掉**
 - 完成标准: 明确写出"打掉/未打掉"，并给出依据（收盘价穿越还是仅影线穿越）。
 - 判停条件: 若未打掉 → 判为"原方向延续"，输出结论并终止。
5. **判定是否走出延续**
 - 完成标准: 打掉防守位后，检查是否走出新结构（新的更低高点+更低低点，或反之）；写明"已走出延续/未走出"。
6. **输出方向改变结论**
 - 完成标准: 只有"防守位被打掉 + 走出延续"两条同时成立，才输出"方向改变"；否则输出"结构可能转变，方向未改变"。
7. **标记回撤（用于判转变与画结构）**
 - 完成标准: 标出"最后一段趋势的回撤结束点"，一旦被打破 → 判"大概率转变或转震荡"；回撤是否有效以"是否清扫前一根创造极值K线的流动性"判定（清扫=画，未清扫=不画）（ep-2025-10-12 L61；ep-2026-07-28 L143、L157、L200）。
8. **判定行情阶段（识别层 + 交易层）**
 - 完成标准（识别层）: 只输出"初期／非初期"两值，不得预测"中期／末期"。
 - 完成标准（交易层）: 交易范围只取"初期之后的延续段（≈中期）"；"末期"与"初期"均不做，初期仅作参考（ep-2026-07-27 L9、L225）。

**实现约定**: 原文未给"摆动高低点如何确认""延续需要几根K线""初期如何量化"的判据；本卡的"至少 2 高 2 低""收盘价穿越""只输出初期/非初期"为**实现约定**，取值不改变"高低点定方向、防守位被打掉 + 走出延续才算改方向"这一原意。摆动高低点确认已有原文判据（实体突破影线，ep-2025-11-23 L433）；"最后回撤结束点被打破""清扫流动性=有效回撤"亦为原文口径，但其量化（多远算远、几根算多、清扫幅度）**原文未给**。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **主周期未确定时**。没有主周期就没有"防守位"和"高低点"的判定基准，先由 `timeframe-contract` 定主周期。
- **想用它预测末期时**。本能力只能识别初期，中期/末期走完才知道；任何"现在到末期了"的判断都是事后脑补。
- **想用它一见反向K线就判反转时**。强势市场在结构未被打破前很难直接反转，节奏转变后一般先转弱；见到反向K线不要立刻判反转，除非最后防守位被打破（ep-2026-01-10 L0071、ep-2026-01-16 L0103）。
- **用它替代强弱判断时**。方向明确不等于可做，强弱与可做性是两个问题（见 `strength-and-momentum`）。
- **平台与合规语境**。本内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护，作者本人自承"不敢说自己是做这个的"。本能力是趋势定义方法，不构成投资建议，也不适用于受监管市场的合规下单。

### 作者警告的失败模式

- **没有一致性的定义/规则，被盘面牵着走**（ep-2026.9.24 L1888–L1913、ep-2026.9.28 L1577–L1844）。陷阱：无一致性标准，看阴线就走空、看阳线就走多，被一两根K线左右、"一阳就改三观"。机制：心里没有规则和评判标准，就会被盘面牵着走，方向一会儿一变，方案随K线反复重建。预警信号："一会儿说走多一会儿说走空""往回两根K线就说走空""一根K线就改方向""方案一天改几次"。
- **把"打破"当成"延续"**（ep-2026.9.16 L2003、ep-2026.9.24 L140、ep-2026.9.28 L2781）。陷阱：价格打破关键位后，直接当成"方向已延续/已改变"就顺势进场。机制：打破只是"可能转变"，需再走出结构延续（U 中 U）才算；作者原话"没有形成一个 U 中 U，也就是没有形成一个结构上的一个延续，重点在这个点能不能破"。预警信号："打破了就是延续了""破位了就顺势做"。

### 作者的盲点 / 时代局限

- **摆动高低点的确认规则部分给出**。作者补了一条确认判据——"K线实体部分突破前方K线的影线部分"才算新高/新低成立（ep-2025-11-23 L433）；但"用几根K线、什么标准确认一个摆动点"仍未给，实际标注仍有主观空间。
- **"走出延续"的量化未给**。"走出一个延续"需要几根K线、多大幅度，原文未定义，本卡按"新结构成立"操作化，属实现约定。
- **"初期"判据缺失**。作者只给"初期/非初期"二元划分，但未给"初期"的量化判据，实际仍靠经验。
- **有效回撤与"回调变反转"的量化未给**。"清扫流动性=有效回撤"（ep-2026-07-28 L143、L157、L200）、"最后回撤结束点被打破=大概率转变"（ep-2025-10-12 L61）均为原文口径，但"清扫的最小穿透幅度""回调离终点多远算远、几根K线算多"**原文未给**。
- **平台语境**。内容围绕黄金 CFD 与加密合约（在中国大陆不受法律保护）；素材为直播口语，同一场直播对"打破"与"延续"的表述时有压缩，本卡以 的定义为准。

### 容易混淆的邻近方法论

- **道氏理论的趋势定义**：同样用高低点定义趋势（更高的高点与更高的低点=上升趋势），但道氏强调"确认"与"相互验证"；本能力的"防守位被打掉 + 走出延续"是作者口径下的改造版，不涉及成交量验证。
- **均线多头/空头排列**：用均线排列判定方向，属于指标法；作者明确不看指标（"指标儿能体现的东西 K线全能体现"）。
- **缠论的"趋势/盘整"与"走势类型"**：用固定规则递归判定；本能力只用高低点与防守位，规则更粗，但作者承认"做结构的"判断本质相同。
