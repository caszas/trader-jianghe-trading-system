# 管不住手 / 执行不到位的根因诊断

## R — 原文（Reading）

> 就两个原因啊／第一个原因你不想管／第二个原因你不知道怎么管／就没有交易逻辑／你不知道该执行什么

— 交易员江河，ep-2026.8.3 L01315–L01396

---

> 你实际上这句话背后的意思是啥／我他妈懒／我不想构建一个系统／我也构建不出来／我能不能就是凭我感觉随便做对吧

— 交易员江河，ep-2026.8.14 L02127–L02147

## I — 方法论骨架（Interpretation）

"管不住手"不是一种病，而是一个需要分诊的症状。作者给出两个根因：一是**不知道该怎么管**（没有交易逻辑，不知道该在什么情况下做、什么情况下不做，纯感觉交易）；二是**不想管 / 知道却不用**（他称为心理疾病问题）。第一种可解，第二种解决不了，只能靠亏疼。

进一步把第一种细分为两类：

- **没有逻辑**：完全没有一套"什么情况做、什么情况不做"的规则 → 处方是建立逻辑（进 `trade-system-build`）。
- **逻辑不全**：有规则但不完整，典型表现是"本来要等某信号进场，却提前进场"。作者指出这种"提前"本质是**不相信自己的逻辑**——如果你真信那个信号有用，你不会抢跑。

所以分诊的输出是三选一：`无逻辑` / `逻辑不全` / `心理问题`。前两者可解（建立／补全逻辑，并用数据说服自己），第三者只能靠亏损本身教育。

关键判断：**"管不住手"往往被误诊为"意志力问题"**。作者把大量"管不住手"重新归因到"逻辑不明确 / 不自信"上——不是你不肯管，是你没有一个你真正相信、且足够完整的规则去管。

补充（新材料的处方层）：针对"知道却不用"，原文给了可执行的处方，补上本卡"心理问题一档"的空缺——

- **执行三方案**（ep-2025-11-23 L753）：如何让自己毫不犹豫地执行一个交易系统？原文："如何能让自己 毫不犹豫地去执行一个交易系统呢 有三个方案 第一呢是外在干预 有奖惩机制 或者说外在的他人强行干预"——① 外在干预（奖惩机制、他人强制）；② 逻辑深入（详细论述、自我辩证，发自内心认同）；③ 数据支撑（用大量样本看到结果、建立信心）。作者推荐后两条，外在干预只作兜底。
- **知行合一的原动力**（ep-2026-01-31 L140–L181）：做/学任何事前先问"我为什么要做这件事、为什么这么做"，把原动力找出来；答不上来说明这事对你没那么重要，就别做、别学。并把学习从被动（被推送/被安排）改成主动（带着具体问题去搜、去解决）。原文："一定要清晰的问自己 我为什么要做这件事儿 我为什么要这么做 把这个原动力给找出来"。
- **压力源于欲望高于能力**（ep-2026-09-25 L18–L48）：交易压力的根源是"你的欲望跑在了能力的前面"，解决方案二选一——提高能力（把刷视频打游戏的时间拿去学习复盘打磨系统），或降低欲望（把目标降到与当前能力匹配，先做到不亏、先活下来）。原文未给"能力"的可衡量标准（**原文未给**）。

## A1 — 应用示例（Application Example）

### 示例 1: 合成演练——分诊"总是提前进场"
- **类型与来源**: 原书未给带标签的诊断案例；以下为合成演练，判据取自 ep-2026.8.3 L01315–L01396。
- **问题/输入**: 用户说"我的系统写着要等回踩确认再进，但我总是没等到就先进了"。
- **方法论的使用**:
 1. 问：你知不知道正确做法？→ 用户能答出（等回踩确认）。排除"无逻辑"。
 2. 问：为什么没等到？→ 用户答"怕错过"。→ 归为"逻辑不全 / 不相信自己的逻辑"。
 3. 处方：用回测把"等确认"的样本跑出来，用数据证明确认后进场的结果（对应 `order-deconstruction-backtest`）。
- **结论**: 诊断 = 逻辑不全（不相信自己的逻辑），不是意志力问题。
- **结果**: 未说明（合成演练）。

### 示例 2: 原书转述——学员拿不住单
- **类型与来源**: 原书转述（cB3-03，ep-2026.8.26 L00982–L01013）。
- **问题/输入**: 学员在 4633 做空、用 AB=CD 测算目标 4614，价格回调到 4628 看到疑似双底就不敢持有、提前离场。
- **方法论的使用**: 作者判定其进场点与目标测算都合理，拿不住的根因是"不信自己能赚到钱"——属于"逻辑不全 / 不自信"，而非意志力。
- **结论**: 处方是"用该方式回测 1000 单、拿数据建立信心"，并拆解亏损订单找因子。
- **结果**: 未说明（原文只说提前离场，未交代最终盈亏）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户说"我管不住手 / 我执行力不行"，但说不清具体卡在哪。
2. 用户有系统但总提前进场或提前离场。
3. 用户完全没有规则，凭感觉做单，问"怎么才能管住自己"。
4. 用户已经反复失败，怀疑自己"是不是心态／心理有问题"。
5. 用户想直接要一个"管住手"的方法。
6. 用户说"我有系统、也懂道理，但就是执行不了 / 执行变形"（对应"执行三方案"与"知行合一"）。

### 语言信号（用户的话里出现这些就应激活）

- "我管不住手 / 我执行力差 / 我做不到"
- "懂了做不到 / 知行合一 / 我有系统但执行不了"
- "我知道该怎么做但就是不做"
- "我凭感觉做 / 我看盘感 / gut feeling"
- "我是不是心理有问题 / 要不要先修心"
- "root cause / 为什么管不住手"

### 与相邻能力的区分

- 与 `rules-over-mindset` 的区别: 本能力是**分诊**（先判断根因属于哪一类），rules-over-mindset 是针对"心理／习惯层"的**处方**（用规则替代意志力）。顺序：先分诊，只有落到"知道却不用"时才用 rules-over-mindset；若诊断为"无逻辑"，处方是建逻辑。
- 与 `trade-system-build` 的区别: 当诊断为"无逻辑"时，交给 trade-system-build 建立系统。
- 与 `order-deconstruction-backtest` 的区别: 当诊断为"逻辑不全 / 不自信"时，用回测拿数据说服自己。
- 与 `setup-gate` 的区别: setup-gate 判断"这一单该不该做"；本能力诊断"为什么你总是做了不该做的"。

## E — 可执行步骤（Execution）

**必需输入**: 一个具体的"管不住手"行为（越具体越好）；用户能否说出"正确做法是什么"；该行为发生的频率与场景。缺失时问："你管不住的具体是哪个动作？""你自己觉得正确做法是什么？"

**交付物与完成标准**: 一个三选一的诊断标签（`无逻辑` / `逻辑不全` / `心理问题`）+ 对应的下一步处方。完成标准：诊断结论与"用户能否说出正确做法""说出后是否照做"两个回答一致，且处方指向唯一一个下游能力。

**实现约定**: 两个根因（不想管 / 不知道怎么管）与三分类出自原文；"用两个提问做分诊"为**实现约定**。

1. **锁定具体行为**
 - 完成标准: 行为可被描述为一个动作 + 场景（如"连亏两单后加仓"），而非"执行力差"。
2. **问一：你说得出正确做法吗？**
 - 完成标准: 得到明确的是／否。
 - 判停条件: 若答"否 / 说不清" → 诊断 = `无逻辑`，处方 = 去 `trade-system-build` 建立系统，**结束本流程**。
3. **问二：说得出，那你照做了吗？**
 - 完成标准: 得到明确的是／否。
 - 判停条件: 若答"是，但总提前／变形" → 诊断 = `逻辑不全 / 不自信`，处方 = 用 `order-deconstruction-backtest` 拿数据建立信任，结束。
4. **判定是否为心理问题**
 - 完成标准: 在"能说出正确做法、也有数据支持，但仍明知故犯"时，诊断为 `心理问题`。
5. **给出对应处置**
 - 完成标准: `无逻辑`→建逻辑；`逻辑不全`→补全并相信逻辑（回测）；`心理问题`→承认只能靠亏疼，配合 `rules-over-mindset` 的外部约束兜底。
6. **给出执行方案（对应"知道却不用"一档）**
 - 完成标准: 先问"我为什么要执行它"（找原动力，答不上来说明该行为对你并不重要，不必强行要求）；再按三方案给出具体动作——外在干预（奖惩/他人强制，兜底）、逻辑深入（自我辩证到内心认同）、数据支撑（回测样本建立信心）；可叠加"降低欲望/提高能力"。
 - 判停条件: 原动力答不上来 → 先不强行要求执行。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **把所有"管不住手"都归为意志力问题**。这是最常见的误诊；作者把大量案例归到"逻辑不明确／不自信"。
- **在诊断为"无逻辑"时先谈心态**。没有逻辑时谈心态是空转，先建逻辑。
- **指望"心理问题"这一档能被方法解决**。作者明说这类解决不了、只能靠亏疼；把它当成可训练项会反复失望。

### 作者警告的失败模式

- **凭感觉 / 盘感交易**（ep-2026.8.14 L02127–L02147）。陷阱：不建系统、凭"我感觉"做决策；机制：感觉无法量化、不可验证，且常与真实数据相反（作者称有人感觉适合剥头皮，实际 20% 胜率、盈亏比 1:0.8），盘感不可复制；预警信号："我感觉我适合做短线""我懒不想构建系统""能不能只靠盘感"。
- **拿感觉判断自己行不行**（ep-2026.8.26 L02211）。陷阱：用感觉判断自己成没成，而不是看资金曲线；机制：感觉是臆想，资金曲线才说明一切；预警信号："我感觉我挺牛逼""我模拟盘比实盘好怎么办"。
- **拿不住单（不信自己能赚到钱）**（ep-2026.9.3 L00518）。陷阱：持仓中因害怕反转提前离场；机制：根因是不相信这套方式能赚钱，解决靠回测数据建立信心；预警信号："看到双底就不敢持有""害怕行情反转"。
- **靠自控力对抗上头**（ep-2026.8.5 L01095）。陷阱：靠意志力；机制：自控力在峰值失效；预警信号："我只靠意志力"。

### 作者的盲点 / 时代局限

- **"心理问题"这一档是黑箱**。作者把它归为"解决不了、只能靠亏疼"，等于放弃了对这一档的方法论建设；对真正需要心理干预的人，这是不充分的。（**部分修正**：新材料补入"执行三方案""知行合一原动力""压力源于欲望高于能力"（见 I 段），为"知道却不用"提供了可执行处方；但作者仍将其定性为"只能靠亏疼"，处方层与定性之间存在张力。）
- **分诊依赖用户自陈**，而"说不说得清正确做法"本身受表达能力和认知影响，可能误判。
- **标的与平台语境**。内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护；本能力是执行诊断工具，不构成投资建议。

### 容易混淆的邻近方法论

- **执行力培训**：假设"知道但做不到"是意志问题；本能力先排除"不知道"这一更大可能。
- **心态调整**：把症状当病因；本能力把"管不住手"当症状，去找根因。
