## I — 方法论骨架（Interpretation）

这个能力是"你在哪个阶段、现在该做什么"的判据集，不是励志话。

**成长三阶段（资金视角）**：① 积累经验（用最小成本，仓位百一／百二，先活下去）；② 用经验换财富；③ 守住财富。顺序不能跳——很多人做反了，该积累经验时拿资金大展拳脚，到该积累财富时筹码已被洗下桌。

**学习三阶段（认知视角）**：① 傻抄／找相似（找一个流派照做，四处站队、拿别人的东西对照自己）；② 拼补／寻找自己（各取优点、做取舍，只留自己完全懂底层逻辑的部分）；③ 内化衍生（在拆条件中发现某套逻辑的缺点，用自己的思考解决它，衍生出属于自己的框架）。作者判断"大多数人都在第一阶段"。

**状态三阶段（心理视角）**：① 初生牛犊不怕虎（挣不着钱）；② 与系统合一（不看金额、给机会就干，赚钱最快但短暂）；③ 在乎得失（回头看发现自己有钱了，开始焦虑犹豫）。对应处置：第二阶段猛冲，第三阶段降仓平衡。

**技术过关判据（"快成了"）**：把账户周期拉长（半年以上，或按笔数），扣除手续费磨损后曲线基本平衡移动、一直小亏小赚、钱亏不没——就是技术过关。顿悟、刚懂、刚过关都不算。

**底线／上限模型**：技术只决定底线（最差不亏），不决定上限（最多赚多少）；上限由行情、筹码分配、认知、性格、价值观、环境、身体等决定。所以"技术过关"是起点不是终点。

**资金成长阶段（另一处口径）**：作者把"从 7 万到 1000 万"分为三阶段——①**磨刀**（学习 → 初步构建系统 → 回测发现问题 → 执行，先获得一个赚钱的能力）；②**原始财富积累**（靠爆发式收益与筹码分配快速积累）；③**复利**（让时间把概率优势显现出来）——ep-2025-12-26 L13。另一处口径与"成长三阶段"一致：①积累经验（先活下去）②积累财富③守住财富，并补充第三阶段的动作是"只在认知内下注，不是机会就空仓弃牌"——ep-2026-08-10 L94、ep-2026-09-05 L172。

**阶段关注重心模型**：作者按资金阶段给出精力该放哪里——**0→1 重心在"我要做什么行情"**（选行情、找机会）；**1→100 重心在"我用多少做"**（筹码分配、仓位）；**成熟期重心在"什么情况下不做"**（过滤、弃牌）——ep-2026-09-05 L159、L172。用于提醒在不同阶段把精力放在对的地方。

**学习六层认知模型（学习三阶段的细化）**：把学习拆成层级并给出每层判据——①浏览（看过）；②记忆（能准确复述默写、不偏差不遗漏）；③理解（能换种说法讲清楚、能区分"是什么"与"不是什么"）；④应用（脱离资料在对应场景独立操作）；⑤分析（拆解知识构成、梳理完整因果链、搭建体系）；⑥独立判断／思辨（质疑前提、论证对错、指出边界）；⑦创造（产出可复用方法体系），最后内化迁移（变成思维本能、可跨领域）——ep-2026-06-18 L15、L57、L82、L112、L132。作者判断"大多数的人呢都只停留在了浏览的这个阶段"。

**小白学习顺序**：先了解市场运转再学技术——先弄清市场与平台怎么运转（合规／不合规市场、国内外市场、MT4／MT5、券商、期货、保证金与交易规则）→ 了解参与者（对手盘都是谁，用真实数据看）→ 认清自己 → 再学技术、再尝试交易——ep-2026-07-25 L966、L1023。

## A1 — 应用示例（Application Example）

### 示例 1: 合成演练——阶段自评
- **类型与来源**: 原书未提供自评表；以下为合成演练，判据取自 ep-2026.8.5 L01604、ep-2026.8.5 L00246–L00249、ep-2026.9.29 L00953–L00995。
- **问题/输入**: 用户入市 4 个月，回测过 2 个月，实盘账户小幅波动、基本打平，问"我现在该干什么"。
- **方法论的使用**:
 1. 成长阶段：资金没增长、经验仍在攒 → 处于第一阶段，任务是"最小成本积累经验"，不是加仓。
 2. 学习阶段：还在"拿别人的形态对照自己" → 处于第一阶段（傻抄），应进入拼补。
 3. 技术过关判据：账户周期仅 4 个月，不足半年 → 尚不能判定"快成了"。
- **结论**: 阶段定位 = 成长①／学习①；当前该做的是小仓位攒经验、补全逻辑，而非放大仓位。
- **结果**: 未说明（合成演练）。

### 示例 2: 原书转述——学员第一月机械执行打平、第二周自主思考后反而瞻前顾后
- **类型与来源**: 原书转述（cB3-17，ep-2026.9.3 L02200–L02241）。
- **问题/输入**: 学员实盘第一个月机械模仿作者、看 K 线形态做单，一周开两三单小赚，遇必要亏损后账户打平；第二周开始自主理解市场，反而觉得"哪儿都是机会又不能做"。
- **方法论的使用**: 按学习三阶段，该学员正从①傻抄往②拼补过渡，卡点是"模仿"——不懂背后逻辑就不知道要提取什么信息。
- **结论**: 处方是想通逻辑、尊重当下、矛盾时不做。
- **结果**: 账户打平（不赚不亏）。

### 与相邻能力的区分

- 与 `trade-system-build` 的区别: trade-system-build 是构建系统的**操作流程**；本能力是**判断你在哪个阶段、当前该做什么**的定位框架，学习三阶段为构建流程提供"你现在该做哪一步"。
- 与 `advantage-amplification` 的区别: 本能力讲"技术过关后要往执行／仓位走"；advantage-amplification 讲"过关后如何放大优势（胜率与盈亏比不可兼得、想多赚从仓位下手）"。
- 与 `order-deconstruction-backtest` 的区别: 回测是本能力"内化衍生"阶段的实测手段；本能力负责判断"该不该进入回测"。
- 与 `self-check-overtrading` 的区别: 本能力判断成长阶段；后者判断做单动机是否被"爽"和"假想稳定"驱动。

## E — 可执行步骤（Execution）

**必需输入**: 用户的入市时长与真实投入（每天盯盘时长／累计做单笔数）；账户曲线长度（时间段）；当前学习方法（是否在模仿某流派）；是否已有可复现的规则。缺失时问："你平均每天实际投入多少时间？""你的账户曲线有多长？"

**交付物与完成标准**: 一份**阶段自评结论**，含四项判定 + 关注重心 + 当前该做的一件事：

- 成长阶段（①经验／②财富／③守住）——判据：资金是否已能稳定不亏（用技术过关判据）。
- 学习阶段（①傻抄／②拼补／③内化）——判据：是否还在"拿别人的东西对照自己"。
- 状态阶段（①初生牛犊／②合一／③在乎得失）——判据：是否"不看金额给机会就干"。
- 技术过关判定（是／否／数据不足）——判据：曲线是否足够长且平衡移动。
- 关注重心（选行情／仓位筹码／过滤不做）——判据：当前资金与能力阶段（0→1 选行情，1→100 仓位，成熟期过滤）。

完成标准：四项都有明确判定或明确写"数据不足"，并给出当前阶段唯一优先动作；不允许输出"继续努力"这类不可判定结论。

**实现约定**: 三套三阶段模型、"快成了"判据、底线／上限模型、六层认知模型、阶段关注重心、小白学习顺序均出自原文；"四项自评表"与"唯一优先动作"为**实现约定**，原文未给自评表与阶段量化门槛（原文明确未给各阶段时长／门槛）。各认知层级的达标时间、各阶段的资金／能力分界**原文未给**。

1. **采集投入数据**
 - 完成标准: 得到真实投入（时长 + 累计笔数），并与"年限"分开记录（作者明确反对以年限当经验）。
2. **判定成长阶段**
 - 完成标准: 依据"账户是否已不亏"给出①／②／③；若在第一阶段，优先动作 = 最小成本积累经验。
 - 判停条件: 若用户处于①却要求加仓／全职 → 明确否决，并说明跳关风险。
3. **判定学习阶段（三阶段 + 六层认知层级）**
 - 完成标准: 依据"是否还在追求与别人相似"给出①／②／③；若在①，优先动作 = 进入拼补（各取优点、只留全懂的部分）。
 - 完成标准（六层自检）: 逐项问"能否准确复述／能否换种说法讲清／能否脱离资料应用／能否梳理因果链／能否质疑与对比／能否产出自己的方法体系"，定位卡在哪一层（ep-2026-06-18 L15、L57、L82、L112、L132）。
4. **补市场认知前置项（仅小白阶段）**
 - 完成标准: 若用户处于"傻抄"或更早，先给学习顺序——市场与平台运转规则 → 参与者／对手盘 → 认清自己 → 再学技术与交易（ep-2026-07-25 L966、L1023）；未完成前置不进入技术学习。
 - 判停条件: 若用户已在拼补／内化阶段 → 跳过本步。
5. **判定状态阶段**
 - 完成标准: 依据"是否还在乎金额／得失"给出①／②／③；若在②，处置 = 猛冲；若在③，处置 = 降仓平衡。
6. **做技术过关判定**
 - 完成标准: 用足够长的账户曲线（半年以上或按笔数）扣除磨损后判断是否"平衡移动、小亏小赚、钱亏不没"；曲线不足则判"数据不足"。
 - 判停条件: 若判定"已过关" → 明确"不要再退回去死磕技术"，转 `advantage-amplification`；若"未过关／数据不足" → 继续积累。
7. **给出关注重心**
 - 完成标准: 按资金阶段输出重心——0→1 选行情、1→100 仓位筹码、成熟期过滤不做（ep-2026-09-05 L159、L172）。
8. **输出唯一优先动作**
 - 完成标准: 结合各项判定给出当前阶段唯一一件事，且可被执行。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **用"年限"代替"投入"**。作者明确反对"我做 10 年交易了"式的自居——每天看十几分钟盘累积几年，可能连 1 万笔订单都没做上。
- **在数据不足时宣布"技术过关"**。曲线不足半年、或没扣磨损，不能判"快成了"。
- **把底线当上限**。技术过关只是起点；用它来推"我能赚多少"是误用模型。

### 作者警告的失败模式

- **期待不劳而获 / 兼职心态 / 报年限不报投入**（ep-2026.9.23 L00705–L00814）。陷阱：以"做了 3/5/10 年"自居但做单量极少，拿手机做单、不尊重盘面；机制：投入时长不足，能力无法积累，落差变成痛苦；预警信号："江哥我做 10 年交易了""白天上班晚上点两下""试试吧就当玩玩了"。
- **模仿作者 / 照葫芦画瓢**（ep-2026.9.3 L02575–L02586）。陷阱：一比一模仿作者的方式／图形但不懂背后逻辑；机制：信息不对等、条件因子不同，无法复制；预警信号："我所有东西都是看您学来的""只模仿 N 字形"。
- **向外求 / 找圣杯 / 要稳定系统**（ep-2026.9.24 L01461–L01499）。陷阱：从别人那要一个看似稳定的系统；机制：别人给的全是不稳定的，稳定只能来自自己内部构建；预警信号："有没有一劳永逸的方法""找圣杯"。
- **技术焦虑（总想再学一样 / 升级）**（ep-2026.8.26 L01883–L01962）。陷阱：已能赚钱仍想再学新方式；机制：受自媒体影响产生"都学会就都赚了"的焦虑；预警信号："我再学会一个方式多赚点""看到别的老师会别的就焦虑"。
- **买课当护身符 / 拿老师当光环**（ep-2026.9.28 L01929–L01992）。陷阱：以为报课就等于自己牛逼、不用学不用练；机制：花钱买心理安慰，市场不认名号；预警信号："提老师名字壮胆""报课后不学不看"。
- **想快、追求神乎其神的技术**（ep-2026-01-03 L314、ep-2025-09-30 L174）。陷阱：把"快速"两个字挂在心上，追求神乎其神的技术、想快速赚钱。机制：想快时"等着你的就是什么 就是镰刀 镰刀跟陷阱"；小资金做大的关键不在玄乎的技术，而在用可掌控的技术搭稳健系统。预警信号："怎么快速回本""有没有很猛的技术""一个月翻倍"。
- **"会的越多错的越多"**（ep-2026-09-25 L136、L139）。陷阱：把自己不赚钱归因于"学太多、会越多错越多"。机制：作者判此说法"那一定是在为他的无能而找理由"——会的越少，连自己错了都不知道；会的越多才能看到自己的错。技术分析本质是过滤器，真正会用的人非常挑食。预警信号："会的越多错的越多""学太多反而乱"。
- **只想靠单次机会搏出来**（ep-2026-08-10 L181、L186）。陷阱：小资金者不相信自己的方式能长期赚钱，只想靠单次某个机会一把搏出来。机制：应把它当经营、长期积累；作者自述前期打仓位筹码时"也只做递减行为／不做那种什么递增行为"。预警信号："就赌这一把""抓住一次大的就够了"。

### 作者的盲点 / 时代局限

- **各阶段的时长／门槛原文未给**。作者只说"稳定需要 3 年硬亏""用半年看曲线"，未给可操作的转换标志；本能力的阶段判定只能是近似。
- **"大多数人都在第一阶段"是观察而非统计**，无样本支撑。
