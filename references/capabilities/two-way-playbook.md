## I — 方法论骨架（Interpretation）

这套方法的出发点是把自己从"猜方向"里拿出来。作者用石头剪刀布作比：市场先出招，我们后应对。前提有两个——你得能认出市场出的是"石头"，且你手里事先备着"布"。于是"方向是走出来的、不是猜出来的"，预测被等同于赌，明确不做。

落到操作上，就是把可能的走法提前写成 if-then 预案：市场往上走怎么做、往下走怎么做、震荡怎么做；每种走法对应一个前提条件和一个动作，同时写清"什么条件放弃、什么条件做"。方案定好之后不改，等市场触发哪一个就执行哪一个；没有触发就不做，走出未被覆盖的形态也不做。这样就不会被一两根 K 线带着走。

预案的价值被作者总结成一句话："有个预案之后，你就知道你要等啥了，很多人都不知道等啥。"这解释了为什么它同时解决了两个问题：既避免了提前下注站队，又避免了临场凭感觉反应。与之配套的两条硬规则是：不挂单（限价挂单）、不提前埋伏——因为不知道市场下一步怎么走，所以只在价格到了区域、看到当下反应时才决定进不进。

与之互补的是"确定性成本换不确定利润"：能掌控的只有成本（这笔单最多亏多少）和离场方式，赚多少是市场给的。所以预案不是提高胜率的工具，而是把"我能控制的部分"固定下来，把"市场给的部分"留给市场。作者对消息面的态度也由此推出：不因消息面开单、也不刻意躲开，只看盘面是否给机会——因为消息只是加速行情，很少直接逆转。

补充（第二轮材料）——预案的几种组织方式：

- **剧本法**：把某一位置可能出现的**所有合理走法**提前列成剧本，每个剧本配一个方案（做多/做空/不做）；盘中只等市场触发某一个剧本就执行，没触发就不做，出现认知外的走法也不做（ep-2026.4.14 L0618、L0724）。"合理可能性"的穷举边界原文未给，作者只说"认知之外的统计过很多种，不做"。
- **应变式流程**：盘前把市场**拆解、分类、归纳**成条件清单；盘中只做"收集信息 → 判断当前属于系统里的哪一种 → 调出对应方案 → 执行"，不在盘中做深度思考；条件是累积到足够才触发交易（ep-2026.2.23 L0263）。
- **盘前三周期梳理**：从大到小依次梳理四小时 → 一小时 → 5 分钟；每个周期判断市场特征（趋势/宽幅震荡）、标出关键位，确定主周期与次周期，列好上涨/下跌/震荡各方案，等价格到区域按方案执行（ep-2026.8.1 L2、L22、ep-2026.7.31 L144）。"共识堆积区"的量化识别标准原文未给。
- **进场后的三种节奏预案**：进场前就预设市场可能走的三种节奏——①按预期运行→持有；②打出回撤后形成震荡→按震荡逻辑加仓处理；③直接反向打→止损；两种可处理、一种止损，做到"不怕错"（ep-2025.12.12 L281）。

作者对预测的否定在第二轮材料里表述得更直接：要做"条件的执行者"，不做"主观的行情预测者"，任务是监控条件是否满足、一旦满足就执行，放弃对价格走势的预想（ep-2025.9.4 L294、ep-2025.11.23 L163）。

## A1 — 应用示例（Application Example）

### 示例 1: 四小时黄金解盘三方案
- **类型与来源**: 原书演示（ep-2026.9.4 L02324、L02340）
- **问题/输入**: 以黄金四小时为例解盘，需要给出可执行的应对方案。
- **方法论的使用**: 作者直接列三套预案：① 第一方案——瞄定下方区域，前提是回到这个位置、站稳之后做一个低多；② 第二方案——若没回到这里、中途往上折、走出一个结构延续，则等着做回踩；③ 第三方案——若直接破下去，则"不管他了"（不属于认知逻辑）。并指出日线攻防一体位与四小时形成重叠共振，优先看多的机会更好。
- **结论**: 三支走法各有前提条件与动作，外加一支"放弃"分支；触发哪个做哪个。
- **结果**: 原书未交代后续实际走势结果（未说明），仅作解盘演示。

### 示例 2: 9.10 白天两单——第一单被扫、第二单吃到
- **类型与来源**: 原书亲历（ep-2026.9.10 L00184）
- **问题/输入**: 作者白天在某个区域做两单。
- **方法论的使用**: 作者先给"在上面某个区域做单"的预案，实际执行时第一单被打掉（上来先扫一单），随后按同一区域预案再开第二单，吃到一段。
- **结论**: 震荡行情里第一单常被扫，预案要允许"同一区域分次执行"，而不是预测一次到位。
- **结果**: 原书交代：第一单扫损，第二单吃到（未拿满）。

### 示例 3: 空单复盘——只做应变不预测
- **类型与来源**: 原书亲历案例，ep-2026.2.23 L0192
- **问题/输入**: 市场大周期较乱，只能在小周期找机会；出现一推回撤二推、突破极值点但无延续。
- **方法论的使用**: 把上述情形合并处理为高空结构，锁定高空区（一推回撤二推的防守位/交界处），等出现排斥反应信号后做空，动态止盈。作者强调"事前不知道会暴跌，只是应变"——"从始至终都在做一件事，就是叫应变"。
- **结论**: 不预测方向，只锁定区域等信号；触发即做，行情给多少吃多少。
- **结果**: 原书交代吃整段（具体金额未说明）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户问"今晚非农会涨还是跌，我该做多还是做空"。
2. 用户想提前挂单或提前埋伏，问"挂在哪个点位好"。
3. 用户说"我感觉它要涨，我先买一点"。
4. 用户被一两根 K 线带着走，临时改主意、临场凭反应下单。
5. 用户问"要不要看消息面／数据来决定方向"。
6. 用户已经进场，问"进场之后行情可能怎么走、分别该怎么应对"（订单管理）。
7. 用户问"每天开盘前该做哪些准备"。
8. 用户想盘中临场想清楚，而不是盘前把条件拆解好。

### 语言信号（用户的话里出现这些就应激活）

- "会涨还是会跌 / will it go up or down"
- "我想提前埋伏 / 先挂个单 / 提前下注"
- "I'm not predicting / 只做应变 / 不猜方向"
- "if-then / 预案 / contingency plan / playbook"
- "非农往哪走 / 消息面怎么看"
- "剧本 / 合理可能性 / 出现哪个做哪个"
- "条件触发 / 应变 / 拆解分类"
- "开盘前怎么准备 / 三周期 / 高抛低吸"

### 与相邻能力的区分

- 与 `setup-gate` 的区别: setup-gate 判单笔"做不做"；本能力先为多种走法各备一套，再由 setup-gate 对触发的那一套做资格判定。预案是候选集合，闸门是逐项过滤器。
- 与 `no-binary-thinking` 的区别: no-binary-thinking 解释"为什么不能二选一站队"；本能力把"不站队"落地成一张可执行的三支预案表。
- 与 `range-market-playbook` 的区别: range-market-playbook 是"震荡"这一支走法内部的打法；本能力的震荡分支调用它。
- 与 `entry-model-taxonomy` 的区别: entry-model-taxonomy 判进场位置属于哪个模型；本能力判"当前市场走的是预案里的哪一支"。
- 与 `state-and-event-guard` 的区别: state-and-event-guard 处理数据行情前 5 分钟的冷却；本能力说明数据行情不必预测，按预案应变即可。

## E — 可执行步骤（Execution）

**必需输入**: 主周期（周期值）；关键区域／预期点（价位或区间）；可能的行情分支（≥3）；每支的触发条件与动作；放弃条件。缺失"关键区域"时必须先让用户描定，不得替他假定。

**交付物与完成标准**: 必须产出**一份写下来的预案表**，至少含四行：上涨分支、下跌分支、震荡分支、放弃分支。每行字段为：分支／触发条件（if）／动作（then）／止损或逻辑否认点／放弃条件。完成标准：① 表至少 3 行"可做"分支＋1 行"放弃"分支；② 每行都有触发条件与动作，无空白；③ 使用者在不看盘时能复述"我要等什么"；④ 预案定稿后不再修改。

**实现约定**: 原文未给"几种预案算完备""预案数量上限""预案互相冲突时如何取舍""触发判定细则"。本卡以"上涨／下跌／震荡三支＋放弃条件"作为最小完备集，属**实现约定**，使用者可按认知圈扩充分支。

当能力被激活后，agent 应按以下步骤执行：

1. **描定关键区域与预期点**
 - 完成标准: 给出明确的价位或区间，且与历史关键位一致（可调用 `key-level-reading`）。
2. **列出可能的走法（≥3 支）**
 - 完成标准: 至少覆盖上涨、下跌、震荡三支；若认知只覆盖一支，如实说明并只写这一支。
3. **为每支写触发条件（if）**
 - 完成标准: 条件可被盘面事实判定（如"实体收在 X 上方"），不含"感觉"。
4. **为每支写动作（then）**
 - 完成标准: 动作为具体进场方式与方向，非"看情况"。
5. **为每支写止损／逻辑否认点**
 - 完成标准: 每支都有明确价位；缺失则该支不成立，划掉。
6. **写放弃条件**
 - 完成标准: 明确"什么情况什么都不做"，至少一条。
7. **定稿并等待触发**
 - 完成标准: 预案表成文、不再修改；触发哪支做哪支。
 - 判停条件: 市场走出未被任何分支覆盖的形态 → 不做，回到步骤 2 重新构建预案（不临场即兴）。
8. **（补充）进场后按三种节奏管理**（ep-2025.12.12 L281）
 - 完成标准: 进场前已预设"按预期 / 回撤后震荡 / 直接反向"三种节奏及各自动作（持有 / 按震荡逻辑处理 / 止损）。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **把预案当成预测的包装**。若预案里只有一支走法且没有放弃条件，那仍是站队，不是预案。
- **预案定好后随行情修改**。定好不改是本能力的纪律内核；临场改预案等于回到凭感觉。
- **用预案替代风控**。预案只规定"怎么走怎么做"，不替代止损与仓位（见 `position-sizing-by-stop`）。
- **在认知之外的走法上强行写预案**。写不出的分支应写"放弃"，不要硬编。

### 作者警告的失败模式

- **预测行为（说"这里就是底／顶"、能识别中期末期）**（ep-2026.8.7 L00196–L00210、ep-2026.9.28 L01193–L01243、ep-2026.9.30 L01182）。陷阱：在盘中声称能判断行情的中期或末期，断言"这里就是底""行情一定会到某点位"。机制：中期／末期只有走出来之后才知道；预测时大脑会同时推演涨跌两个方向，事后又给自己找理由。预警信号："能识别出末期的全是意淫""说'这里就是底'""我早知道要涨"。
- **提前下注站队／做"天使投资人"**（ep-2026.8.12 L00768–L00772、L01357）。陷阱：在方向未明、没有优势时提前下注站队。机制：博弈未分胜负时提前站队就是赌，会让自己被动、进场就被扫；应等分出胜负再做。预警信号："提前下注战队没有意义""做天使投资人"。
- **看消息面、做事后分析**（ep-2026.8.17 L01571、L02205）。陷阱：依据新闻／数据／政策做交易，或事件发生后复盘拼凑解释。机制：消息不可复制、下次同样的消息结果可能相反，事后分析不指导行为。预警信号："今天是不是有消息催动""纠结非农往哪走""复盘'这个点上涨是因为什么消息'"。
- **主观预测市场（把交易降级成猜谜游戏）**（ep-2025.9.4 L294、ep-2025.11.23 L163）。陷阱：对价格走势做预想、以"预测者"自居。机制：预测一旦成为出发点，就不再监控条件是否满足。预警信号："我赌他会下去""我感觉他能上去"。
- **想买在最低、卖在最高（提前预判趋势）**（ep-2025.11.23 L282、L465）。陷阱：想在下跌趋势开始前卖在最高、上涨趋势开始前买在最低，或在市场没方向时提前堵方向。机制：这是"走不出来"的常见原因；应做趋势形成初期后的跟随。预警信号："抄底""摸顶""想抓在起爆点"。
- **预测行情 / 让市场迎合自己的主观**（ep-2026.2.23 L0184、ep-2026.3.21 L0092）。陷阱：先有"想做多"的主观意愿，再去找进场理由。机制：把前置条件搞反了——应是因为出现了可做多/可做空的模型才做。预警信号："我想做多，所以找机会进"。
- **拿主观意识强行套交易方式找进场点**（ep-2026.3.21 L0092）。陷阱：拿主观意愿去套一个交易方式、硬凑进场点。机制：与上一条同源，把"我想做"当成"可以做"。预警信号："强行套一个进场点"。

### 作者的盲点 / 时代局限

- **预案完备性没有标准**。原文 明确写着"'几种预案算完备'的标准、'预案数量上限'、预案互相冲突时如何取舍、'方案触发'的判定细则原文未给出"。所以"够不够全"仍靠个人判断。
- **"不挂单／不埋伏"在快速行情里会错过**。作者接受"宁可错过不做错"，但这条代价未被量化，也未讨论流动性极差时的滑点。
- **消息面处理依赖"加速而非逆转"的经验判断**。原文 写着"'加速行情'的识别判据原文未给出"，因此"不躲消息面"这一步缺少可执行判据。
- **合规与平台语境**。内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护，作者本人也承认"不敢说自己是做这个的"。与平台规则绑定的操作（如数据行情规避、出金安排）不蒸馏为通用能力，仅作风险提示；本卡不构成投资建议。
- **"合理可能性"的穷举边界原文未给**。作者只说"认知之外的统计过很多种、不做"，未给判据；因此"列全了没有"仍靠个人判断。
- **"共识堆积区"的量化识别标准原文未给**（ep-2026.8.1 L2），盘前三周期梳理缺少可执行判据。

### 容易混淆的邻近方法论
