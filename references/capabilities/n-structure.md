## I — 方法论骨架（Interpretation）

N 字形是这套体系的**唯一结构单元**。任何周期的走势都被拆成"推动—回撤—推动"三段拼接：连续向上的 N 即上涨，连续向下的 N 即下跌，N 无法延续即震荡。它要解决的不是"预测方向"，而是把"关键位在哪、在哪进、在哪走"落到同一套坐标上，让不同周期用同一种语言对话。

标记规则有三条硬约束：

1. **只标本级别**。在目标级别画出的结构，若被更大级别的两条边界线包含，说明画的是内部结构、级别错了，应合并为一条线。原文警告"你画出内部结构的 N 类型就是错误的"。
2. **实体才算突破**。新高/新低须由 K 线实体突破前方 K 线的影线部分才成立；影线参与标记，但判突破以实体为准。
3. **回撤要判有效/无效**。回撤清扫（吞没/突破）了前一根创造极值的 K 线的流动性 = 有效回撤，才画；未清扫 = 无效回撤，不画。

一个 N 字只产出**两个可交易位置**：进攻位（第一次推动终点 / 第一次回撤起点的交接处）与防守位（第一次回撤终点 / 第二次推动起点的交接处）。作者的交易全部发生在这两个位置，其余位置不做。

交易方式分两类：突破式（靠第二次推动打破前关键位的冲击力进场）与回踩确认式（等价格回踩到防守位/进攻位）。回踩确认式再分极速、常规、慢速三种，只做极速与常规；慢速回踩因结构扩散，改做逆向回调波段。

止损用**逻辑型**：顺着趋势做，趋势被否定（防守位/关键点被打破）就离场，不按固定点数。价格创出新高/新低后，可把止损移到回调结束的极值点。

级别选择走"看大做小"：大周期标 N 定整体偏向，小周期找内部 N 的防守位承接进场，大小周期方向一致则偏向确立。

## A1 — 应用示例（Application Example）

### 示例 1: 2025-08-11 比特币 15 分钟 N 字形突破空单
- **类型与来源**: 原书亲历案例（firsthand，ep-2026.7.30 L17 / L34 / L77）
- **问题/输入**: 当天价格突破前方关键位、到达四小时级别的历史前高；作者想做一笔短线。
- **方法论的使用**: 在四小时关键位等待；切 15 分钟，看到上涨 N 字形被打破 → 做 15 分钟级别的 N 字形突破空单；止损放 15 分钟 N 字形极值点；止盈设一比一。
- **结论**: 大级别关键位的推动力推动小级别结构反转，做的是小级别 N 字形突破。
- **结果**: 次日顺利止盈。
- **缺口**: 原文未给当时的具体进出场价格与盈亏金额。

### 示例 2: 结构型突破的完整执行链（合成演练）
- **类型与来源**: 素材中该流程只给规则、无带数值的成交记录；以下为**合成演练**，用于演示步骤，不代表作者亲历。
- **问题/输入**: 15 分钟图已标出一个上涨 N 字形，前高 100。价格来到前高关键位。
- **方法论的使用**:
 1. 在前高 100 画水平线，切到一分钟周期观察；
 2. 一分钟回落后再向上突破该水平线（且以实体突破）→ 进场；
 3. 止损放 N 字形下方极值点（如 96）；
 4. 目标 = 进场价 +（进场价 − 止损），即一比一。
- **结论**: 进场点、止损位、一比一止盈三件套齐备，方可下单。
- **结果**: 演练演算，无真实成交结果。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户说"帮我看看现在的结构"，但不知道从哪画起、画在哪个周期。
2. 用户在一张图上画了结构，却不确定自己画的是本级别还是内部结构（"我这么画对吗"）。
3. 用户问"哪里是关键位 / 哪里是进攻位、防守位"。
4. 用户问"突破了这个前高算真突破吗"（需要实体/影线、二次确认的判据）。
5. 用户问"N 字形成了该怎么下单"（突破式还是回踩式）。
6. 用户问"止损放哪"（需要落到逻辑否认点/防守位）。

### 语言信号（用户的话里出现这些就应激活）

- "N 字形 / N 字型 / 结构型突破 / N 字型突破"
- "前高前低 / 新高新低 / 结构点"
- "进攻位 / 防守位 / 发力点 / 攻防一体位"
- "这算真突破吗 / 假突破 / 二次确认"
- "画在哪个周期 / 内部结构 / 级别画错"
- "止损放哪 / 逻辑型止损"

### 与相邻能力的区分

- 与 `trend-definition` 的区别: trend-definition 用高低点定义方向；本能力把方向进一步标准化为可标记的 N 字结构，并给出结构上的两个交易位。方向定义是前置，本能力是它的结构化表达。
- 与 `internal-external-structure` 的区别: 该卡专管"级别画错没画错"（被包含即内部结构、合并为一条线）；本能力负责把 N 字画出来并交易它，两者是画图与校验的分工。
- 与 `key-level-reading` 的区别: key-level-reading 讲关键位怎么找、怎么延伸；本能力的进攻位/防守位是 N 字内部的固定两处，属于关键位在结构中的落点。
- 与 `true-false-breakout` 的区别: 该卡判定突破真假；本能力的"实体突破前 K 影线 + 小周期二次确认"是它的一条具体判据。
- 与 `dynamic-exit` 的区别: 本能力管"结构在哪、怎么进"；dynamic-exit 管持仓后"行情能否沿原方向流畅运动、何时离场"。

## E — 可执行步骤（Execution）

**必需输入**: 目标级别的 K 线图（含实体/影线）；更大级别的两条边界线（用于级别校验）；当前时间周期。

**交付物与完成标准**: 一份 N 字标记结果 —— 三段（推动-回撤-推动）、两个关键位（进攻位价、防守位价）、方向；以及由它得出的进场方式与止损位。完成标准：画出的 N 字通过"不被更大级别两条边界线包含"的校验，且新高/新低均以实体突破前 K 影线成立。

1. **选级别、画 N 字**
 - 连接前低前高、新低新高，标出"推动—回撤—推动"三段。
 - 完成标准: 三段首尾相接，两个转折点可指名到价。
2. **校验级别（是否为外部结构）**
 - 检查该 N 字是否被更大级别的两条边界线包含。
 - 判停条件: 若被包含 → 判为内部结构、级别画错，**合并为一条线后重画**，不要在此结构上交易。
3. **确认新高/新低成立**
 - 完成标准: 新高/新低由 K 线**实体**突破前方 K 线的影线部分；仅影线穿越不算。
4. **判回撤是否有效**
 - 完成标准: 回撤清扫了前一根创造极值的 K 线的流动性 → 有效、保留；未清扫 → 无效、不画。
 - 缺口标注: 原文未给"清扫"的最小穿透幅度（**实现约定**：以实体收过该极值价视为清扫）。
5. **标出两个关键位**
 - 完成标准: 进攻位 = 第一次推动终点/第一次回撤起点交接处；防守位 = 第一次回撤终点/第二次推动起点交接处。只有这两处可交易。
6. **选进场方式**
 - 突破式: 等第二次推动打破前关键位（实体突破）进场。
 - 回踩确认式: 等价格回踩到进攻位/防守位。极速、常规回踩可做；慢速回踩不做突破单，改做逆向回调波段。
 - 完成标准: 明确写下本单属于哪一类，及进场价。
7. **定止损**
 - 止损放防守位/逻辑否认点（上涨 N 放关键低点下方，下跌 N 放关键高点上方）；价格创出新高/新低后，可把止损移到回调结束的极值点。
 - 完成标准: 止损位 = 趋势被否定的价位，不是一个固定点数。
8. **级别一致性检查（看大做小）**
 - 完成标准: 大周期方向与小周期进场方向一致，偏向才算确立；冲突时不做。

**实现约定**: 本卡中"实体收过极值价视为清扫""一比一止盈"等具体取值，原文只给口径未给数值，属**实现约定**，不改变"以 N 字定结构、只在两关键位交易、以逻辑位止损"的原意。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **画成内部结构时**。N 字被更大级别边界包含，说明级别错了，此时所有关键位与止损位都建立在错误坐标上。先合并、重画。
- **宽幅突破的 N 字形**。原文明确"尽量放弃交易宽幅突破 N 字形""尽量少做这种 N 字型"——宽幅突破动能弱，不适合突破式交易。
- **说不出逻辑否认点时**。止损放不出逻辑位，等于这笔单没有依据；本能力产出的止损位不是随手设的点数。
- **把 N 字形态本身当系统时**。原文警告"有的人一直错把交易技巧当成了交易系统"——N 字只是系统中的一个环节，看到形态就进、缺少前后因果，结果不会好。

### 作者警告的失败模式

- **形态当系统**（ep-2025.9.4 L334–L342）。陷阱: 看到 N 字/头肩顶/三角收敛就下单。机制: 形态是环节不是系统，缺上下连贯的前因后果。预警信号: "出现了 N 字，进"。
- **宽幅突破单**（ep-2026.7.28 L44、ep-2026.7.30 L514）。陷阱: 在动能弱的宽幅 N 字上做突破。机制: 宽幅突破冲击力不足、延续差。预警信号: "这个 N 字挺大，突破就追"。
- **弱多里把回踩当进攻位做多**（ep-2026.1.16 L64、ep-2026.4.14 L833）。陷阱: 分不清进攻位与防守位，把弱多的回踩当进攻位做多，被套在山顶。预警信号: "回到关键位就多"。

### 作者的盲点 / 时代局限

- **"清扫流动性"无量化标准**。原文未给最小穿透幅度（、 的原文均标"原文未给"）。
- **"被包含"无量化判据**。 标"原文未给"（如重叠比例）；级别画错只能靠人工判断。
- **极速/常规/慢速回踩无分界值**。 标"原文未给"时间或角度分界。
- **突破需实体还是影线，原文自相矛盾**。 标"原文未给明确要求（其他课提到实体）"；本卡统一采用"实体"口径，属**实现约定**。
- **三种突破进场方式无优先级量化条件**、**四类回踩无风险/胜率排序**、**三个买点无仓位分配比例**、**大小周期搭配无具体表**——均标"原文未给"。
- **强/弱趋势无量化区分**、**需一致的周期数量下限未给**。
- **平台与合规语境**。内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护；数据行情下杠杆会调、滑点很大，"实体突破"与"逻辑位止损按价成交"两个假设可能同时失效。内容不构成投资建议。

### 容易混淆的邻近方法论

- **形态学（头肩顶、三角形收敛）**: 作者把它归为"交易技巧"，与 N 字同属形态层，但强调不能单独当系统。
- **道氏理论的高低点结构**: 同样用高低点定义趋势；本能力的差异在于用"实体突破前 K 影线"过滤噪音，并固定两个可交易位。
- **固定的支撑/阻力线**: 本能力的进攻位/防守位是 N 字内部的**固定两处**，不是任意画出的支撑阻力线。
