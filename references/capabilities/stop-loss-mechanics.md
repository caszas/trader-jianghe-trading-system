# 移动止损机制

## R — 原文（Reading）

> 以上逻辑都一样 / 就是退止损 / 够了够了 / 一比一左右就开始推止损

— 交易员江河，ep-2026.10.5 L02385–L02387

---

> 止损一般多大 / 一般给进场开业上面一根儿就是如果 / 离发力点近的话 / 你就给发力点

— 交易员江河，ep-2026.10.5 L01935–L01937

---

## I — 方法论骨架（Interpretation）

移动止损回答的是"止损**怎么移**"，不回答"该不该走"（后者归 `dynamic-exit`）。

三条机制：
1. **推的时机**：盈亏比到一比一左右就开始推。也就是浮盈大致等于初始风险时，止损第一次上移。
2. **推的依据**：按结构点逐级推——发力点、防守位。这样不容易被卖飞，代价是可能被打掉后行情继续走。
3. **初始止损给多大**：一般给进场 K 线上面一根；离发力点近就给发力点，离发力点远就没必要给那么大。

一条心理依据：**浮盈转浮亏最难受**，比"浮盈变少"难受得多。所以一旦有浮盈，就要推保本/推止损，把"从赚变亏"这条路堵住。

一条禁令：**亏损单不再挪止损**。信号本来就不对，再挪一次成本太大、不合理——挪止损等于把已经站不住的逻辑再往后拖，是纯粹的成本追加。

还有一层自省：作者指出"推止损"这个动作本身暴露了心理状态——推止损的意义是保护利润，动机是"怕行情回来"；也就是说，推止损的那一刻，你其实认为市场不能再走了。若真的笃定逻辑，就不会推。所以推止损是"感觉/可能"，不是"笃定"。

新材料把止损的**性质**讲得更完整：它是**逻辑型止损**——"我们的止损呢都是逻辑型止损 / 什么叫逻辑型止损呢 / 就是我们顺着趋势去做交易 / 那么一旦市场否否认这个趋势 / 就代表我们应该停止交易 平仓离场"（ep-2025.11.23 L626、L652）。即止损放在逻辑位而非固定点数：上涨趋势放在关键低点下方、下跌趋势放在关键高点上方；关键点被打破（趋势被否定）即离场（ep-2025.12.18 L712）。

推止损还有**第二个触发点**：到预期位。作者的固定习惯是"到我预期位之后我就会把止损推上去……我还不太会直接走 / 就是我会先给他推上去让一点利润 / 然后等那个小概率事件"（ep-2026.7.7 L94、ep-2026.7.24 L210、ep-2026.7.25 L1635）。做法是：未到第一预期位前不动止盈；到达后把止损上推到接近现价、锁定部分利润，再等是否继续飞——反向则被止损带走已锁利润，继续飞则吃超额（ep-2026.7.31 L325、L425、ep-2026.8.1 L443）。好处是"用小部分的利润回撤 / 有可能会换到一个更大利润的奔跑"；止损上推的具体距离/比例原文未给。

移动的落点被统一为**结构位**：到达预期位后"按照这个结构的发力点呢进行下移啊……1.1点的进行移动"（ep-2026.9.28 L37、ep-2026.10.4 L154）。止损（及下移止损）放在拐点、发力点等结构位置而非随意点位；无逻辑的纯粹上移只在临近目标时用。止损距离（点数/ATR）的量化标准原文未给。

## A1 — 应用示例（Application Example）

### 示例 1: 7.29 弱空高空单，统一止损后一路往下推
- **类型与来源**: 原书亲历案例（ep-2026.7.29 L01484–L02139）
- **问题/输入**: 作者在 5 分钟周期做了一笔"弱空高空"单，在描定区域分两笔半仓进场。
- **方法论的使用**:
 1. 两笔进场后设**统一止损**（同一个逻辑否认点，不是每笔各设一个）
 2. 行情按预期向下推进，盈亏比接近一比一后开始推止损
 3. 后续按结构点逐级下移止损，保护利润
 4. 全程只带止损、不带止盈
- **结论**: 止损随结构逐级推进，浮盈被逐步锁定。
- **结果**: 盈利 1 万 4 千美金（作者自述实盘）；当天直播间首次破千。

### 示例 2: 8.14 两单，边拿边推止损
- **类型与来源**: 原书亲历案例（ep-2026.8.14 L02445–L02571）
- **问题/输入**: 作者当天做两单，5 分钟回踩入场、1 分钟细化进场。
- **方法论的使用**:
 1. 进场后挂初始止损
 2. 行情沿原方向走，不断推止损保护利润
 3. 不做静态止盈，离场交给动态判定
- **结论**: 移动止损是持仓期间的标准动作，不是"行情好才做"。
- **结果**: 两单均赚钱离场（原书交代）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户有浮盈，问"止损要不要往上挪""挪到哪里"。
2. 用户问"止损一开始该给多大"。
3. 用户说"我想推保本，把风险去掉"。
4. 用户一笔单已经浮亏，问"能不能把止损挪一挪，给它点空间"。
5. 用户问"什么时候开始推止损比较合适"。
6. 用户到了预期目标位，问"该直接走还是继续拿"。

### 语言信号（用户的话里出现这些就应激活）

- "推止损 / 移动止损 / trailing stop"
- "止损给多大 / 止损放在哪根 K 线"
- "推保本 / move stop to breakeven"
- "浮盈了要不要把止损挪上来"
- "止损能不能再挪一下 / 给它点空间"
- "到预期位了，该走还是继续拿"

### 与相邻能力的区分

- 与 `dynamic-exit` 的区别: **dynamic-exit 判断"该不该走"，本能力规定"止损怎么移"**。dynamic-exit 输出"离场/继续持有"；本能力输出"新的止损价"。两者可同时运行，但不要用"推止损"去替代"离场判定"——把止损推到成本价，不等于行情已经该走了。
- 与 `order-exit-discipline` 的区别: order-exit-discipline 管出口的合法集合（只有打止损或赚钱离场，且不推保本这一说法在该卡里被限定为"一根 K 线不足以否认逻辑时不该推"）；本能力管"允许推的时候具体怎么推"。
- 与 `position-sizing-by-stop` 的区别: position-sizing-by-stop 定的是**初始止损位**（逻辑否认点）；本能力定的是**持仓期间的止损位移**。初始止损不能为了让仓位好看而移动，移动只发生在浮盈阶段。
- 与 `exit-choice-tradeoff` 的区别: exit-choice-tradeoff 决定"选移动止损还是选扛回撤"这个方向性选择（选移动就每笔都移动）；本能力是选定之后的具体机制。

## E — 可执行步骤（Execution）

**必需输入**: 进场价；初始止损价；当前价；持仓方向；最近的发力点/防守位价位（结构点）；初始风险 `R0 = |进场价 − 初始止损价|`。缺失结构点时必须先向用户要，或按"进场 K 线外侧一根"给默认值并标注为实现约定。

**交付物与完成标准**: 输出一份**止损位更新建议** —— `是否移动`（是/否）、`新止损价`、`移动依据`（一比一 / 结构点 / 保本）、`移动后的风险状态`（仍亏损 / 保本 / 已锁利）。完成标准：新止损价必须只朝有利方向移动（多单只上移、空单只下移）；移动依据必须能指到具体价位或比例，不允许写"感觉差不多了"；若判定不移动，必须写明"触发移动的条件是什么"。

**实现约定**: 原文给出的是口径而非公式。本卡把以下取值标为**实现约定**：① "一比一"＝`当前浮盈 ≥ R0`，即盈亏比达到 1:1；② "按结构点推"＝把止损推到最近一个**已经确认**的发力点或防守位（该结构点须已被一根收盘 K 线确认）；③ 默认初始止损＝进场 K 线外侧一根的低点/高点（多单取下侧、空单取上侧），若离发力点更近则改用发力点；④ "亏损单不再挪"中的"亏损单"＝当前浮盈 < R0 且未达保本的单；⑤ "第一预期位"＝进场前预设的第一目标位，到达后推止损为原文口径（ep-2026.7.7 L94），其"接近现价"的具体距离原文未给。

1. **确认当前盈亏状态**
 - 完成标准: 算出当前浮盈，并与 R0 比较，判断是否达到一比一。
 - 判停条件: 若当前为亏损单（浮盈 < R0 且未保本）→ **不移动止损**，跳到步骤 5。
2. **确认是否已达推止损的触发点**
 - 完成标准: 给出"达到/未达到"的明确结论。触发点有两个：①盈亏比达一比一（实现约定）；②价格到达第一预期位（原文口径，ep-2026.7.7 L94）——到达后按"上推到接近现价、锁利、再等小概率延续"处理（ep-2026.7.31 L325）。
 - 判停条件: 两个触发点均未达到 → 不移动，输出"等待触发"，跳到步骤 5。
3. **定位结构点**
 - 完成标准: 给出最近一个已确认的发力点或防守位价位；若比当前止损更有利则作为候选新止损。
4. **计算并给出新止损价**
 - 完成标准: 新止损只朝有利方向移动；写出移动后的风险状态（保本/已锁利）。
5. **检查是否存在"亏损单挪止损"的冲动**
 - 完成标准: 若用户要求给亏损单"让空间"，明确拒绝并说明理由（信号本来就不对，再挪成本太大）。
6. **记录**
 - 完成标准: 记下每次移动的时间、价位与依据，供复盘时检验"是否一致性执行"。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **订单处于浮亏时**。亏损单不再挪止损；此时该走的是 `trapped-order-triage`（判逻辑是否被否认），而不是"给它挪点空间"。
- **结构点无法确认时**。没有已确认的结构点，"按结构点推"就没有依据，只能退回一比一或保本这一档。
- **把它当成离场判定**。推止损是保护动作，不是"行情该走了"的信号；离场判定归 `dynamic-exit`。

### 作者警告的失败模式

- **亏损单再挪止损**（ep-2026.10.5 L01935–L01939）。陷阱：信号已明显不对，仍继续挪止损。机制：信号本来就不对，再挪止损成本太大、不合理。预警信号："信号不对了还想再挪止损"。

### 作者的盲点 / 时代局限

- **"结构点""发力点"未量化**。本卡用"已确认的发力点/防守位 + 一根收盘 K 线确认"作为实现约定，原文未给判定细则。
- **"一比一"是举例而非硬规则**。原文说"一比一左右"，具体阈值需使用者自定；原文另给"到预期位"作为第二个触发点（ep-2026.7.7 L94），但两个触发点如何取舍、以谁为准原文未给。
- **推止损与"笃定"之间的张力未解**。作者一边说推止损＝不相信自己，一边自己也在推止损；两者如何调和，原文未给正面规则（只给了一个心理诊断）。
- **滑点与跳空**。内容围绕黄金 CFD 与加密合约，作者自承数据行情滑点极大，止损"按价成交"的假设会失效；这类平台在中国大陆不受法律保护，全篇不构成投资建议。

### 容易混淆的邻近方法论

- **保本止损**：只是移动止损的一个档位（推到进场价），不是独立机制；推到保本后若被扫，等于白玩，这是 `exit-choice-tradeoff` 里"选移动止损"的已知代价。
- **分批止盈**：那是仓位层面的减仓动作，不是止损位移；两者可以并存，但概念不同。
