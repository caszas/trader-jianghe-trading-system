# 本金规模与备用金

## R — 原文（Reading）

> 你就感觉你拿出一个就是亏没了／你能心疼的／或者说你确确实实付出了一段时间努力／才得到的这个钱……这个钱那个资金的额度／大到你足以把它当回事儿

— 交易员江河，ep-2026.10.2 L01209–L01271

---

> 绝对不要啊／绝对不要绝对不要／……就是不要把全部的钱都拿去做交易／能懂吧／一定要有一个备用金／无论如何什么状态下／都要有个备用金存在

— 交易员江河，ep-2026.9.30 L02047–L02136

---

## I — 方法论骨架（Interpretation）

这条方法回答的是入金之前的一个问题：**放多少钱进去。** 它由两个互相约束的判断组成。

第一个判断是**本金的下限——这笔钱要"当钱"**。标准不是某个绝对金额，而是一个主观的验算：如果这笔钱亏光了，你会不会心疼？它是不是你确实付出过一段时间努力才换来的？额度要大到你"足以把它当回事儿"。太小的钱（几十、几百美金）你不会当钱，亏了也无所谓，于是就会"恶性重复梭哈"——不是纪律问题，是这笔钱本身没有重量。作者给的经验量级是两三个月的工资。

第二个判断是**本金的上限——不能是全部的钱**。无论什么状态，手里必须留一份备用金，绝不能把所有钱都扔进交易。备用金的作用不是"亏了还能补"，而是**避免被迫中断**：当你的长期规划走到七八成、生活突然出问题时，备用金能让你挺下来，不必强行中止。作者把"知识/认知也是复利的、中断会倒退"作为这条规则的理由——被迫暂停的代价不是暂停，是倒退。

两个判断合起来，其实是一个匹配问题：本金要与**你的心理承受度**匹配，也要与**你的资金容纳量**匹配。作者反复强调"资金没有绝对的大小，只有相对的大小"——千八百万进场也是散户；同时"能力永远比本金重要"，没能力前给你 1000 万也是亏。所以本卡的产出不是一个数字，而是一个**落在区间内的额度 + 一条不可突破的底线**。

## A1 — 应用示例（Application Example）

### 示例 1: 三步判断该入多少金（合成演练）
- **类型与来源**: 原书未提供带数值的成交案例；以下为合成演练，判据阈值见 E 段"实现约定"
- **问题/输入**: 用户月薪 8000 元，可支配积蓄 20 万，打算全职做交易，问"该拿多少本金进去"。
- **方法论的使用**:
 1. 验算"心疼线"：亏光会心疼、且是努力换来的 → 符合"当钱"的下限
 2. 定备用金：先划出覆盖最低生活保障的备用金（若按 6 个月最低支出 ≈ 3 万计）→ 这部分**不进交易账户**
 3. 定本金上限：剩余部分再按"亏光不影响生活"过滤，只取其中一份进交易账户
 4. 反查"全职可行性"：用备用金 ÷ 每月最低支出判断能撑几个月；若不足以支撑能力成长周期 → 明确告知"现阶段不适合全职"
- **结论**: 备用金 3 万先锁死；交易本金取一个"亏光会心疼但不影响生活"的额度；并给出"能否全职"的二值判断。
- **结果**: 演练演算，无真实成交结果（未说明）。

### 示例 2: 作者养盘手两三年后散伙（原书亲历）
- **类型与来源**: 原书亲历（firsthand），ep-2026.8.3 L01925–L02146
- **问题/输入**: 作者自述曾养过两三年盘手（两三个人），后来都散了；他分析原因时提到"资金容纳量"这一概念——盘手到百万级别就上不去、一上就变形。
- **方法论的使用**: 用本卡的"本金与容量匹配"视角回看：出问题的不是钱不够，而是**资金规模超过了盘手能驾驭的容量**；同时分成模式让他们觉得"自己拿 100 万做能全进兜"，于是离开。作者由此强调自己"只筛选不培养"。
- **结论**: 本金（或受托资金）规模必须与执行者的资金容纳量匹配，超出容量会"变形"、执行不下去。
- **结果**: 盘手与合作全部离开、解散（未说明后续）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户问"做交易需要多少本金""1 万够不够""100 美金能不能做"。
2. 用户打算把全部积蓄（甚至借钱、卖房）投进交易。
3. 用户想用很小的资金全职做交易，问"能不能靠这个生活"。
4. 用户账户做大后"动作变形"，问"是不是资金太多了"。
5. 用户已经赚了一笔，问"要不要把利润也全放进去继续做"。
6. 用户资金小、时间少，问"能不能靠做短线把本金做起来"。

### 语言信号（用户的话里出现这些就应激活）

- "本金多少合适 / 起步资金 / how much capital to start"
- "备用金 / 应急资金 / emergency fund / reserve"
- "全部身家 / 梭哈进去 / 把房子抵押了"
- "小资金全职做交易 / 靠这个生活 / quit my job to trade"
- "资金容纳量 / 一上仓位就变形 / capacity"
- "资金小想靠短线翻身 / 只有碎片时间做交易"

### 与相邻能力的区分

- 与 `risk-budget-and-circuit-breaker` 的区别: 那张卡是在**已经入金之后**算"单笔/当日能亏多少"；本卡是**入金之前**决定"总共放多少进去"。本卡给出总额，风险预算卡在总额内部切分。
- 与 `capital-isolation-and-withdrawal` 的区别: 那张卡解决"钱进来以后，交易账户里留多少、其余放哪"（账户间摆布）；本卡解决"这笔钱本身该不该拿来交易、有多少绝不能拿来"（入金资格）。
- 与 `growth-path` 的区别: `growth-path` 讲成长阶段与学习顺序（先活下去、用最小成本积累经验）；本卡是它的一条前置约束——没有合格的本金与备用金，"先活下去"就无从谈起。
- 与 `advantage-amplification` 的区别: `advantage-amplification` 讲"想多赚从仓位/风控下手"；本卡的"资金容纳量"是它的前提——容量没到，放大的尝试会直接表现为执行变形。

## E — 可执行步骤（Execution）

**必需输入**:
- 个人可支配资产总额（金额）
- 每月最低生活支出 `E`（金额/月）
- 当前月收入或"这笔钱相当于几个月工资"
- 是否计划全职、以及可接受的能力成长周期（月）

**交付物与完成标准**: 输出四元组 —— `备用金 S`、`交易本金 C`、`C 是否满足"当钱"判据（是/否）`、`全职可行性（可行/不可行）`。完成标准：`S + C ≤ 可支配总额` 成立；`S` 是具体金额且用途明确；"当钱"判据与全职可行性都是**二值判断**，不留"可能吧"。

**实现约定**: 原文**未给出**"备用金应占总资金多少比例"，也**未给出**"适合的度"的量化算法；只说"两三个月工资还可以""资金体量没到几百（万）不用想太多"。本卡的 `备用金 ≥ 6 个月最低生活支出`、`本金 ≈ 2–3 个月工资` 均为**实现约定**（后者的量级来自作者原话），不改变"本金要当钱、必须留备用金"这一原意。判定为二值，无容差。

当能力被激活后，agent 应按以下步骤执行：

1. **验算"当钱"判据（本金下限）**
 - 完成标准: 用两个问题得出二值结论——① 这笔钱亏光，你是否真的心疼？② 它是否是你确实付出过一段时间努力换来的？两问皆"是"才通过。
 - 判停条件: 若为"否"（典型如几十/几百美金、随手可得的钱）→ 结论是"这笔钱太小，不构成合格本金"，给出理由并回到步骤 2 重新定量；不要替用户"先用小钱练手"。
2. **定备用金 S（硬底线）**
 - 完成标准: `S` 是具体金额，且 `S ≥ 6 个月最低生活支出`（实现约定）；明确写出"任何情况下 S 不进入交易账户"。
 - 判停条件: 若可支配总额扣除 S 后所剩极少 → 结论是"当前不具备交易本金条件"，流程终止于"先积累"。
3. **定交易本金 C**
 - 完成标准: `C ≤ 可支配总额 − S`；`C` 的量级与 2–3 个月工资可比（实现约定）；`C` 亏光不影响生活。
4. **反查资金容纳量**
 - 完成标准: 结合用户当前的手数习惯，判断 `C` 是否超过其能驾驭的容量——可操作判据是"在这个 C 下，用户是否能按既定规则下单而不变形"；若用户自述"手数一上去就动作变形"，则判定 C 超出容量，给出下调建议。
5. **判断全职可行性**
 - 完成标准: 用 `S ÷ E` 得出"无收入情况下能撑几个月"；若该月数不足以覆盖用户自报的能力成长周期 → 判定"现阶段不适合全职"，并给出替代方案（保留收入来源、用小资金过渡）。
6. **确认资金态度检查**
 - 完成标准: 确认用户已了解"这笔钱的风险可接受"、并愿意在正式使用前先验证方法（作者："先验证一下我这个方式可不可行"）；若用户表现出"亏了卖房卖地也要充"的倾向 → 明确指出其不适合做交易（对应 ）。
7. **输出并交接**
 - 完成标准: 输出 `S` 与 `C` 两个金额，`C` 交接给 `risk-budget-and-circuit-breaker` 与 `capital-isolation-and-withdrawal`。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **把它当成"攒够钱才能开始"的门槛时**。作者同时说"能力永远比本金重要""没能力前给你 1000 万也是亏"；本卡是给一个**下限与底线**，不是给一个"够了才能做"的准入证。
- **用它劝阻小额练习时**。作者反对的是"用不当钱的资金做真实交易"，不是反对任何小规模实践；判断依据是"是否当钱"，不是金额数字本身。
- **在用户已有备用金但本金仍不合规时只讲其中一条**。两条判据必须同时满足：只讲"要心疼"会让用户把全部身家当本金，只讲"要留备用金"会让用户用 50 美金做真实交易。
- **把"资金容纳量"当成"资金越多越差"时**。容量是个人能力上限，可以通过成长提高；本卡用它来匹配当下规模，不是用来否定扩大规模。

### 作者警告的失败模式

- **小资金全职做交易**（ep-2026.9.25 L01186–L01231）。陷阱：用几十、上百美金全职做交易，自称"十油战神/百油战神"。机制：即便一年翻 100 倍也只有 1000 美金，"扣生活成本与手续费后无法维生"；且小资金不被当回事，回撤和盈利都没感觉。预警信号："想拿几十/百来美金全职做""干一年挣 7000 块钱"。**本卡的"全职可行性"步骤就是为拦住这一类。**
- **小资金不当钱 → 恶性重复梭哈**（ep-2026.7.29 L02617–L02630、ep-2026.10.2 L01091–L01096）。陷阱：觉得小资金无所谓、不用做资金管理，直接梭哈；"刚开始还按规则做呢，连损两单之后就开始了，直接就梭哈梭哈梭哈"。机制：钱太容易得到（送外卖、开滴滴就能挣回），失去时不在乎，永远觉得"还有子弹"，于是不按规则。预警信号："小资金无所谓我不用太管理了""我就是梭哈就行了""这是最后一次 50 了"。**这正是"当钱"判据要防的东西。**
- **资金小、时间少却想靠短线翻身**（ep-2026.8.3 L274、L281）。陷阱：资金小、可支配时间少的人抱着"靠短线翻身"的想法进场。原文："很多人都是抱着这种想法态度来的 但是其实如果你资金非常巧 以及时间不多 真不太适合去做短线 因为短线单次收益都很低 再加上你非常小的仓位 一次可得利润非常少 并且你还得算上手续费的耗损"。机制：短线单次收益低、仓位小、扣手续费后更少，且需要高频率重复，与"资金小＋时间少"的条件相冲突。预警信号："我资金小想靠做短线快点做大""只有碎片时间做短线"。原文未给"资金小""时间少"的量化门槛。
- **在工具上斤斤计较**（ep-2026.9.29 L01945–L01955）。陷阱：在能提升能力的工具上省钱（"有没有免费的，那太贵了"），却在交易里一天亏掉够买十个月会员的钱。机制：本末倒置，把钱花在了错误的地方。预警信号："心疼工具钱却频繁亏损"。**提示：本卡的"该省省、该花花"指向能力投入，不是指向本金规模。**

### 作者的盲点 / 时代局限

- **备用金比例原文未给**。原文明确记录"原文未给出备用金应占总资金多少比例"；本卡的 6 个月最低支出是实现约定。
- **"适合的度"无算法**。原文只说要考虑"欲望值、消费观、期望值"，未给量化方法；本卡用"2–3 个月工资"作量级锚点，同样是把定性口径具体化。
- **"资金小""时间少"缺门槛**。新材料警告"资金小＋时间少不适合做短线"，但"资金小""时间少"的量化门槛原文未给，落地时仍靠使用者自定。
- **"能力比本金重要"是作者自承的悖论**。他同时指出"认知不能变现就等于没有认知"；这意味着本卡给出的"先积累能力"建议，在缺少变现路径时可能变成无限期推迟。
- **标的与平台语境**。内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护；本卡涉及的资金规模、备用金与"出金"均以合法合规的资金安排为前提，不构成任何开户、入金或平台选择建议。全篇不构成投资建议。

### 容易混淆的邻近方法论

- **理财规划的应急资金（3–6 个月开支）**：形式相似，但那是通用财务建议；本卡的备用金多了一个特定理由——避免"被迫中断复利导致倒退"。
- **固定本金法（永远只用一笔固定金额做）**：那是账户内的资金结构（见 `capital-isolation-and-withdrawal`）；本卡决定的是这笔固定金额**从哪来、多大**。
- **仓位规模（position size）**：那是单笔层面的量，本卡是账户层面的总量，层级不同。
