# 内部结构只用于明确外部结构

## I — 方法论骨架（Interpretation）

"大周期/小周期"是人为加的工具，不是市场自带的属性——大可以无穷大、小可以无穷小，所以"大不代表对"，大小是相对的。市场唯一自带的信息只有价格的变化，时间周期是后来调出来的观察工具。

在这套视角下，**内部结构（次级别）唯一的作用，是帮你明确外部结构（主周期）**。它不是独立决策依据：你在内部结构上做单，等于把逻辑周期换成了内部那个周期，而不是在主周期上做单。所以交易决策以主周期（外部结构）为准；如果主周期本身就在震荡、没有明确的外部结构，那么"在内部结构里做日内"这个问题本身不成立——答案是"换周期就完事了"，或者"不做内部"。

还有一层推论：顺势是相对的。你顺一个方向的同时，必然在另一个周期上逆着走，因此不存在"绝对顺势"，只需顺自己的主周期。先定主周期，再由主周期确定关联周期；如果真正能从市场获取信息而不是在画图，内外之分就消失了，只剩节奏与时间线拉长的问题。

新材料补了一条更具体的"内部结构如何产生"的判据：先用波段的起点/终点定义**有效低点**与**有效高点**——"高点不断抬高 低点不断抬高为上涨"；两点向右延伸出两条平行线，在价格未突破这两道平行线之前产生的所有结构都称为**内部结构**（无效），突破之后才产生外部结构；最后只连接有效高低点重新划线，得到干净的市场方向（ep-2026.7.27 L42、L115、L373）。也就是说，内部/外部结构的边界由"是否突破由有效高低点引出的平行线"来划定，而不是靠感觉命名；当"很难明确判断出一个有效的市场方向"时，用这套导出与合并划线来清理。原文未给"波段"的最小幅度/时间标准，也未给平行线宽度阈值。

## A1 — 应用示例（Application Example）

### 示例 1: 合成演练——用内部结构确认外部防守位
- **类型与来源**: 原书未提供带完整盘面的独立案例，以下为合成演练（口径来源 ep-2026.9.24 L1135–L1137）
- **问题/输入**: 主周期（1 小时）处于上涨结构，价格回落到最近一个关键低点附近。用户在 5 分钟图上看到价格在低点附近反复震荡，问"内部结构破了，要不要在内部做空"。
- **方法论的使用**: 先不看 5 分钟的方向，而是把 5 分钟当作"确认工具"——用它观察主周期防守位是否被有效打掉、回落后是否走出主周期级别的延续。内部结构的用途是确认外部结构，不是提供交易方向。
- **结论**: 若 5 分钟只是在防守位上方反复震荡而未确认主周期结构被破，则外部结构未变，内部震荡不构成做空理由；此时要么按主周期继续等，要么不做内部。
- **结果**: 合成演练，无真实成交结果（未说明）。

### 示例 2: 合成演练——主周期震荡时"日内怎么做"
- **类型与来源**: 原书未提供案例，以下为合成演练（ep-2026.9.24 L1135）
- **问题/输入**: 用户问"大周期在震荡，我想在大周期内部做日内，怎么找内部结构点"。
- **方法论的使用**: 按本能力的回答，先检查外部结构是否明确。主周期震荡 = 外部结构不明确，此时内部结构没有"要确认的对象"，其唯一作用无处落地。
- **结论**: 换一个主周期（让外部结构重新变得明确），或直接不做；不应在震荡主周期内部硬找结构做日内。
- **结果**: 合成演练，无真实成交结果（未说明）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户问"内部结构点被打破了，意味着什么 / 要不要按它做"。
2. 用户问"大周期在震荡，怎么在它内部做日内"。
3. 用户把次级别结构当成独立的交易依据，问"我能不能就在一分钟/五分钟上做"。
4. 用户纠结"大周期和小周期哪个说了算"。
5. 用户说"我要顺大势"，但说不清顺的是哪个周期的势。

### 语言信号（用户的话里出现这些就应激活）

- "内部结构 / 外部结构 / internal structure"
- "次级别 / 次周期 / 大周期里面做日内"
- "大周期在震荡，内部能不能做"
- "内外结构 / 结构点被打破了"
- "顺大势 / 大周期说了算吗"

### 与相邻能力的区分

- 与 `timeframe-contract` 的区别: 本能力回答"内部结构拿来干什么"（只用于确认外部结构）；`timeframe-contract` 回答"主周期怎么选、主次周期怎么配、周期错配怎么判"。本能力是周期分工的一条具体规则。
- 与 `trend-definition` 的区别: 本能力说明"决策以外部结构为准"；`trend-definition` 给出在外部结构上判定趋势方向的具体规则（高低点 + 防守位 + 延续）。
- 与 `range-market-playbook` 的区别: 本能力处理"外部结构震荡时怎么办"（换周期或不做的判据）；`range-market-playbook` 处理"确认是宽幅震荡之后怎么做"（高空低多、中间不碰）。
- 与 `kline-market-reading` 的区别: 本能力是"看哪个周期"的规则；`kline-market-reading` 是"看K线读出什么行为"的方法，两者一个是尺度、一个是内容。

## E — 可执行步骤（Execution）

**必需输入**: 用户当前使用的主周期；用户提到的"内部结构"所在周期；两者的倍数关系。
**交付物与完成标准**: 一个明确结论——"内部结构用于确认外部结构的哪一点" + 是否具备交易资格（在主周期上做/换周期/不做）。

当能力被激活后，agent 应按以下步骤执行：

1. **确认主周期（外部结构）**
 - 完成标准: 用户能说出自己的主周期，且该周期上存在明确的趋势或震荡定性。
 - 判停条件: 若用户说不清主周期 → 先转 `timeframe-contract` 定主周期，本流程暂停。
2. **确认内部结构所在周期**
 - 完成标准: 写出内部周期，并给出它与主周期的倍数关系。
3. **明确"要确认的外部结构点"**
 - 完成标准: 指出内部结构要确认的是外部结构的哪个具体点（如主周期防守位、主周期关键位是否被打破）。
 - 判停条件: 若说不出要确认什么（只是"看看内部结构"）→ 说明内部结构在此没有用途，输出"不做内部"，终止。
4. **用内部结构确认外部结构**
 - 完成标准: 给出"外部结构是否被确认（打破/未打破、延续/未延续）"的结论，并注明依据来自内部周期的哪些K线。
5. **判定是否具备交易资格**
 - 完成标准: 分三种输出之一——①外部结构明确→在主周期上做（进场细化交 `timeframe-contract`）；②外部结构为震荡→换周期或不做；③内部结构无法确认任何外部点→不做。
6. **排除"在内部结构上独立做单"**
 - 完成标准: 检查用户的交易方向是否由内部结构单独决定；若是，明确指出"这等于换了逻辑周期"，并要求回到主周期重新判定。
7. **导出有效高低点并合并划线（新增）**
 - 完成标准: 找出波段起点/终点对应的有效低点与有效高点，两点向右引两条平行线；平行线内的结构判为内部结构（无效），向上突破上线＝趋势延续、向下突破下线＝趋势转换；最后只连接有效高低点重新划线，得出市场方向。
 - 门槛说明: "波段"的最小幅度/时间标准、平行线宽度阈值原文未给。

**实现约定**: 原文未给"内部结构何时可忽略"（只说"不同节奏不同对待"）、也未给主次周期的倍数标准；本卡的"倍数关系检查""三种交易资格输出"为**实现约定**，取值不改变"内部结构唯一作用是明确外部结构、决策以主周期为准"这一原意。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **主周期本身是震荡时**。外部结构不明确，内部结构没有要确认的对象，此时正确动作是换周期或不做，而不是在内部找结构。
- **想用内部结构独立产生交易方向时**。在内部结构上做单等于换了逻辑周期，不再是"主周期决策"。
- **想论证"大周期一定对"时**。大小是相对的，"大不代表对"；本能力不提供"越大越准"的结论，只提供"以你定的主周期为准"。
- **平台与合规语境**。本内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护，作者本人自承"不敢说自己是做这个的"。本能力是周期使用规则，不构成投资建议，也不适用于受监管市场的合规下单。

### 作者警告的失败模式

> 说明: 原文 `internal-external-structure` **未收录 counter-example 条目**；以下失败模式取自原文中的明确警示，未作外推。

- **把内部结构当成独立决策依据**（ep-2026.8.26 L1629–L1631、ep-2026.9.24 L1137）。陷阱：在内部结构上做单，或对"内部结构点被打破"作过度解读。机制：内部结构唯一作用是帮你明确外部结构；作者称自己"都不看内部结构这个东西"，在内部结构做单等于换了逻辑周期。预警信号："内部结构破了，所以要做""我就在五分钟上做，不看大周期"。
- **把"大周期"当成绝对正确**（ep-2026.7.29 L1315–L1369、ep-2026.8.14 L338–L346）。陷阱：认为顺大周期才是对的、逆大周期一定错。机制："没有大没有小，大小是你臆想出来的"——大可以无穷大、小可以无穷小，"大不代表对"；顺势是相对的，"你顺一个势的同时一定逆一个势"，只需顺自己的主周期。预警信号："我要顺大周期""逆了大周期就不行"。
- **把本周期的内部结构当小周期外部结构**（ep-2026.7.25 L886、L720）。陷阱：认为本周期的内部结构等于小周期的外部结构，想靠它推断小周期状态。原文："他会把这个本周期的内部结构当成小周期的外部结构……内部结构不等于小周期的外部结构 能懂吗就是我只看他当下有意义的行为"。机制：两者是两回事（作者以"水杯接尿"作比），想看小周期状态就切到小周期去看，不能由本周期内部结构推断；"顺大逆小"是另一种处理方式，与内部/外部结构无直接关系。预警信号："本周期的内部结构就是小周期的外部结构""用大周期内部推断小周期"。

### 作者的盲点 / 时代局限

- **"何时内部结构可忽略"未定义**。原文只说"不同节奏不同对待"，没有给出可判定的条件，实际仍靠经验。
- **主次周期倍数关系未给**。作者强调周期要"相搭"（如四小时配一小时），但未给出倍数阈值；本卡用"倍数关系检查"操作化，属实现约定。
- **有效高低点/平行线缺阈值**。新材料给出"有效高低点＋两条平行线"来划定内外结构，但"波段"的最小幅度/时间标准、平行线宽度阈值原文未给，实操仍靠经验判断。
- **"内外之分消失"缺乏判据**。作者说真正懂逻辑后内外之分只是节奏问题，但没有说明如何判断自己已到这一步，容易成为自我豁免的借口。
- **平台语境**。内容围绕黄金 CFD 与加密合约（在中国大陆不受法律保护）；素材为直播口语，同一场直播对"内部结构"的表述有松紧变化，本卡以 的定义为准。

### 容易混淆的邻近方法论

- **多周期分析（Multi-Timeframe Analysis）**：常见做法要求"所有周期同向才做"，把每个周期都当决策依据；本能力只认一个主周期，内部结构只作确认工具。
- **缠论的"级别递归"**：把每个级别都当作独立的走势类型来分析；本能力明确内部结构不是独立依据。
- **"顺大势、逆小势"的日内做法**：把大周期当趋势、小周期找回调；本能力会先检查大周期（外部结构）是否明确，若大周期是震荡则此法不成立。
