# 情绪三步法（事实 → 感受 → 我要怎么做）

## R — 原文（Reading）

> 第一个我们要考虑就是亏损了之后／我们就抢几件事就行了／第一个对吧／先考虑一下事实啊／事实是什么／比如说我亏了／那第二个再考虑什么／我感受到了什么对吧

— 交易员江河，ep-2026.8.14 L00651–L00698

---

> 就是不要想着说是这个问题出现了之后／我怎么把这个问题解决／要想的是什么呢／就是如何让这个问题不发生／或者说一旦发生了／如何最小代价就可以了

— 交易员江河，ep-2026.7.29 L00330

## I — 方法论骨架（Interpretation）

亏损发生时，人的注意力会自动跳到"怎么把亏的赚回来"，而这一步恰恰是爆仓的起点。作者把亏损后的处理拆成固定顺序的三步：先只陈述事实（我这一单亏了多少），再只命名感受（我难过／生气／不甘），最后才决定下一步动作（停手，还是按规则继续）。

前两步是观察，不会伤到你；**第三步才是分水岭**——如果第三步是"重仓打回来""加仓摊平"，那亏损就从一次成本变成一次事故。事实和感受都不会让你爆仓，只有第三步选错才会。

关键判断：情绪是中性的，情绪化才是错的。有难过不是问题，难过之后做出的事才是问题。所以三步法要解决的不是"让我不难过"（做不到，也没必要），而是"让难过不改变我的行为"。

配套还有一层更前置的思路：与其在情绪发生后想办法化解，不如用规则让它根本不发生（连损两次就停、当日熔断）。三步法是"已经亏了之后"的兜底，不是第一道防线。

新材料给"怎么面对亏损"补了一个**三阶段**视角："面对亏损呢有三个阶段第一个阶段就是都是市场的错……第二个阶段呢就是恐惧亏损追求完美……第三个阶段呢就是已经可以坦然的面对风险能够接受盈亏同源了"（ep-2026.7.10 L8、L44、L95）。①"都是市场的错"——不认输、找理由、骂市场，需把怨气磨没才能进步；②"恐惧亏损、追求完美"——想把所有亏损原因都解决，但发现做不到，因为盈亏同源，彻底避免亏损的方式只有放弃交易；③"坦然面对风险、接受盈亏同源"——把亏损当经营成本。检验标准是逐笔自问："这笔是我模式里该花的钱，还是违反模式罚的钱？"

## A1 — 应用示例（Application Example）

### 示例 1: 合成演练——单笔打损后的三栏记录
- **类型与来源**: 原书未提供带数值的三步记录案例；以下为合成演练，规则骨架取自 ep-2026.8.14 L00651–L00698。
- **问题/输入**: 用户刚一笔多单打损，亏掉单笔风险额度（设为账户 1%），情绪上想立刻反手做空打回来。
- **方法论的使用**:
 1. 事实栏：只写客观发生的事——"我在 X 价做多，止损在 Y 价被触发，本单亏 1%"，不写"我怎么这么蠢"。
 2. 感受栏：只命名情绪——"我现在很生气，也有点不甘心，想马上把这笔赚回来"。
 3. 下一步动作栏：对照交易系统里写死的亏损后规则，写"停手／等下一个系统触发的机会"，而不是"反手重仓"。
- **结论**: 三步走完后，"想打回来"被识别为一个感受，而不是一个指令。
- **结果**: 未说明（合成演练）。

### 示例 2: 原书亲历——9.30 赚爽后主动停手
- **类型与来源**: 原书亲历（cB6-23，ep-2026.9.30 L01043–L01094）。
- **问题/输入**: 作者当天带情绪赚完钱，情绪高涨，盘中又出现一次回调机会。
- **方法论的使用**: 他先做觉察——"我马上我就发现我情绪好像有一点过于激动了"；然后把感受命名出来（过于激动）；最后在"下一步动作"栏选择"不给它机会"，没看盘、也没进这次回调。
- **结论**: 情绪高涨和情绪低落一样，都属于"第三步可能变形"的状态。
- **结果**: 作者主动放弃该次回调机会，避免了操作变形。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户刚打完一笔止损、情绪上头，问"我这单亏了，现在特别想把它赚回来，怎么办"。
2. 用户反复出现"亏损 → 报复性加仓 → 更大亏损"的循环，想找方法打断。
3. 用户把亏损归因为"心态不好"，希望找心理调节或放松技巧。
4. 用户赚了一笔之后同样情绪高涨，问"赚了这么多要不要继续做"。
5. 用户在连损之后想立刻重进同一个位置。

### 语言信号（用户的话里出现这些就应激活）

- "我亏了，特别想马上打回来 / 我想把它赚回来"
- "我心态崩了 / 我心态不好 / 怎么调整心态"
- "亏了之后我总想重仓 / 报复性交易 / revenge trading"
- "情绪 / 上头 / tilt / after loss"
- "赚这么多有点飘，还想再做一单"

### 与相邻能力的区分

- 与 `write-loss-action` 的区别: write-loss-action 是在**交易系统里提前写死**"亏损后要做什么"这条规则；本能力是**在亏损已经发生的那一刻**，用三栏把事实、感受、动作拆开，让那条规则真的被调用。前者是条文，后者是当场执行。
- 与 `rules-over-mindset` 的区别: rules-over-mindset 解决"平时怎么不靠意志力"（用外部规则约束）；本能力解决"亏损当场怎么不让情绪变成动作"。规则是事前设计，三步法是事后兜底。
- 与 `execution-root-cause` 的区别: execution-root-cause 诊断"管不住手"的**根因**（无逻辑／逻辑不全／心理问题）；本能力不诊断根因，只处理亏损后的**即时动作**。若三步法反复失败，应回到 execution-root-cause 做分诊。
- 与 `self-check-overtrading` 的区别: self-check-overtrading 查"做单动机是不是为了爽"；本能力查"亏了之后那一步做了什么"。前者事前自检，后者事后处理。

## E — 可执行步骤（Execution）

**必需输入**: 一笔已发生的亏损（金额或比例 + 方向 + 是否触发止损）；用户当前的即时想法。缺失时问："这笔单亏了多少？你现在最想做的一件事是什么？"

**交付物与完成标准**: 一张**三栏记录**——`事实` / `感受` / `下一步动作`，三栏都非空，且"下一步动作"栏必须是一个**可被系统判定的动作**（停手／等下一个触发／按规则离场），不能是"我要冷静一下""调整好心态"这类不可判定表述。完成标准：第三步的动作与交易系统里写死的亏损后规则一致。

**实现约定**: 三步法本身出自原文（ep-2026.8.14 L00651–L00698）；"三栏记录表"这一载体、以及"动作必须可判定"这条验收标准为**实现约定**，原文未给出记录模板。

1. **只写事实栏**
 - 完成标准: 内容只含可被第三方核对的客观陈述（价格、方向、亏损金额/比例），不含评价词（"蠢""应该""早知道"）。
 - 判停条件: 若事实栏里出现评价或情绪词 → 划掉重写，直到只剩客观陈述。
2. **写感受栏**
 - 完成标准: 至少命名一个具体情绪（难过／生气／不甘／害怕／兴奋），且用"我感到……"句式，不写"我要……"。
3. **写下一步动作栏**
 - 完成标准: 写出的动作能被规则判定（如"今天不再开新单""等系统再次触发""按止损离场"）。
 - 判停条件: 若写出的动作是"重仓打回来""加仓摊平""再赌一把" → **立即停止本流程**，判定为情绪化交易，直接跳到步骤 5。
4. **比对交易系统的亏损后规则**
 - 完成标准: 步骤 3 的动作与系统里写死的规则一致（一致 → 执行；不一致 → 以系统规则为准）。
5. **执行并留档**
 - 完成标准: 按步骤 4 的结论执行，并把三栏记录留存，作为日后统计"情绪化交易"频率的原始数据。
6. **区分"成本"与"罚款"（新增）**
 - 完成标准: 对这笔亏损给出二值判定——是"模式里该花的钱"（成本）还是"违反模式罚的钱"（罚款）；后者归入情绪化交易统计，不计入系统正常成本（口径见 I 段三阶段模型）。

**致命的是第三步**: 事实和感受都不会让你爆仓，只有第三步选错（情绪化交易）才会。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **把三步法当成"消除情绪"的工具**。它不承诺让你不难过；目标是让难过不改变行为。若用户期待"做完就不难受了"，目标就设错了。
- **在情绪没上来时把它当仪式**。三步法是亏损／大赚之后的即时处理，不是日常打卡。
- **用它替代风控**。若没有连损熔断、资金隔离这些事前规则，三步法只是事后补救，防不住反复上头。

### 作者警告的失败模式

- **连损／上头 → 重仓、报复性交易**（ep-2026.7.29 L00807–L00814）。陷阱：单笔打损后想一把打回；机制：用主观情绪对抗客观事实，形成恶性循环；预警信号："这一把我要把它打回来""亏了就想加倍做""连亏几单后突然上重仓"。**这正是第三步选错。**
- **亏损后找心理按摩 / 娱乐逃避**（ep-2026.9.16 L00691–L00713）。陷阱：用看动画片、看电影、出去转来"缓解"；机制：逃避不解决情绪，作者的做法是"硬挺"、直面脱敏；预警信号："难受了我就看个片放松一下""寻求心理按摩"。
- **用情绪／心态解决亏损问题**（ep-2026.10.5 L00635–L00645）。陷阱：把亏损归因于心态、把"心态>风控>技术"当真理；机制：技术好、风控好，心态自然好；技术不行总亏钱，心态才不行。预警信号："我心态不好""怎么保持心态"。
- **情绪化交易行为（过激与过怂两侧）**（ep-2025.11.7 L41、L49）。陷阱：连亏几单后调整仓位、重仓梭哈直到爆仓；或连续被打止损后、机会再来时反而不敢做；也包括扛单、重仓不敢拿单。原文："因为连续亏损了几单 随后你开始调整仓位 重仓梭哈 然后爆仓 再比如你做交易连续被打到几单止损 结果机会又出现的时候 不是你却不敢做了"。机制：根因不在情绪/人性，而在缺少规则——这对应"第三步选错"的两种表现（一种过激、一种过怂）。预警信号："连亏后突然上重仓""被连着打损后不敢再进"。

### 作者的盲点 / 时代局限

- **三步法的"停一停"没有量化标准**。原文未给"停多久""停到什么程度算停"，只说觉察到"想得跟平时不一样"就停手——这依赖使用者的自我觉察能力。
- **作者自承练不到毫无情绪**，也承认"上头了是控制不了的"。三步法是行为层的兜底，不是情绪层的解决方案，对已经形成重度赌性的人效力有限（作者对这类"心理问题"的判断是"只能靠亏疼"）。
- **标的与平台语境**。内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护；三步法不改变交易本身的高风险属性，也不构成任何投资建议。

### 容易混淆的邻近方法论

- **正念 / 情绪日记**：也记录感受，但目标是接纳情绪；本能力的目标是**让第三步动作不变形**，记录只是手段。
- **止损纪律**：管的是"该不该认错离场"；本能力管的是"认错之后那一步做什么"。
