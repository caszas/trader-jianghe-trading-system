# 能做 vs 硬座的判定闸门

## I — 方法论骨架（Interpretation）

这套方法的起点是一个很反直觉的取舍：判断"能不能做"不是去罗列"哪些不能做"，而是只守住"哪些我明确懂"。理由是认知圈外还有一层"你不知道自己不知道"的东西，它无法被穷举、也无法被识别，所以任何"我不确定但我感觉懂了"的状态都必须被归到不懂那一侧。作者把这件事叫"两极划分"：除了明确懂的那一小块，其余全部算不懂，中间不留模糊地带。

在这个划分之上，"能做"被给了三个可检验的特征：一是在认知以内（能指出它对应自己明确懂的那类行情）；二是下单时没有犹豫（不是"要不要问一下别人这盘面什么情况"）；三是事后倒推仍然会这么做——把行情走完、把时间倒回进场那一刻，你还会做同样的动作。三条同时成立才叫"能做"，除此之外的一切都叫"硬座"。

闸门的关键在于它是二值的。原文里没有"小仓位试一下"这个档位：硬座就是不做，不是缩小仓位做。这一点和后面所有涉及仓位的能力都不冲突——仓位能力处理的是"已经判定能做的单该给几成"，而本能力只回答"要不要进入这一步"。因此判定失败的出路只有一条：放弃、弃牌、空仓等待。学会弃牌被作者用斗地主"过牌"来类比，意思是交易没有任务量，不做不亏钱。

**补全（2026 新素材）——"认知圈"被进一步界定为"能力圈／系统内"**：

其一，**能力圈外的机会一律不做，也不追**。作者："只算自己系统之内的一个利润……我清楚的知道我的能力圈有多大，所以不该是我的机会，我绝对不会去尝试"（ep-2026.3.21 L0187）。即使信号没出现、行情直接飞走，也不追——市场每分每秒都有人赚钱，不可能赚到所有的钱。

其二，**学技术的目的是减少交易机会**。作者："学技术的目的并不是为了让你参与到所有的行情，而是为了限制你在不同的行情中开单……并不是增加你的交易机会，而是减少你的交易机会"（ep-2026.6.28 L85、L119）。这与本闸门"只减不增"的性质一致。

其三，**位置纪律补全**：只在关键位附近做单、从不在中途（行情半路）做单，中途出现信号也不做；且只做短线（从关键位到下一目标空间明确）（ep-2026.8.11 L488、L508、L514）。"关键位附近"的距离范围原文未给。

## A1 — 应用示例（Application Example）

### 示例 1: 早期被朋友带进加密，两人一起亏
- **类型与来源**: 原书亲历（ep-2026.9.23 L01105、L01148）
- **问题/输入**: 作者自述最早入行是被朋友带进加密，当时对加密完全零了解，把它当"资金盘／投资项目"做，纯靠胆大和运气。
- **方法论的使用**: 用闸门三步检验这笔"投资"——① 认知归属：当时他对加密没有任何明确定义，属于"圈外"；② 犹豫检验：并非无犹豫，而是靠运气和胆大；③ 事后倒推：事后他自己判定"进去先挨套"，说明当时的动作不可复制。三项均不通过。
- **结论**: 按闸门应判为硬座，不做。
- **结果**: 原书交代：朋友一心一意带他赚钱，结果"我俩一起亏"，作者早期"进去先挨套就给我套没"。作者据此把"认知圈"确立为决策边界。

### 示例 2: 连麦学员做山寨，越做越看不明白
- **类型与来源**: 原书转述的连麦案例（ep-2026.9.24 L02678、L02689）
- **问题/输入**: 学员自述做山寨币，刚开始能看明白，市场变化、吸引流动性之后"慢慢就看不明白"。
- **方法论的使用**: ① 认知归属：学员当下已无法把行情归入"我明确懂的"那一类（他自己说"看不明白"）；② 犹豫检验：正是"看不懂"驱动他来问；③ 事后倒推：既然当时已看不懂，倒推回去也不构成可复制的动作。三项不通过。
- **结论**: 判为硬座，结论是"直接离场、别做山寨"，而不是"换个小仓位继续做"。
- **结果**: 原书交代：作者建议直接离场，并称"那山寨那都不是正经市场"。

### 示例 3: 弱多结构上方有关键位压制——作者解盘时不做多
- **类型与来源**: 原书解盘（ep-2026.4.14 L0159）
- **问题/输入**: 一小时弱多（高低点仍向上但很弱），上方有大周期关键位顶着。
- **方法论的使用**: 用闸门检验这笔潜在多单——① 认知归属：作者判定该处不属于他会做的多单（理由：不是初期、上方有大周期关键位压制、这段上涨非常弱）；② 犹豫检验：他明确"我不会去从这儿找做多的性价比不是很高"；③ 事后倒推：不可复制的动作，不成立。三项不通过。
- **结论**: 判为硬座，不做多；做多只在回踩防守位、成本小、利润可期时做，否则等结构打破再看。
- **结果**: 原书交代：作者选择不在此处找多（作为解盘，未交代后续行情）。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户已经看好方向与位置，临下单前问"这单我到底能不能做"。
2. 用户复盘时承认"我当时就知道看不懂，但还是做了"。
3. 用户在做与不做之间反复犹豫，想找人确认盘面"到底什么情况"。
4. 用户说"机会这么好，不做可惜，先小仓位试试"。
5. 用户想把某个看起来诱人但明显超出自己经验范围的行情纳入可做清单。
6. 用户问"行情已经飞走了，要不要追一下"（能力圈外的机会，ep-2026.3.21 L0187）。

### 语言信号（用户的话里出现这些就应激活）

- "这单能不能做 / should I take this trade"
- "我小仓位试试 / 先试一手 / 先拿半仓将就"
- "我看不懂但感觉要涨 / I can't read it but it feels bullish"
- "硬座 / 硬做 / forcing a trade"
- "要不要问问别人这盘面现在什么情况"

### 与相邻能力的区分

- 与 `necessary-conditions` 的区别: necessary-conditions 检查的是条件层面（方向／位置／节奏／信号是否齐备）；setup-gate 是条件之上的资格闸门。四要素即使齐备，只要"需要问别人""事后不会重做"，仍会被本闸门判为硬座。
- 与 `healthy-order` 的区别: healthy-order 在"已决定要做"之后检查订单是否挑不出毛病；setup-gate 更靠前，先决定要不要进入质量评估。健康订单必然是"能做"的单，但"能做"不等于"健康"。
- 与 `entry-model-taxonomy` 的区别: entry-model-taxonomy 要求"先说清这笔单属于哪个进场模型，不属于任何模型就不做"，那是本闸门在"进场位置"这一维度上的具体化子闸门。
- 与 `no-binary-thinking` 的区别: no-binary-thinking 反对把因子二值化，而本能力的结论恰恰是二值的。二者不矛盾——二值化只允许发生在"做／不做"这一层；一旦判定要做，仓位、止损、进场、离场全部是可调因子。

## E — 可执行步骤（Execution）

**必需输入**: 候选订单的自然语言描述（方向、理由、位置、拟用止损、进场模型）；使用者自建的"我明确懂哪类行情"清单（字段：行情类型、判据）；下单前的犹豫自评（有／无）；事后倒推答案（会／不会重做）。缺失"认知清单"时应先问用户："你能明确说清自己懂哪一类行情？"若答不出，直接进入步骤 2 的判停分支。

**交付物与完成标准**: 输出必须是**二值**结论之一——`做` 或 `不做（硬座）`，并附一句理由（指明是认知／犹豫／倒推哪一项未通过）。完成标准：输出中不含"小仓位试试""看情况""先做着看看"这类第三态；若任一项未通过，最终字段只能是 `不做（硬座）`。

**实现约定**: 原文只给了"能做／硬座"的两极划分与三条描述，未给任何可计算的阈值或判分公式。本卡把三条描述操作化为"认知归属／犹豫／事后倒推"三个可提问的检验点，属**实现约定**，不改变"除能做之外全是硬座"这一原意；"我明确懂哪类行情"的清单也必须由使用者自建（原文：上涨／下跌趋势的明确定义细则原文未给出）。

当能力被激活后，agent 应按以下步骤执行：

1. **写出这笔单的逻辑**
 - 完成标准: 能用一句话说出"我做这笔单是因为我认为它会往 X 走"，且句中不含"感觉""应该""大概"。
 - 判停条件: 若说不出一句话逻辑 → 该单无资格进入后续，直接判 `不做（硬座）`。
2. **认知归属检验**
 - 完成标准: 能指出这笔单对应认知清单里的**具体哪一条**（不是"差不多算这类"）。
 - 判停条件: 找不到对应条目，或只能答"我不确定／好像懂" → 判 `不做（硬座）`，终止。
3. **犹豫检验**
 - 完成标准: 使用者能回答"下单时不犹豫、不用问别人"。
 - 判停条件: 出现犹豫，或需要问别人"这盘面什么情况" → 判 `不做（硬座）`，终止。
4. **事后倒推检验**
 - 完成标准: 假设行情已走完、时间倒回进场那一刻，使用者回答"我还会这么做"。
 - 判停条件: 回答"不会／当时只是试试" → 判 `不做（硬座）`，终止。
5. **二值化输出**
 - 完成标准: 仅输出 `做` 或 `不做（硬座）`。判定为 `做` 时才把订单交给 `necessary-conditions` 与 `healthy-order` 继续处理；判定为 `不做` 时**不进入**仓位计算，不调用 `position-sizing-by-stop`。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **用来给"想做"找理由**。本能力只会减少机会、不会增加机会；若使用者带着结论来，它会退化成自我说服。
- **已经明确不做之后反复自检**。它不是拖延工具，也不是"再确认一下"的接口。
- **评估离场、加仓、仓位大小**。那属于 `order-exit-discipline`、`position-allocation`、`position-sizing-by-stop`，本能力只回答下单前的资格。
- **把"能做"当成"一定会赢"**。能做只是"在我的认知内、我可复制"，不改变交易是概率游戏的事实。

### 作者警告的失败模式

- **硬做（看不懂／明知高风险仍做）**（ep-2026.8.14 L01752–L01756、ep-2026.9.14 L00313、ep-2026.9.25 L00903）。陷阱：看不懂行情却硬做，或明知是高风险单还"小仓位试试"，亏了又不认。机制：不在认知内，事后只能反推理由、不可复制；既然知道是高风险单就不该做，该学会弃牌、挑食，而不是明知是"屎"还拿起来吃。预警信号："我知道这是高风险单的我小仓位试试吧""做之前就犹豫""需要问别人""亏损后找外部理由"。
- **把震荡当趋势硬做**（ep-2026.8.17 L00231、ep-2026.9.10 L00508）。陷阱：在无趋势的震荡里硬找趋势做单，或在宽幅震荡中间凭看到一根K线就临时起意。机制：没有趋势本身就是信息，硬做必亏；震荡中间区域空间不够、没有明确信号。预警信号："画不出趋势还硬做""我在中间看到……能不能做呀"。
- **逆势硬做**（ep-2026.9.29 L00659–L00668、ep-2026.10.5 L01273–L01277）。陷阱：已经判断出方向却反着做，或在主周期为空头时顶着做多。机制：与主周期不共振，属低质量订单，即使赚钱也不该要这个钱，等于左右脑互搏。预警信号："我知道是上涨但我做空""主周期空头仍找机会做多"。
- **为直播／受弹幕影响硬做单**（ep-2026.10.5 L01289–L01296）。陷阱：为了直播效果开单、受弹幕节奏影响。机制：注意力应以盘为主，聊天时容易错过机会或被带节奏。预警信号："为直播硬做""被弹幕带节奏"。
- **什么行情都冲（赌狗）**（ep-2026.1.9 L128）。陷阱：所有行情都用一样仓位去冲。机制："赌狗是什么行情都冲，而交易员是应该在该冲的时候冲"——只应在有概率优势、该冲的时候加大仓位，该休息时休息。预警信号："这波我也想参与一下""每单都上"。
- **问别人做多做空（无自我意识）**（ep-2026.8.22 L329、L356）。陷阱：混各种群、天天问别人行情怎么做、看收益图求带。机制：别人给结果你接不住（周期／理念／胜率追求不同）；明明自己认为做多，听人一顿说改做空，是"最愚蠢的"；应关闭聊天渠道、埋头自学，请教问题而非索要结果。这正是"犹豫检验"要拦下的情形。预警信号："这单别人怎么看""求带""群友说要做空"。
- **"大家都这么说"——盲从网友**（ep-2026.9.5 L255、L263）。陷阱：把"大家都这么说／他们说"当依据。机制：100 个网友里可能 99 个都亏钱，听他们没用；要有自己的判断与信息来源（K线），不被大众观点牵着走。预警信号："大家都这么说""他们说"。

### 作者的盲点 / 时代局限

- **"认知内""有没有犹豫"都是主观自评，无法外部验证**。闸门完全依赖使用者对自己诚实；作者本人也承认"手工交易能赚钱取决于两个字——主观"。一个自欺的使用者可以轻松把任何单子说成"认知内、不犹豫"。
- **"明确定义的行情"原文未给细则**。原文 明确写着"上涨／下跌趋势的明确定义细则原文未给出"，所以"我懂哪一类"这份清单必须由使用者自建，本卡无法代填。
- **合规与平台语境**。全部内容围绕黄金 CFD 与加密合约展开，这两类平台在中国大陆不受法律保护，作者本人也承认"不敢说自己是做这个的"。与平台规则绑定的操作（如出金、对锁、数据行情规避）不属于通用交易能力，本卡不做蒸馏，仅作风险提示；本卡内容不构成投资建议。
- **闸门不能替代经验**。它只能把"该不该做"的判定顺序固定下来，无法告诉使用者"你实际懂什么"。

### 容易混淆的邻近方法论

- **"小仓位试一下"**：作者明确否掉。试仓是把劣质条件用仓位中和，属"包容行为"（见 `healthy-order`）；本闸门输出只有做／不做。
- **"胜率低的单不做"**：闸门不看胜率，看认知与犹豫；一笔高胜率的单若是硬座，照样不做。
- **"没到位置不做"**：那是 `necessary-conditions` 的位置维度，本闸门在位置之上还要求认知与不犹豫。
