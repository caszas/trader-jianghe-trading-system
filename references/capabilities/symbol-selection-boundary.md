## I — 方法论骨架（Interpretation）

这套体系把"能不能做"的载体放在**逻辑**上，而不是放在**品种**上。同一套逻辑默认可以搬到不同品种，因为真正起作用的是对结构、关键位、进场与止损的处理，不是某个标的本身。作者只做黄金，是精力、时间、成本约束下的取舍，并不等于"只有黄金能赚钱"；反过来，"我没赚钱是因为没做对品种"是把因果放错了位置。

唯一的例外是**极小众、纯控盘、筹码严重失衡**的盘子。在那里信息不对等，筹码集中在少数人手里，关键位可以被他们自己画出来、上下由他们定，技术博弈的前提被破坏——技术分析在这类品种上失效。这是"系统适配"受品种限制的唯一情形。

"在垃圾堆里找食物"是这条边界的反面教材：桌上摆着流动性充足、合规明确的机会不做，偏要去山寨币里挑"流动性高一点"的做。作者观察这类地方靠的是筹码、子弹、胆量、信仰，不是技术。

**专注一个主品种属于精力管理，不属于系统绑定**。因为人的精力有限，同时看十个二十个品种会分散注意力、拉低决策质量，所以把精力砍到一个主品种上。这是注意力范围的收敛，和系统"能用在哪些品种"是两件事。

关键口径必须钉死：**集中注意力不等于梭哈**。聚焦一个主品种只约束你"看什么、跟踪什么"，不约束仓位大小；重仓与否仍由仓位与风险规则决定，不能拿"专注"当加仓理由。

本能力的输出是一个判断：某候选品种对这套系统是"默认可用""控盘例外不可用"，还是"精力上暂不纳入"。

## A1 — 应用示例（Application Example）

### 示例 1: 想用技术挑山寨币（原书反例 / 观点转述）
- **类型与来源**: 原书反例与观点转述，非亲历成交案例（ep-2026.11.18 L376、ep-2026.11.18 L396、ep-2026.11.18 L497）。

- **方法论的使用**: 先识别这是"放弃桌上的菜、去垃圾堆找食物"的行为；再指出山寨信息不对等、筹码集中在发币方及相关人手里，关键位与技术共识失效；最后说明这类地方靠的是筹码/子弹/胆量/信仰而非技术。
- **结论**: 判"不做"，技术方法不适应该品种。

### 示例 2: 对候选品种做适配判定（合成演练）
- **类型与来源**: 素材只给规则、无带数值的判定记录；以下为**合成演练**，用于演示步骤，不代表作者亲历。
- **问题/输入**: 交易者目前以黄金为主，问"我这套系统能不能拿去做某小众合约"。
- **方法论的使用**:
 1. 默认判定：载体是逻辑，系统与该品种不强绑定 → 标"默认可用"。
 2. 例外排查：该合约是否极小众/纯控盘/筹码失衡？若是 → 技术失效，改标"不可用"并结束；若否 → 继续。
 3. 反例核对：诉求不是"放弃优质标的去低质量标的挑机会"，跳过"垃圾堆找食物"判停。
 4. 精力管理：交易者精力不足以同时跟踪多个品种 → 保留黄金为主品种，该合约标"暂不纳入"，理由是精力而非系统不适配。
 5. 注意力与仓位解耦：写明聚焦黄金只是收窄跟踪范围，仓位仍按既有仓位规则，不因此梭哈。
- **结论**: 系统可用性上该品种"默认可用，除非落入控盘例外"；是否投入精力另判。
- **结果**: 演练演算，无真实交易结果。
- **缺口**: 原文未给"小众/控盘"的客观界定标准。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户问"我这套系统能不能用到 X 品种上 / 这方法在别的品种还灵吗"。
2. 用户说"我没赚钱是因为没做对品种 / 是不是该换个品种"——需要纠正"品种决定盈亏"的错觉。
3. 用户想做山寨币并试图用技术筛选，例如"能否挑流动性高一点的山寨做"。
4. 用户同时盯十几个品种、精力分散、决策变差，问该不该聚焦一个主品种。
5. 用户把"专注一个主品种"理解成"重仓/梭哈单一品种"。
6. 用户问某极小众/疑似控盘品种的关键位、技术信号是否可信。

### 语言信号（用户的话里出现这些就应激活）

- "系统绑品种吗 / 换个品种还灵吗 / 能用在哪些品种"
- "没赚钱是因为没做对品种 / 是不是品种选错了"
- "山寨币 / 小众盘子 / 控盘 / 流动性高一点的山寨"
- "看多少个品种 / 精力分散 / 专注一个主品种"
- "集中注意力 / 梭哈 / 重仓一个"

### 与相邻能力的区分

- 与 `kline-market-reading` 的区别: 该卡讲单个品种的K线如何倒推多空行为；本能力在"要不要把这套逻辑用到某品种"的层面做适配判断，是标的选择层面，不是单品种读数层面。
- 与 `setup-gate` 的区别: 该卡判"这一笔能不能做"（能做 vs 硬做），针对单笔机会；本能力判"这个品种/这类品种能不能纳入系统"，针对标的集合。
- 与 `mentor-consistency-check` 的区别: 该卡评估某个交易博主的手法是否一致；本能力评估品种与系统的适配，不评估人。
- 与 `timeframe-contract` 的区别: 该卡配置主/次周期；本能力配置品种集合，两者是"周期维度"与"品种维度"的分工。
- 与 `state-and-event-guard` 的区别: 该卡管精力/身体状态与数据行情冷却；本能力只借用"精力有限"作为聚焦主品种的理由，产出是品种选择，不是状态冷却。

## E — 可执行步骤（Execution）

**必需输入**: 待判断的交易逻辑/系统；候选品种及其市场结构信息（是否极小众、是否疑似控盘或筹码集中、流动性、合规性）；交易者当前精力与经历（决定聚焦几个品种）。

**交付物与完成标准**: 一份品种适配判定 —— 每个候选品种标注"默认可用 / 控盘例外不可用 / 精力上暂不纳入"三选一并附理由。完成标准: 结论不出现"某品种才赚钱"的预设；"专注主品种"与"仓位大小"被明确分成两件事。

1. **默认判定**
 - 以逻辑为主，系统与品种不强绑定 → 候选品种默认标"可用"。
 - 完成标准: 不把盈亏归因于"做没做某个品种"。
2. **例外排查（小众/控盘）**
 - 检查是否极小众、纯控盘、筹码失衡（信息不对等、关键位可被自画、上下由少数人决定）。
 - 完成标准: 若是 → 判"不可用"，技术失效，该品种到此结束；若否 → 进入下一步。
 - 缺口标注: 原文未给"小众/控盘"的客观界定标准（**实现约定**：仅凭定性描述不替使用者判定具体品种，交回使用者自行核实）。
3. **反例核对（垃圾堆找食物）**
 - 若诉求是"放弃流动性充足、合规明确的品种，去低质量品种挑机会" → 指出该行为，判"不做"。
 - 完成标准: 识别出该行为并给出不做结论。
 - 缺口标注: 原文未给"靠技术无法盈利"的样本统计口径（**实现约定**：只给定性结论，不作统计推断）。
4. **精力管理（选一个主品种）**
 - 评估精力能否支持同时跟踪多个品种；不能 → 聚焦一个主品种，其余标"暂不纳入"。
 - 完成标准: 写明主品种，且"暂不纳入"的理由是精力，不是系统不适配。
5. **注意力与仓位解耦**
 - 明确"专注一个主品种"只约束注意力范围，不约束仓位大小。
 - 完成标准: 写明仓位仍按既有仓位与风险规则执行，不因聚焦而梭哈。

**实现约定**: "小众/控盘"客观标准、"靠技术无法盈利"样本口径、"精力够/不够"判定标准原文未给，本卡只做定性分流、不替使用者判定具体品种；不改变"系统默认不绑品种、控盘例外技术失效、专注是精力管理"的原意。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **要具体品种涨跌预测时**。本能力只判"系统/精力是否适配该品种"，不产出方向、价位或涨跌预测；不收具体品种涨跌预测。
- **把"专注一个主品种"当成系统绑定或加仓理由时**。专注是精力管理，集中注意力不等于梭哈。
- **在流动性充足、合规明确的正常品种上硬套"控盘例外"时**。默认不绑品种，例外只针对极小众/纯控盘品种。

### 作者警告的失败模式

- **"品种决定盈亏"错觉**（ep-2026.11.17 L1156、ep-2026.11.17 L2674、ep-2026.11.17 L2683）。陷阱: 认为"没赚钱是因为没做这个品种"。机制: 系统的载体是逻辑，换品种不解决执行与认知问题。预警信号: "是不是该换个品种做"。
- **垃圾堆找食物**（ep-2026.11.18 L376、ep-2026.11.18 L396、ep-2026.11.18 L497）。陷阱: 放弃桌上合规且流动性充足的标的，去山寨里挑"流动性高一点"的。机制: 筹码集中在发币方，可自行画K线、决定关键位有效性，技术博弈前提被破坏，靠的是子弹/胆量/信仰。预警信号: "能否挑流动性高一点的山寨做"。
- **多品种分散精力**（ep-2026.11.5 L92、ep-2026.11.5 L120、ep-2026.11.5 L127）。陷阱: 同时看十个二十个品种。机制: 精力分散导致决策质量下降。预警信号: "我同时盯十几个品种"。

### 作者的盲点 / 时代局限

- **"小众/控盘"无客观界定标准，原文未给**；只能定性描述，无法量化分级，落地依赖使用者自行核实。
- **山寨币"靠技术无法盈利"无样本统计口径，原文未给**；结论为作者观察，不是统计数据。
- **"精力够/不够"无客观判定标准，原文未给**；只能按定性自评执行。
- **平台与合规语境**。内容围绕黄金 CFD 与加密合约，这类平台在中国大陆不受法律保护；山寨币部分尤其涉及合规风险。内容不构成投资建议。

### 容易混淆的邻近方法论

- **能力圈 / 只做认知以内的单子**: 那是按"认知"划界；本能力按"品种市场结构 + 精力"划界，判据不同，可叠加使用。
- **单一品种重仓 / 集中度管理**: 那是仓位维度；本能力的"专注一个主品种"是注意力维度，集中注意力不等于梭哈。
- **技术分析方法本身的好坏**: 本能力不评判某技术方法是否有效，只评判它在某类品种（小众/控盘）上是否失效。
