## I — 方法论骨架（Interpretation）

不设静态止盈。理由很简单：亏损是自己能决定的，盈利是市场给的——设死一个止盈位，等于认定"价格到那里就会反转"，这是试图掌控市场。

替代方案是**动态离场**：只挂止损，随行情推进不断上移止损保护利润，离场与否取决于"行情还能不能沿原方向流畅运动"。对一笔空单，判据是：不能继续向下、动能减弱、不能流畅向下、创不出新低——四条中任一条成立，就可以走。多单对称。

离场判断有两种实现方式，且不可兼得：
- **敏感离场**：等"一个减弱信号"就走（K 线动能变化），能避开大部分大幅回撤，但容易卖飞。
- **钝化离场**：等"结构被打破"或"推左一"才走（用左侧第一根 K 线跟着往上推止损），趋势能拿更长、盈亏比可能更高，但会有大幅回撤。

还有一个常用的操作习惯：当"不想拿了""感觉超出预期""执行管理变难"时，不直接平仓，而是把止损推到保本或保护利润的位置，留一个"继续奔跑"的可能性。

要点是：离场由**逻辑触发**，逻辑触发就走、没触发就拿着，不按时间点进出场，也不看单根 K 线。至于"该不该走"和"止损怎么移"是两件事——本能力判前者，移动规则归 `stop-loss-mechanics`。

补充几套原文给出的离场实现，按周期/场景细分：

- **剥头皮两型离场**：①"价格停滞"——进场后价格不再朝有利方向走（做多不创新高）就立即走，不等收 K 线，可用于均线缠绕的震荡；也可用"连续两次不能创新高/新低"或分时图"双尖一冲"代替。②"收反向 K 线"——收出一根反向 K 线就走，可用于均线稳定时。依据未破且价格再次给出同向发力，可对同一根 K 线反复做 T（ep-2026.4.9 L2263、L2402、L2531）。
- **被动离场 / 主动离场**：被动离场＝打到固定止损/止盈；主动离场＝出现否定信号提前走、或行情继续肯定而延后走。规则：**未拿到 1:1 盈亏比前绝不主动离场**；达到 1:1 后按 N 字形是否延续决定是否提前走；离场后可等二次进场（ep-2026.7.28 L90、L210、L241）。
- **不贴长短标签**：作者不预设自己是短线或长线交易员，一笔多单只要没反转就一直持有，做长做短由市场决定（ep-2025.11.23 L322）。

口径提示：上面"被动离场（含固定止盈）"与另一处的"预期止盈参考位"（设到主周期 K 线的**实体部分**，不追最高/最低点、不吃满，ep-2026.4.12 L0067、ep-2026.4.8 L0098），都与本卡"不设静态止盈"的主线**表述不同**。二者并存、不改旧说——本卡主线仍是"不设静态止盈、由动能延续性触发离场"；上两条属作者在不同语境下的另一套表述，使用者需自行区分适用场景。

## A1 — 应用示例（Application Example）

### 示例 1: 5 分钟回踩多单，靠推止损赚钱离场
- **类型与来源**: 原书亲历案例（ep-2026.8.14 L02445–L02571）
- **问题/输入**: 作者当天做两单，5 分钟回踩入场、用 1 分钟细化进场；其中一单位置差一点，先清掉半仓。
- **方法论的使用**:
 1. 不设静态止盈，只挂止损
 2. 行情沿原方向推进时，不断上移止损保护利润
 3. 直到出现"不能继续沿原方向流畅运动"的信号才离场
 4. 位置不理想时，先减半仓（该动作属仓位层面的处理，不在本能力范围内）
- **结论**: 出口由动能延续性触发，而非预设目标位。
- **结果**: 两单均赚钱离场（原书交代）。

### 示例 2: 差一点到止盈位就反向
- **类型与来源**: 转述案例（ep-2026.9.24 L02198–L02217）
- **问题/输入**: 学员设了一个止盈位，价格差一点没到就反向，这段利润没吃到，于是觉得"剧本没演完"，产生报复心重新做进去。
- **方法论的使用**:
 1. 定位问题：学员把"价格必须走到止盈位"当成必然，这是试图掌控市场
 2. 用动态离场替换静态止盈：不再预设"必须到某点"，而是看行情还能不能继续运动
 3. 预期别给那么高，做跟随；没到止盈位就反向，本身不构成"市场欠我一段"
- **结论**: 应改为动态离场，不设死止盈。
- **结果**: 作者建议动态离场、别想掌控市场（未说明后续）。

### 示例 3: 9/14 日内两笔多单，止损上移被打掉（原书亲历案例）
- **类型与来源**: 原书亲历实盘（ep-2026.9.14 L198、L217）。
- **问题/输入**: 前一段下跌的关键位被打破且阳线强、与空头关键位拉开距离 → 判定为"强第一推动"；回调出阴线后一根阳线吞没 → 多军保持控制权，于阳线收 K 进场。
- **方法论的使用**:
 1. 因回调阴线实体较大、成本空间大，用**较轻仓位且不加仓**
 2. 止损贴脸放到下方，止盈**不做预设**
 3. 行情推进后上移止损保护利润，直到止损被打掉，视为一次离场
- **结论**: 出口由"止损上移被打掉"触发，属微波段；全天做两笔多单。
- **结果**: 止损上移后被打掉离场；该单盈利金额**原文未给**。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. 用户问"止盈设在哪里好""要不要设一个固定止盈"。
2. 用户持仓有浮盈，问"现在该不该走""还能不能拿"。
3. 用户抱怨"每次差一点到止盈就反向，特别难受"。
4. 用户说"我知道要拿住，但不知道什么时候该走"。
5. 用户问"浮盈回吐了要不要先出来"。

### 语言信号（用户的话里出现这些就应激活）

- "止盈设在哪 / take profit / TP"
- "现在该不该走 / 什么时候离场"
- "拿不住 / 浮盈回吐 / 利润回撤"
- "差一点到止盈就反向"
- "dynamic exit / 动态离场 / 移动止盈"

### 与相邻能力的区分

- 与 `stop-loss-mechanics` 的区别: **本能力回答"该不该走"，stop-loss-mechanics 回答"止损怎么移"**。本能力输出"离场/继续持有"的判定；stop-loss-mechanics 输出"新的止损价"。两者配合使用，但问题不同，不要用"推止损"来替代"离场判定"，反之亦然。
- 与 `exit-choice-tradeoff` 的区别: 本能力提供了敏感/钝化两种实现，但"选哪一种"由 exit-choice-tradeoff 的必选题决定；本能力不替用户选偏向。
- 与 `order-exit-discipline` 的区别: order-exit-discipline 规定出口的合法集合（只有打止损或赚钱离场）；本能力是"赚钱离场"那一侧的具体判定机制。
- 与 `strength-and-momentum` 的区别: strength-and-momentum 判的是进场侧的强弱与动能；本能力把同一套"动能是否延续"的判据用在持仓侧。

## E — 可执行步骤（Execution）

**必需输入**: 持仓方向；当前价；最近若干根 K 线的高低点（用于判断"是否创出新高/新低"）；进场逻辑；用户已选定的离场偏向（敏感 / 钝化）——若未选定，先走 `exit-choice-tradeoff`。

**交付物与完成标准**: 输出一份**离场判定** —— `是否离场`（是/否）、`触发信号`（哪一条：创不出新低/新高、动能减弱、不能流畅运动、结构被打破）、`依据的 K 线与结构`、`若继续持有，下一步的关注点`。完成标准：判"是"时必须能指出具体的 K 线或结构点，不允许只写"感觉不行了"；判"否"时必须写出"什么情况下才走"。

**实现约定**: 原文把判据说成"动能减弱""不能流畅运动""创不出新低/新高"，但未给出量化口径。本卡把以下取值标为**实现约定**：① "创不出新低/新高"＝在最近 N 根（默认 3 根）同周期 K 线内未再创出比前一根更低的低点（空单）或更高的高点（多单）；② "不能流畅运动"＝出现一根反向实体 K 线，且其收盘价收回上一根推进 K 线的 50% 以上；③ "结构被打破"＝最近一个防守位/发力点被反向穿越并收盘确认。三者命中任一即判"是"。

1. **确认偏向已选定**
 - 完成标准: 用户明确说了选敏感还是钝化。
 - 判停条件: 未选 → 跳到 `exit-choice-tradeoff`，选定后再回来。
2. **取最近的结构与 K 线**
 - 完成标准: 列出最近 3 根同周期 K 线的高低点，以及最近一个防守位/发力点价位。
3. **按偏向套用判据**
 - 完成标准: 敏感偏向只查"动能减弱/不能流畅运动"；钝化偏向只查"创不出新低/新高 + 结构被打破"。不得两种都查（那会变成"两头都要"，见 `exit-choice-tradeoff`）。
4. **输出判定**
 - 完成标准: 给出是/否 + 触发信号 + 具体依据。
 - 判停条件: 判"是" → 执行离场，跳到步骤 6。
5. **若继续持有，给关注点**
 - 完成标准: 写明"接下来看哪一根/哪个位置"，并转 `stop-loss-mechanics` 决定是否推止损。
6. **记录离场**
 - 完成标准: 记下离场价、触发信号、当时的动能状态，供复盘口径（`review-scope`）统计。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **订单还没有浮盈时**。本能力是"赚钱离场"那一侧的机制；亏损侧的处理归 `order-exit-discipline` 与 `trapped-order-triage`。
- **用来替代止损**。"只带止损不设止盈"里，"带止损"是前提；把动态离场当成"反正会走"而省略止损，是反向误用。
- **宽幅震荡里机械套用"创不出新低就走"**。震荡中价格本来就不创新高低，会把正常波动读成离场信号；此时应回到 `range-market-playbook`。

### 作者警告的失败模式

- **试图战胜市场 / 掌控市场（设死止盈）**（ep-2026.8.3 L01562–L01568）。陷阱：设死止盈、非要市场走到某个点，追求面面俱到。机制：个人无法对抗市场合力，越较真越痛苦；市场不会尊重你的止盈位，差一点不到就反向会让人产生报复心重进。预警信号："差一点到止盈就反向→报复心重进""认定价格到某点必反转"。
- **贪（有利润不走，回撤到差点不够手续费）**（ep-2026.10.5 L02600–L02604，作者自述复盘）。陷阱：有利润时因"发力好"想拿住，不走该走的止盈位，结果回撤被扫。机制：贪心让他放弃该走的止盈位，价格直接回来被扫。预警信号："这单子贪了""看着发力不错就想拿""没走就回来扫了"。

### 作者的盲点 / 时代局限

- **"动能减弱""不能流畅运动"没有量化口径**。本卡给的 N 根 K 线、50% 收回等阈值都是实现约定，原文未给。
- **剥头皮"价格停滞"的秒数标准原文未给**。作者说"我没有特意掐秒数"，只凭"明确停滞"判断（ep-2026.4.9）；无法量化为可执行阈值。
- **"N 字形构成失败"的判定次数阈值原文未给**。示例为"连续两次未破前高"，但未规定统一阈值（ep-2026.7.28）。
- **两型偏向的代价不对称，原文只说"选一个"**，未给"什么性格/数据该选哪型"的判据。
- **震荡行情下的适用性存疑**：动态离场在趋势里表现好，在宽幅震荡里容易反复触发，原文未系统讨论。
- **标的与平台语境**。内容围绕黄金 CFD 与加密合约，作者自承数据行情滑点极大，离场判定与成交价会有偏差；这类平台在中国大陆不受法律保护，全篇不构成投资建议。

### 容易混淆的邻近方法论

- **固定盈亏比止盈**：那是静态离场，与本能力相反；作者明确只设止损不设静态止盈。
- **被动离场（含固定止盈）**：作者另一处把"打到固定止盈"列为被动离场（ep-2026.7.28）；与本卡"不设静态止盈"的主线表述不同，属不同语境的另一套说法，不能直接混用。
- **时间止盈（拿够多少根就走）**：作者明确"离场由逻辑触发，不按时间点"。
