# 决策规则速查 — 交易员江河 · 交易决策体系

| 能力 | 一句话规则 |
|---|---|
| 放大优势（胜率与盈亏比不可兼得） | 胜率与盈亏比不是选出来的而是你的初始条件——只能发现优势再无限放大，新手要数据极端化而非均衡化。 |
| 本金规模与备用金 | 本金取"亏了会心疼"的量级（约两三个月工资），且必须单独留备用金——不要把所有钱都扔进交易。 |
| 资金隔离与分批出金 | 账户只留当日最大使用额度，盈利每日提出到另一个钱包，不足时补入——物理上不给自己重仓的机会。 |
| 静态复利（固定式复利 + 资金隔断） | 反对随账户同步放大的动态复利——按初始基数固定比例做，达成分段目标后提走一半、另一半并入继续。 |
| 连损熔断（同一逻辑两次即停） | 同一个逻辑连续被止损两次就停手——第三次即使再给信号也不做，卖飞也认。 |
| 可固定成本换不固定收益（交换公式） | 下单前先算成本——用可被固定的成本，去换取不固定的收益。 |
| 模拟盘 → 实盘的数据折损评估 | 模拟盘数据到实盘要打折——胜率先按减 10% 估，先做资金隔离再小仓验证。 |
| 动态离场（动能延续性判断） | 不设固定止盈——行情不能沿原方向流畅运动（动能减弱、创不出新高低）时就离场。 |
| 优先参与行情初期（该参与哪一段） | 行情分初/中/末期——初期是加分项、末期是减分项；不追已经走远的趋势。 |
| 情绪三步法（事实 → 感受 → 我要怎么做） | 亏损后按三步走——① 事实是什么 ② 我感受到什么 ③ 我下一步要做什么；致命的是第三步，不是情绪本身。 |
| 进场模型五分类与左右侧 | 判断一笔单属于左中左/左中右/右中左/右中右还是共振——不属于任何模型就不做；左侧要点位优势，右侧只帮你少亏。 |
| 管不住手 / 执行不到位的根因诊断 | 管不住手的根因不是意志力，是你对自己的逻辑不相信、不明确——用数据说服自己。 |
| 离场二选一（卖飞 vs 利润回撤） | 离场方式是必选题——能接受卖飞就给敏感离场，能接受回撤就给钝化离场，绝不两头都要。 |
| 忘掉形态·形态是逻辑的载体 | 忘掉形态——一个逻辑可以有多种形态，一个形态在不同背景下含义不同；看的是变化过程，不是图形名字。 |
| 成长与学习三阶段 | 成长三阶段（积累经验 → 积累财富 → 守住财富）与学习三阶段（抄 → 拼 → 内化）；顺序不能跳关。 |
| 健康订单与不做包容行为 | 起步点必须是"挑不出任何逻辑毛病"的健康订单——有劣质条件就直接不做，不是小仓位做。 |
| 内部结构只用于明确外部结构 | 内部结构的唯一作用是帮你明确外部结构；交易决策以主周期（外部结构）为准，内部震荡就换周期或不做。 |
| 投资与投机判定 | 投资=买公司的一部分（假设明天退市、5 年不上市还敢按此价买入）；投机=想低买高卖赚价差——与持有时间长短无关。 |
| 关键位区域化与交易位/参考位 | 关键位是一个区域不是一条线——先分清"交易位"与"参考位"，再在区域内等当下的价格反应。 |
| 从K线倒推多空行为 | 不看形态看行为——先问"现在谁在赚钱"，再问"这个变化意味着谁的订单被套或被解套"。 |
| 交易博主手法一致性评估 | 判断一个交易博主值不值得学，看手法有没有一致性——第一单和第 1000 单是不是同一套逻辑。 |
| N字形结构（结构型突破） | N 字形是这套体系的唯一结构单元——任何周期的走势都拆成"推动—回撤—推动"，连续向上的 N 即上涨，N 无法延续即震荡。 |
| 必要条件与组合判断 | 必要条件出现才做、不出现绝不做；方向/节奏/位置/信号缺一不可，信号排最后。 |
| 不做二极管思维（一笔订单的因子拆解） | 不能做多不等于就能做空——除了买卖方向，仓位、止损、进场、出场都还是可变因素。 |
| 拆订单回测法（拆盈利找必要条件；拆亏损砍条件） | 把历史里所有同类机会全找出来，拆盈利找必要条件、拆亏损砍条件，不看单次看整体。 |
| 订单出口纪律（只有打止损或赚钱离场） | 一笔订单只有两个出口——打止损，或赚钱离场；没有"没打止损就割肉"这第三种，也不推保本。 |
| 筹码分配与评分系统（只递减不递增） | 健康订单起步、按机会质量分层给仓——符合逻辑给半仓、有共振加分给正常仓，且只递减不递增。 |
| 以损定仓（逻辑否认点 → 仓位反推） | 先找逻辑否认点当止损，再由止损距离反推仓位——顺序是先定止损、再定仓位。 |
| 抓转折：第一推动 + 微弱回调 → 第二推动 | 强势行情不追单——等强势第一推动之后的微弱回调走完，在回调结束处进场拿第二推动；只做第一推动。 |
| 宽幅震荡识别与高空低多 | 创新高/新低无法延续、无跟随、价格收回 = 震荡；只做上下沿，中间位置不碰，压缩段尽量别碰。 |
| 复盘口径（只看实际结果） | 复盘只统计实际成交结果——卖飞是假盈利，亏损才是真亏；同一逻辑的亏损是必要成本，不必刻意复盘归因。 |
| 单笔风险预算与当日熔断（亏不没） | 单笔固定亏 1%–2%，账户只放当日最大回撤额度（如 10%），到线即熔断停手。 |
| 盈亏比 1:1 底线（低于此不做） | 1:1 是盈亏比的下限，只可提高不可降低；未拿到 1:1 之前绝不主动离场。 |
| 用规则替代修心 | 新人修心没有用——用外部规则约束行为，重复执行直到成为肌肉记忆；意志力是消耗品。 |
| 短线剥头皮操作手册（强转弱到弱转强） | 剥头皮是牺牲盈亏比换胜率与频率的打法——只赚波动不赚趋势，前置条件（点差/手续费/流动性）比技术更决定成败。 |
| 过手瘾 / 假想稳定自检 | 自检两件事——做单是为了赚钱还是为了爽（过手瘾）；有没有拿单日收益外推成年收益（假想稳定）。 |
| 能做 vs 硬座的判定闸门 | 看不懂、有犹豫、需要问别人的，一律不做——判定结果是二值的"不做"，不是"小仓位试一下"。 |
| 精力/身体管理与数据行情冷却 | 精力状态大于市场时段，状态不好绝对不做；数据公布前 5 分钟停下来留白，让冲动消退。 |
| 移动止损机制 | 盈亏比到一比一开始推止损，按结构点（发力点/防守位）逐级推；亏损单不再挪止损。 |
| 强弱判断与动能/结构取舍 | 强弱先看结构、再看动能、最后看单根K线，而且是走出来才知道；动能与结构二选一时优先动能。 |
| 周期契约与主/次/参考周期配置 | 周期不是方向而是"拿什么成本换什么利润"的契约——顺主周期即可，次周期只做精细化进场。 |
| 交易系统构建（主观构建 → 客观执行） | 交易系统三环节——知识点获取 → 主观构建并自我论证 → 回测优化；且"触发才做，不是想做就做"。 |
| 被套单排障（逻辑被否认即离场） | 不许有被套单——当初的做单逻辑被否认时就离场，不要扛到解套。 |
| 趋势与结构延续的明确定义 | 用高低点变化定义趋势——方向改变要"防守位被打掉 + 走出延续"两条同时成立，不能看一根K线改方向。 |
| 真突破/假突破判定 | 实体拉出关键位 50% 以上且第二根跟随 = 真；两个条件都不满足 = 假，等右侧或共振。 |
| 双向预案 / 不预测不埋伏 | 不猜方向、不提前埋伏——为上涨、下跌、震荡各备一套预案，市场怎么走就按哪套做。 |
| 亏损后动作写死（交易系统的最后一段） | 交易系统末尾必须写死一段——逻辑被否认、亏损之后你要做什么，由规则触发而不是临场决定。 |
