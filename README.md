## 这是什么

不是书摘，也不是课程笔记，而是一套**可执行的决策流程**。

| | |
|---|---|
| 能力卡 | **47 张**，每张含 R / I / A1 / A2 / E / B 六段 |
| 术语表 | 75 条（作者用法 vs 常识用法的差异） |
| 触发测试用例 | 49 条 |
| 整理自 | 交易员江河的公开直播与视频内容，共 135 万字转写稿 |

每张能力卡分六段：

| 段 | 内容 |
|---|---|
| **R** | 原文引用（带出处，如 `ep-2026.7.17 L1264`） |
| **I** | 方法论骨架：这套工具解决什么问题、作者怎么做 |
| **A1 / A2** | 应用示例与触发场景 |
| **E** | 可执行步骤（照着做就行） |
| **B** | 边界与失败模式（什么时候会失效） |

所以它既能给人读，也能直接装进 AI 助手里用。

### 七层体系

| 层 | 解决什么 | 代表能力 |
|---|---|---|
| 市场认知 | K 线背后谁在赚钱 | 裸K读盘、关键位、真假突破、宽幅震荡、**N字形结构**、**强弱与动能** |
| 机会筛选 | 这单该不该做 | 硬座闸门、必要条件、健康订单、**优先参与行情初期** |
| 周期契约 | 该按哪个周期做 | 主/次/参考周期配置 |
| 执行风控 | 止损放哪、什么时候走 | 以损定仓、订单出口纪律、动态离场、连损熔断、**抓转折**、**剥头皮**、**盈亏比底线** |
| 资金仓位 | 从小做大 | 筹码分配、风险预算、资金隔离、静态复利、**可固定成本换不固定收益** |
| 系统建模 | 把感觉变成数据 | 拆订单回测、交易系统构建、放大优势 |
| 心态成长 | 知道但做不到 | 情绪三步法、用规则替代修心、成长三阶段、**投资与投机判定** |

### 核心原则

1. 市场看的是资金与多空力量对比，不是形态；形态只是逻辑的载体。
2. 只做认知以内的机会——看不懂、有犹豫、需要问别人的，一律不做；空仓不是损失。
3. 周期是「拿什么成本换什么利润」的契约，不是方向。
4. 一笔订单只有两个出口：打止损，或赚钱离场；没有第三种，也绝不留被套单。
5. 技术只决定底线；从小做大靠筹码分配，且只做递减不做递增。
6. 心态问题用规则解决而非「修心」；亏损后要做什么，必须在系统里写死。
7. 把感觉量化成数据：拆盈利找必要条件，拆亏损砍条件。

## 怎么用

### 一、先安装

**最省事的办法：让 AI 帮你装。** 把下面这段整个复制给你的 AI：

```text
帮我安装这个技能包：
https://github.com/caszas/trader-jianghe-trading-system

请把它下载下来，放到你的技能目录里（比如 ~/.claude/skills/ 或 ~/.workbuddy-ai/skills/），
目录名用 trader-jianghe-trading-system。

装好后请确认：
1. SKILL.md 能被正确识别（frontmatter 能解析）
2. 里面的 references/capabilities/ 下有 47 张能力卡
3. 告诉我以后该怎么向你提问才能用上它
```

**如果你的 AI 不能联网**，就手动装：

```bash
git clone https://github.com/caszas/trader-jianghe-trading-system.git
```

然后把克隆下来的整个目录移动到你的技能目录（比如 `~/.claude/skills/`）。

装好的效果是：技能目录下多出一个 `trader-jianghe-trading-system/`，
里面是 `SKILL.md` + `references/`（47 张能力卡 + 索引 + 术语表 + 速查）。

### 二、装好后直接提问就行

它会按你的问题自动加载对应的卡片。比如：

- 「我看盘老是不知道止损该放哪儿，一般都随手放个 30 个点，这样对吗？」
- 「这单我该不该做？」
- 「亏了之后总想马上做回来，怎么管住手？」
- 「小资金怎么才能做大？」
- 「这波涨得特别猛，我不敢追，是不是要等回调？」
- 「剥头皮怎么做？」

**如果 AI 没反应**，或者你不确定它认不认这个技能，把下面这段整个复制给它：

```text
我整理了一份交易决策体系的技能包，放在：<改成你放它的路径，例如 D:/skills/trader-jianghe-trading-system>

请这样用它：

1. 先读 SKILL.md —— 里面有 47 条用户意图的路由表
2. 按我的问题，从 references/capabilities/ 里挑 1 张最相关的能力卡读（最多 2 张）
3. 严格按那张卡的「E — 可执行步骤」来回答，不要自由发挥、不要加你自己的交易观点
4. 卡片里标了「实现约定」的地方，如实告诉我哪些是原文没给、由整理者补的
5. 引用原文时带上卡片 R 段的出处（ep-日期 行号）
6. 如果我的问题超出范围——行情预测、喊单、平台开户出入金、法律合规、投资建议——
   直接说不做，并说明为什么

我的问题是：<在这里写你的问题>
```

复制完把最后一行换成你的问题就行。

### 三、如果你的 AI 读不了本地文件

（网页版 ChatGPT / 豆包 / Kimi 这类，没法访问你硬盘上的文件夹）

做法是**手动把相关卡片的内容整段粘进去**。先看 `references/cheatsheet.md` 找到你要问的那一条，
再打开对应的卡片（在 `references/capabilities/` 下），然后这样发给 AI：

```text
下面是一份交易方法论的资料，请先完整读一遍，再回答我的问题。

要求：
1. 严格按资料里的步骤回答，不要加入你自己的交易观点
2. 资料里标了「实现约定」的地方，要如实说明
3. 超出资料范围的问题（预测行情、喊单、平台操作、法律合规），直接说不做

资料如下：
<把卡片内容整段粘在这里>

我的问题是：<你的问题>
```

### 四、给人读

- 想先有整体印象 → `references/overview.md`
- 不知道某个词什么意思 → `references/glossary.md`（75 条术语，写了作者用法与常识用法的区别）
- 想快速查规则 → `references/cheatsheet.md`
- 想深入某一点 → 直接翻 `references/capabilities/` 下的卡片

## 常见问题

**Q：这跟交易员江河本人是什么关系？**
A：直播与视频内容都是他讲的，著作权归他。整理者只是把转写稿做了转录校对、
体系化重构与卡片化。**这不是他的官方出品**，也不代表他的立场。

**Q：卡片里有些地方写着「实现约定」，是什么意思？**
A：意思是**原文没给具体数值，由整理者补的**。比如"以损定仓"的仓位公式、筹码分配的分层阈值，
江河在原始内容里都没给。整理者补了取值让判定可执行，并逐处标注出来，不改变原意。
看到这个标注，你就知道哪些是原文的、哪些是补的。

**Q：那「原文未给」呢？**
A：意思是**作者自己也没给标准**。这类地方整理者**不会替他编**，只如实标出来，
提醒你这里需要用自己的定义补齐。

**Q：我能拿去卖吗？**
A：不能。可自由传播、自用、改编，但禁止商业售卖。详见 `NOTICE.md`。

**Q：我能拿去做成课程吗？**
A：免费分享可以，收费不行。而且转的时候要保留原作者和整理者的署名。

**Q：怎么知道内容有没有被改过？**
A：以本仓库为准。仓库的提交历史也记录了内容的发布时间。

**Q：发现有人倒卖怎么办？**
A：到官方地址拿原版，向平台投诉，并联系整理者。

**Q：能装到哪些 AI 里？**
A：支持 skill 的（Claude Code、WorkBuddy 等）直接放进技能目录即可；
网页版 AI 用上面「怎么用」的第三种方式，手动粘卡片内容。

**Q：`test-prompts.json` 是干什么的？**
A：49 条测试用例（该触发 / 不该触发 / 边界），用来验证技能会不会正确加载对应的卡片。
也可以喂给 darwin-skill 做自动进化。
